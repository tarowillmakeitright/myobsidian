## 1) OpenAI + Broadcom unveil an LLM-optimized inference chip
**Why it matters:** This is a high-signal infrastructure move. It points to continued vertical integration in AI compute, potential cost/performance gains for large-scale inference, and more pressure on the existing GPU-centric supply chain.

**Why it matters:** If you rely on GPT-4.5 workflows, custom GPT behavior, or benchmark comparisons, this is immediately actionable. Users and teams need to validate replacements, especially where output style or latency changed.
**Source:** https://help.openai.com/en/articles/6825453-chatgpt-release-notes

**Why it matters:** This is the most actionable security item in the set. If you run UniFi OS, patching and exposure review should move up the queue now. KEV inclusion usually means exploitation is real, not theoretical.
