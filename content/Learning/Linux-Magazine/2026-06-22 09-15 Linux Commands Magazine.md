# Linux Commands Magazine — 2026-06-22

1) 今日の1コマンド
`sed` — テキストを非対話で置換・抽出・整形できる、ログ処理と設定変更の定番コマンド。

2) 実務で使う場面
- アプリやNginx設定の一部だけを一括置換して、環境差分を素早く反映するとき
- CI/CDで生成した設定ファイルやenvファイルの値を自動書き換えするとき
- ログやコマンド出力から必要な行だけ抜き出して次の処理へ渡すとき
- 機密値を含むログの一部をマスクして共有用ファイルを作るとき

3) よく使うオプション
- `-n` : 自動表示を止め、`p`指定した行だけ出力する
- `-i` : ファイルを直接書き換える（破壊的なので要注意）
- `-E` : 拡張正規表現を使う。`+` や `()` が書きやすい
- `-e` : 複数の編集式を順番に適用する

4) 実例コマンド
```bash
# 1. 設定ファイルのポート番号を置換する
sed -E 's/^PORT=.*/PORT=8080/' .env

# 2. 元ファイルを直接更新する（事前にバックアップ推奨）
sed -i -E 's/listen 80;/listen 8080;/' /etc/nginx/conf.d/app.conf

# 3. ERROR を含む行だけ表示する
sed -n '/ERROR/p' /var/log/app.log

# 4. 20〜40行目だけ確認する
sed -n '20,40p' deploy.sh

# 5. IPアドレスらしき値をマスクして共有用ログを作る
sed -E 's/[0-9]{1,3}(\.[0-9]{1,3}){3}/[REDACTED_IP]/g' access.log > access.shared.log

# 6. 空行を削除して見やすくする
sed '/^$/d' inventory.txt
```

5) よくあるミスと安全ポイント
- `-i` は元ファイルを直接変更する。設定ファイルに使う前に `cp file file.bak` かGit管理で退避する
- 正規表現の `.` は任意の1文字。IPやドメイン置換では `\.` のようにエスケープを忘れない
- 置換対象が広すぎると意図しない行まで変わる。`^` や `$` で行頭・行末を固定すると安全
- 本番設定を書き換える前に、まず `sed ... file` で標準出力確認 → 問題なければ `-i` が堅い

6) 追加学習
- `man sed` の「Addresses」「Regular Expressions」「s command」を読むと実務で困りにくい
- 関連コマンド: `grep`（抽出）, `awk`（列処理）, `perl -pe`（より複雑な置換）
