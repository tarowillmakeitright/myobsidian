# Linux Commands Magazine — 2026-07-04 09:15

[[Home]]

1) 今日の1コマンド
`stat` — ファイルやディレクトリの更新時刻・権限・サイズ・inode を正確に確認するコマンド。

2) 実務で使う場面
- デプロイ後に、対象ファイルが本当に更新されたか時刻で確認するとき。
- バックアップや同期前後で、サイズ・mtime・inode の差分を確認するとき。
- 権限事故や所有者ミスでアプリが読めないときに、実ファイル属性を調べるとき。
- シンボリックリンクや設定ファイル実体の切り替え確認をするとき。

3) よく使うオプション
- `-c` — 表示フォーマットを指定する。スクリプトで必要な項目だけ抜き出しやすい。
- `-f` — ファイルシステム情報を表示する。空き容量確認ではなく、マウント種別やブロック情報確認向き。
- `-L` — シンボリックリンク自体ではなく、リンク先の情報を見る。
- `%y` — 更新時刻（human-readable）。更新確認でよく使う。
- `%U:%G` — 所有者:グループ。権限トラブル確認向き。

4) 実例コマンド
```bash
# ファイルの基本情報を確認
stat /etc/nginx/nginx.conf

# 更新時刻・サイズ・権限だけを見やすく出す
stat -c 'mtime=%y size=%s mode=%a path=%n' /var/www/html/index.html

# 所有者と権限を確認して、権限事故を切り分ける
stat -c 'owner=%U group=%G mode=%a %n' /srv/app/.env

# シンボリックリンクではなく実体の情報を見る
stat -L /etc/localtime

# ディレクトリ配下の設定ファイルをまとめて確認
stat -c '%y %U:%G %a %n' /etc/systemd/system/*.service

# ファイルシステム種別やブロックサイズを確認
stat -f /var/lib/docker
```

5) よくあるミスと安全ポイント
- `ls -l` だけで判断しない。秒単位の時刻や inode まで見たいなら `stat` の方が確実。
- シンボリックリンク確認で `-L` を付け忘れると、実体ではなくリンク自体の情報を見てしまう。
- スクリプトで使うなら、素の出力ではなく `-c` で明示的にフォーマット指定する。環境差の影響を減らせる。
- 時刻比較はタイムゾーン差に注意。複数ホスト比較では UTC で見る癖をつけると安全。

6) 追加学習
- `man stat` の「FORMAT SEQUENCES」を読むと、`%a` ` %u` `%g` `%i` `%n` など実務向け書式が一気に分かる。
- 関連コマンド: `ls`, `find`, `readlink`, `file`。
