# 2026-06-16 09:15 Linux Commands Magazine

## 1) 今日の1コマンド
**`ss`** — ソケット通信の状況を高速に確認できる、待受ポート・接続調査の基本コマンド。

## 2) 実務で使う場面
- WebサーバーやDBが正しくポート待受しているか確認するとき
- 障害調査で「どのプロセスが 80/443/5432 を使っているか」を見たいとき
- 接続数急増やESTAB/TIME-WAITの偏りをざっと把握したいとき
- `netstat` の代わりに、より高速に接続状況を確認したいとき

## 3) よく使うオプション
- `-t` — TCPソケットだけ表示
- `-u` — UDPソケットだけ表示
- `-l` — LISTEN中（待受中）のソケットだけ表示
- `-n` — 名前解決せず数値で表示。調査が速く、見間違いも減る
- `-p` — プロセス情報も表示（PID/プロセス名確認に便利）
- `-a` — LISTEN中も接続済みも含めて全部表示

## 4) 実例コマンド
```bash
ss -tuln
ss -ltnp
ss -tn state established
ss -ltnp 'sport = :443'
ss -ltnp | grep ':5432'
ss -uan
```

## 5) よくあるミスと安全ポイント
- `-n` を付けないと名前解決で見づらくなり、確認にも時間がかかる
- `-p` は権限不足だとプロセス名が見えないことがある。必要なら `sudo` で再確認
- 出力件数が多い環境では、`state established` や `sport = :PORT` で絞ると読みやすい
- `ss` は確認系コマンドで安全だが、結果を元に停止・killする前に対象プロセスを再確認する

## 6) 追加学習
- `man ss` の `FILTER` セクションを読むと、`sport` / `dport` / `state` を使った絞り込みが実務でかなり役立つ
- 関連コマンド: `ip`, `lsof`, `journalctl`
