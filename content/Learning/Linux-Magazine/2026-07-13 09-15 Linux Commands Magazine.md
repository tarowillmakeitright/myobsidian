# Daily Linux Commands Magazine

## 1) 今日の1コマンド
`diff` — 2つのファイルや設定の差分を確認し、変更点だけを正確に把握するコマンド。

## 2) 実務で使う場面
- デプロイ前後で `.env` や設定ファイルの差分を確認するとき
- 本番用とステージング用の Nginx / systemd / Kubernetes マニフェストの違いを点検するとき
- 生成されたログやレポートの変更点だけをレビューしたいとき
- バックアップから戻したファイルが元と同じかをざっくり確認するとき

## 3) よく使うオプション
- `-u` — unified diff 形式で表示。Git の差分表示に近く、最も読みやすい
- `-r` — ディレクトリを再帰比較。設定ディレクトリ全体の比較に便利
- `-q` — 差分があるかどうかだけを簡潔に表示。スクリプト向き
- `-y` — 左右並列で表示。目視レビューしやすい
- `-w` — 空白の違いを無視。インデント差分だけでノイズになるときに有効

## 4) 実例コマンド
```bash
diff -u .env.example .env
```
サンプル設定と実運用設定の差分を確認する。

```bash
diff -u /etc/nginx/nginx.conf /tmp/nginx.conf.new
```
Nginx 設定の変更点を適用前に確認する。

```bash
diff -r config-prod/ config-staging/
```
本番・ステージングの設定ディレクトリ全体を比較する。

```bash
diff -q backup/app.conf current/app.conf
```
バックアップと現行ファイルが同一かだけを素早く確認する。

```bash
diff -y --suppress-common-lines old-list.txt new-list.txt
```
共通行を省いて、追加・変更行だけを左右並列で見る。

```bash
diff -uw before.yaml after.yaml
```
空白差分を無視して YAML の実質的な変更だけを確認する。
```

## 5) よくあるミスと安全ポイント
- **改行コード差分に引っかかる**: Windows 由来ファイルは `^M` で差分だらけに見えることがある。必要なら `dos2unix` 後に比較する
- **ディレクトリ比較で件数が多すぎる**: `-r` は大量出力になりやすい。対象を絞るか `-q` で先に有無だけ見ると楽
- **空白差分を無視しすぎる**: `-w` は便利だが、Makefile や Python のように空白が意味を持つケースでは注意
- **比較前に対象を確認する**: 本番ファイルとテンプレート、生成前後ファイルなど、何を比べているかを間違えると判断ミスにつながる

## 6) 追加学習
- `man diff` では **`-u` / `-r` / `-q`** を先に押さえると実務でかなり使える
- 関連コマンド: `cmp`（バイナリ含む厳密比較）, `sdiff`（横並び比較）, `patch`（diff を適用する）
