# Mission: Build an AI Output Contract Test

[[Home]]

## Objective

In 30–60 minutes, create a tiny Python test harness that checks whether an LLM-style JSON response obeys a strict schema. This practices a production-ready AI/DevOps habit: validating model output before downstream automation uses it.

## Exact steps

1. Create a clean folder and Python virtual environment.
2. Install `pydantic` and `pytest`.
3. Define a `MissionResult` model with `title: str`, `summary: str`, `confidence: float` (0–1), and `sources: list[str]`.
4. Add three sample responses: one valid, one missing `sources`, and one with `confidence` above 1.
5. Write tests proving that the valid response passes and both invalid responses fail with validation errors.
6. Run `pytest -q` and save the output in `test-results.txt`.
7. Add a short README explaining why schema validation belongs at the boundary of an AI-powered pipeline.

## Expected output artifact

A small folder containing `models.py`, `test_models.py`, `README.md`, and `test-results.txt`, with all tests passing.

## Stretch challenge

Add a CI workflow that runs the tests on every push, or generate a JSON Schema from the Pydantic model and save it as `mission-result.schema.json`.
