## Mission Title
Build a Tiny RAG Evaluator with Local Embeddings

## Objective
In 30–60 minutes, create a minimal script that compares retrieval quality across 2 embedding models on a small custom dataset.

## Exact Steps
1. Create a folder `rag-mini-eval/` and add 8–12 short notes (plain text) on one topic you know.
2. Install dependencies (Python): `sentence-transformers`, `numpy`, `scikit-learn`.
3. Write `eval.py` that:
   - loads notes,
   - embeds them with model A (`all-MiniLM-L6-v2`) and model B (`all-mpnet-base-v2`),
   - runs 5 manual queries,
   - returns top-3 docs per query (cosine similarity).
4. For each query, mark whether the expected doc appears in top-3 (hit/miss).
5. Compute and print Hit@3 for each model.
6. Save findings in `results.md` with one paragraph: which model performed better and why.

## Expected Output Artifact
- `rag-mini-eval/eval.py`
- `rag-mini-eval/results.md` including Hit@3 table and short conclusion.

## Stretch Challenge
Add a simple reranker step (cross-encoder or keyword overlap heuristic) and measure whether Hit@3 improves.
