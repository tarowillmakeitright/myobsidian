# Mission: Build a Tiny Local RAG Pipeline in 45 Minutes

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Create a minimal Retrieval-Augmented Generation (RAG) prototype that indexes one local markdown file and answers a question from it using embeddings + similarity search.

## Exact Steps (30–60 min)
1. Create a new working folder and a sample `notes.md` file with 8–12 short facts (pick AI/DevOps/space topics).
2. Set up Python env and install: `sentence-transformers`, `numpy`, `scikit-learn`.
3. Write `rag_mini.py` to:
   - load `notes.md`
   - split text into chunks (~200–400 chars)
   - generate embeddings for each chunk
   - embed a user question
   - return top-3 similar chunks (cosine similarity)
4. Add a simple prompt template that combines top chunks + question, then print a final answer (even if mocked with concatenation).
5. Test with 3 questions and save outputs in `results.txt`.

## Expected Output Artifact
- `rag_mini.py`
- `notes.md`
- `results.txt` (3 Q&A runs with retrieved chunks shown)

## Stretch Challenge
Add a tiny CLI flag (`--question "..."`) and cache embeddings to `embeddings.npy` so repeated runs are faster.
