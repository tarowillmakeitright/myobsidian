# Mission: Containerize a Tiny AI Inference API

[[Home]]

**Timebox:** 45–60 minutes

## Objective

Build and run a small containerized HTTP service that accepts text and returns a deterministic “AI-style” classification (`positive`, `negative`, or `neutral`) with a confidence score. The goal is to practice a complete local AI-service delivery loop: API, container, health check, and smoke test.

## Exact steps

1. Create a new folder named `tiny-ai-api` with `app.py`, `requirements.txt`, and `Dockerfile`.
2. In `app.py`, implement:
   - `GET /health` → `{"status":"ok"}`
   - `POST /classify` accepting `{"text":"..."}`
   - a lightweight keyword-based classifier with a label and numeric confidence
3. Add only the required Python packages to `requirements.txt` (for example, FastAPI and Uvicorn).
4. Write a minimal Dockerfile using a slim Python base image, a non-root user, port `8000`, and a Uvicorn start command.
5. Build the image: `docker build -t tiny-ai-api:today .`
6. Run it locally: `docker run --rm -p 8000:8000 tiny-ai-api:today`
7. In another terminal, verify `/health` and send three `/classify` requests: one positive, one negative, and one neutral.
8. Save the commands and observed responses in `RESULTS.md`.

## Expected output artifact

A runnable `tiny-ai-api/` project containing the API code, dependencies, Dockerfile, and `RESULTS.md` with successful build/run evidence and sample JSON responses.

## Stretch challenge

Add a Docker `HEALTHCHECK`, then inspect the container until Docker reports it as `healthy`.
