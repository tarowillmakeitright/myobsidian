# Daily Learning Mission — 2026-04-08
[[Home]]

## Mission title
Build a Tiny AI Reliability Check with GitHub Actions

## Objective
In 30–60 minutes, create a simple CI workflow that runs an LLM output quality check (format + keyword guardrails) on every push.

## Exact steps
1. Create a small repo folder `ai-reliability-check/` with:
   - `prompts/sample_prompt.txt`
   - `outputs/sample_output.txt`
   - `checks/validate_output.py`
2. In `sample_output.txt`, paste a mock AI response.
3. In `validate_output.py`, add checks for:
   - Required heading present (e.g., `Summary`)
   - Max length (e.g., <= 250 words)
   - Forbidden terms list (e.g., `TODO`, `TBD`)
   Exit with non-zero code if any check fails.
4. Add `.github/workflows/ai-check.yml` to run `python checks/validate_output.py` on `push`.
5. Commit once with a passing output.
6. Commit again with an intentionally failing output to confirm CI fails.
7. Fix output and confirm CI passes again.

## Expected output artifact
- One GitHub Actions workflow file (`ai-check.yml`) and a screenshot (or copied log) of one failed run + one passed run.

## Stretch challenge
Add a second validator that checks JSON schema compliance for structured AI output using `jsonschema`.
