## Objective

In 45 minutes, create a small, repeatable benchmark that compares two prompts on the same 10 test cases and reports which prompt performs better.

## Exact steps

1. Choose one task: classify support messages as `billing`, `technical`, or `other`.
2. Write 10 short test inputs and a correct label for each in `cases.json`.
3. Draft two prompt variants: a simple instruction and a version with label definitions plus one example.
4. Write a short Python script that runs both prompts against every case, records predictions, and calculates accuracy. Use a fixed model and temperature `0`.
5. Run the benchmark and save the results.
6. Spend five minutes reviewing errors; add one sentence explaining why the better prompt won.

## Expected output artifact

A folder containing `cases.json`, `eval.py`, and `results.md` with a 2-row accuracy table, failed cases, and a one-sentence conclusion.

## Stretch challenge

Add a second metric for output-format compliance and fail any response that is not exactly one allowed label.
