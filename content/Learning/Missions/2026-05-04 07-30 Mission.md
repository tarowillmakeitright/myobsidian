## Mission Title
Build a Tiny RAG Pipeline with Local Embeddings

## Objective
In 30–60 minutes, create a minimal Retrieval-Augmented Generation (RAG) workflow that indexes a small set of notes and answers one question using retrieved context.

## Exact Steps
1. Create a folder `rag-mini/` and add 3–5 short text files (your own notes or docs).
2. Generate embeddings for each file (use any tool/library you prefer: Python + sentence-transformers, Ollama embeddings, etc.).
3. Store vectors in a simple index (FAISS, Chroma, or even in-memory cosine similarity).
4. Write a script that:
   - accepts a user question,
   - retrieves top 2 relevant chunks,
   - builds a prompt with those chunks,
   - gets an answer from your chosen LLM.
5. Run one test question and log:
   - retrieved chunks,
   - final answer,
   - one observation about answer quality.

## Expected Output Artifact
- A runnable script/notebook (`rag_mini.py` or `rag_mini.ipynb`) plus a short `README.md` with setup and one sample Q&A output.

## Stretch Challenge
Add a simple evaluation pass: ask 3 questions and score each answer (1–5) for relevance and factuality; write one improvement you’d try next.
