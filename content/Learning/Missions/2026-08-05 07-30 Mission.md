# Mission: Build an AI Service Reliability Check

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 45 minutes, create a small Python health-check script that tests an AI API endpoint for availability, latency, and valid JSON—without requiring a real API key.

## Exact steps

1. Create `ai_healthcheck.py` using only Python's standard library.
2. Accept a URL argument, send an HTTP GET request, and measure response time.
3. Report HTTP status, latency in milliseconds, and whether the response parses as JSON.
4. Return exit code `0` when status is 2xx and JSON is valid; otherwise return `1`.
5. Test it against `https://httpbin.org/json` and one deliberate failure case.
6. Add a five-line README showing usage and example output.

## Expected output artifact

A folder containing `ai_healthcheck.py` and `README.md`, plus captured output from one successful and one failed check.

## Stretch challenge

Add `--max-latency-ms`; fail the check when the response exceeds that threshold, making the script suitable for CI or a monitoring cron job.
