# Mission: Add Observability to a Tiny AI Service

[[Home]]

## Objective

Build a small Python service that wraps a mock AI inference function, then instrument it with latency, request-count, and error metrics. Complete in 30–60 minutes.

## Exact steps

1. Create a minimal FastAPI app with a `POST /predict` endpoint that accepts text and returns a mock label plus confidence score.
2. Add Prometheus instrumentation for total requests, errors, and inference latency.
3. Expose the metrics at `GET /metrics`.
4. Run the service locally and send five successful requests plus one deliberately invalid request.
5. Capture the relevant metric lines showing request count, error count, and latency observations.
6. Write three sentences explaining which metric would alert you first if the service degraded.

## Expected output artifact

A folder containing `app.py`, `requirements.txt`, and `evidence.md`; the evidence note includes the test commands, captured metrics, and the three-sentence operational takeaway.

## Stretch challenge

Add a Prometheus histogram bucket strategy suited to sub-second inference and explain why you chose those bucket boundaries.
