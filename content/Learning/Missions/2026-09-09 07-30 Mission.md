# Mission: Add an AI Quality Gate to a CI Pipeline

#learning #mission #ai #devops #science

[[Home]]

## Objective

In 45 minutes, build a tiny automated evaluation that prevents a prompt-based AI feature from shipping when its output fails basic quality checks.

## Exact steps

1. Create a small Python script with five test prompts and expected keywords or simple pass/fail rules.
2. Add a mock AI-response function (or connect an API if credentials are already configured).
3. Run every response through the rules and print a compact pass/fail report.
4. Make the script exit with code `1` when any test fails and `0` when all pass.
5. Add a minimal CI workflow—or a local shell command that mirrors CI—to run the evaluation.
6. Deliberately break one response, confirm the gate fails, then restore it and confirm it passes.

## Expected output artifact

A runnable evaluation script, five test cases, and a CI workflow or command that demonstrates both failing and passing runs.

## Stretch challenge

Save the results as JSON with a pass rate and require at least 80% to pass the quality gate.
