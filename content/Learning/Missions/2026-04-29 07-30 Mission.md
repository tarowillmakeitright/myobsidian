# Daily Learning Mission — 2026-04-29
[[Home]]

## Mission Title
**Ship a Tiny Local RAG Assistant (CLI) in 45 Minutes**

## Objective
Build a minimal local Retrieval-Augmented Generation workflow that indexes 3 short docs and answers one question with cited snippets.

## Exact Steps (30–60 min)
1. Create a folder `mini-rag` and add 3 text/markdown files on one topic (e.g., Kubernetes basics, LLM evals, or orbital mechanics).
2. Use Python + `sentence-transformers` (or `ollama embeddings` if preferred) to embed each chunk (200–400 chars).
3. Store vectors in a lightweight index (FAISS or simple cosine search in-memory).
4. Add a CLI prompt: user asks one question.
5. Retrieve top-3 chunks by similarity.
6. Generate an answer with your preferred model using only retrieved context.
7. Print answer + cited chunk IDs/files.

## Expected Output Artifact
- A runnable script: `mini-rag/main.py`
- A short run log in `mini-rag/RESULT.md` containing:
  - the question,
  - top-3 retrieved snippets,
  - final answer with citations.

## Stretch Challenge
Add a **"no-answer guard"**: if top similarity is below a threshold, respond with “insufficient context” instead of hallucinating.
