# Mission: Build a Tiny RAG Evaluator in Python

Tags: #learning #mission #ai #devops #science
Link: [[Home]]

## Objective
In 30–60 minutes, build a minimal Retrieval-Augmented Generation (RAG) evaluator that measures whether retrieved chunks actually contain the answer.

## Exact Steps
1. Create a folder `rag-mini-eval` and a Python file `eval.py`.
2. Define 8 short factual Q&A pairs (e.g., AI/DevOps/space facts).
3. Build a tiny in-memory “document store” of 12–20 text chunks.
4. Implement simple retrieval using keyword overlap scoring.
5. For each question, retrieve top-3 chunks.
6. Check if the gold answer string appears in any retrieved chunk (`hit@3`).
7. Print per-question results and overall score.
8. Save results to `results.md` with: total questions, hits, misses, and 2 failure examples.

## Expected Output Artifact
- `eval.py` (working script)
- `results.md` with a final metric like: `Hit@3 = 6/8 (75%)`

## Stretch Challenge
Add a second retrieval method (TF-IDF or embeddings) and compare both methods side-by-side in `results.md`.
