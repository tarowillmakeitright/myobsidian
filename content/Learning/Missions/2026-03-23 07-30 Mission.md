## Mission Title
Build a Local AI Log Analyzer with Python

## Objective
Create a small script that scans system logs and summarizes the top recurring warning/error patterns using a local AI model or simple NLP fallback, in 30–60 minutes.

## Exact Steps
1. Collect a sample log file (e.g., `/var/log/messages` or app logs) and copy 200–500 lines into `sample.log`.
2. Create `analyze_logs.py` with logic to:
   - parse lines,
   - extract warning/error entries,
   - group similar messages (keyword-based is fine),
   - produce a short summary.
3. (Optional AI pass) If Ollama is installed, send grouped entries to a local model (e.g., `llama3`) for a concise “top 3 issues + likely cause” summary.
4. Run the script and save output to `report.md`.
5. Add one paragraph: “What I would automate next in a real DevOps pipeline.”

## Expected Output Artifact
- `analyze_logs.py`
- `report.md` containing:
  - Top 3 recurring issues
  - Count per issue
  - One likely root cause hypothesis per issue
  - Next automation idea

## Stretch Challenge
Convert the script into a GitHub Action (or cron job) that runs daily and appends results to a dated markdown report.
