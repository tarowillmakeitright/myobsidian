# Mission: Build a Tiny RAG Evaluation Harness

**Objective:** Compare how well two retrieval settings answer the same 5 questions over a small document set, and identify which setup gives more grounded answers.

## Steps
1. Pick 3-5 short source documents (README files, notes, or articles you already have locally).
2. Create 5 factual questions that can be answered only from those documents.
3. Build a minimal script or notebook that:
   - chunks the docs in two different ways (for example: 300 chars vs 800 chars)
   - retrieves top 3 matches for each question
   - records the retrieved passages and final answer
4. Score each run on:
   - answer correctness
   - whether the answer is supported by retrieved text
   - which chunking strategy retrieved better context
5. Write a short conclusion: which retrieval setup worked better, and why.

## Expected Output Artifact
A single markdown note or CSV table showing the 5 questions, retrieved passages, answers, scores, and your conclusion.

## Stretch Challenge
Add one failure case analysis: find a question both setups handled badly, then propose one fix (better chunking, reranking, metadata filtering, or query rewriting).
