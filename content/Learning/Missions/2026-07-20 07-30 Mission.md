## Objective

In 45 minutes, build and evaluate a simple text classifier that labels short operations messages as `incident`, `change`, or `routine`.

## Exact steps

1. Create a Python script and a 15-message labeled dataset (five examples per class).
2. Use scikit-learn's `TfidfVectorizer` and `LogisticRegression` in a pipeline.
3. Run stratified 3-fold cross-validation and record accuracy plus a confusion matrix.
4. Add three deliberately ambiguous messages, inspect the predicted probabilities, and note the weakest prediction.
5. Write three sentences on what the tiny dataset gets wrong and which new examples would improve it.

## Expected output artifact

One runnable Python script plus a short Markdown results note containing the dataset, mean cross-validation accuracy, confusion matrix, ambiguous-message predictions, and conclusions.

## Stretch challenge

Compare word-level TF-IDF with character n-grams and explain which performs better on this dataset.
