# Daily Learning Mission — 2026-05-14

[[Home]]

## Mission Title
Build a Tiny Local RAG Assistant with Docker

## Objective
In 30–60 minutes, create a minimal retrieval-augmented QA setup that indexes one markdown note and answers one question using local components.

## Exact Steps
1. Create a working folder and add a short note file (`notes.md`, ~200–400 words) on any technical topic you care about.
2. Run a lightweight embedding + vector stack via Docker (for example: Qdrant + a small embedding script).
3. Split `notes.md` into chunks (around 300–500 chars each) and embed them.
4. Insert embeddings into the vector store with source metadata (`file`, `chunk_id`).
5. Query the store with one question and retrieve top 3 chunks.
6. Build a final answer using only retrieved text (no external browsing).
7. Save commands and outputs to `README.md`.

## Expected Output Artifact
A folder containing:
- `notes.md`
- ingestion/query script (`ingest.py` or `ingest.js`)
- `README.md` with:
  - Docker command(s)
  - one sample query
  - retrieved chunks
  - final answer

## Stretch Challenge
Add a second note file on a different topic and implement a simple filter (`topic=...`) so retrieval can be constrained per topic.
