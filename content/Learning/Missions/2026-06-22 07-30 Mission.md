# Mission: Build a Tiny Embedding Similarity Lab

**Objective**  
Learn how text embeddings work by generating embeddings for 10 short notes and testing whether semantic similarity beats keyword matching.

**Exact steps**  
1. Create a small dataset of 10 short sentences: 4 about AI, 3 about DevOps, 3 about space/science.  
2. Pick one embedding tool/API/library you already have access to.  
3. Generate embeddings for all 10 sentences and save the vectors or output JSON.  
4. Compare 3 query sentences against the dataset using cosine similarity.  
5. Record the top 3 matches for each query.  
6. Write 5 bullets on what matched well, what failed, and where embeddings felt smarter than plain keyword search.

**Expected output artifact**  
A single note or script bundle containing: dataset, embedding command/code, top-match results, and your 5 observations.

**Stretch challenge**  
Add one intentionally tricky query with different wording (for example, “deploy safely without downtime”) and see whether it still finds the DevOps rollout-related sentence better than keyword search.
