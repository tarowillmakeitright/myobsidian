## Mission Title
Build a Tiny RAG Pipeline Locally

## Objective
Understand the core flow of retrieval-augmented generation (RAG) by building a minimal local prototype that ingests a few notes, retrieves the most relevant chunk, and produces an answer.

## Exact Steps
1. Create a folder with 3-5 short text notes on one topic you already know a bit about (for example: Docker, tea, Linux networking, or space missions).
2. Split each note into small chunks of 200-500 characters.
3. Generate embeddings for each chunk using any local or API-based embedding tool you already have access to.
4. Store the chunks plus embeddings in a simple format such as JSON or SQLite.
5. Write a small script that takes one question, embeds it, finds the top 3 nearest chunks, and prints them.
6. Add a final step that sends those retrieved chunks into an LLM prompt and asks for a grounded answer.
7. Test with 2-3 questions and note where retrieval succeeds or fails.

## Expected Output Artifact
One markdown note or README containing:
- the topic you used
- the script/repo path
- 2-3 sample questions
- retrieved chunks for one question
- one short paragraph on what worked and what broke

## Stretch Challenge
Add a "source confidence" section that shows similarity scores and makes the answer refuse unsupported claims when retrieval is weak.
