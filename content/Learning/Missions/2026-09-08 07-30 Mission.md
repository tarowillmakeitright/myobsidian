# Mission: Build an AI Incident-Triage Assistant

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 45 minutes, build a small Python tool that turns a pasted service log into a structured incident summary: likely cause, supporting evidence, severity, and next action.

## Steps

1. **Define the contract (5 min):** Create a JSON schema with `severity`, `likely_cause`, `evidence`, `next_action`, and `confidence` fields.
2. **Prepare test data (5 min):** Write a 15–25 line synthetic log containing one clear failure, such as database connection exhaustion or repeated HTTP 503 responses.
3. **Build the analyzer (20 min):** Write a Python script that reads the log, sends it to an LLM, requests schema-conforming JSON, and validates the response. Keep the prompt grounded: conclusions must cite exact log lines.
4. **Test failure handling (10 min):** Run it on the incident log and on a harmless log. Confirm it avoids inventing a cause when evidence is weak.
5. **Record findings (5 min):** Add the commands used, outputs, one failure mode, and one improvement idea to a short README.

## Expected output artifact

A folder containing `triage.py`, `incident.log`, `normal.log`, `triage-schema.json`, and `README.md`, with two captured JSON results.

## Stretch challenge

Add secret redaction for API keys, bearer tokens, email addresses, and IP addresses before any log text is sent to the model.
