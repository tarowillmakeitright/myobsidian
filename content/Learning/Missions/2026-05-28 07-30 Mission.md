# Daily Learning Mission — 2026-05-28

## Mission Title
Build a Tiny RAG QA Pipeline with Local Embeddings

## Objective
In 30–60 minutes, create a minimal Retrieval-Augmented Generation (RAG) workflow that can answer questions from your own short notes using embeddings + vector search.

## Exact Steps
1. Create a folder `rag-mini/` and add 3–5 short text files (topics you care about: AI/DevOps/space).
2. Generate embeddings for each file (use any tool/library you already have: Python + sentence-transformers/OpenAI-compatible API/local model).
3. Store vectors in a simple in-memory index (or FAISS if already installed).
4. Write a script that:
   - takes a user question,
   - embeds the question,
   - retrieves top-2 relevant notes,
   - builds a final prompt with retrieved context,
   - outputs an answer + cited source filenames.
5. Test with 3 questions and tune retrieval (top-k or chunk size) once.

## Expected Output Artifact
A runnable script/notebook (`rag_mini.py` or `rag_mini.ipynb`) plus a short `README.md` showing:
- how to run it,
- one sample question,
- retrieved sources,
- final answer.

## Stretch Challenge
Add a relevance threshold: if similarity is too low, return “I don’t have enough context” instead of hallucinating an answer.
