# Latency Lab: Benchmark Local AI Inference

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Measure and compare the response speed of two local or accessible AI models, then summarize what setup gives the best latency/quality tradeoff.

## Exact Steps
1. Pick 2 models/endpoints you can access today (for example: Ollama local model vs API model, or two Ollama models).
2. Prepare 3 short prompts:
   - one factual question
   - one coding task
   - one summarization task
3. Run each prompt on both models and record:
   - time to first token / visible response start
   - total completion time
   - brief quality note
4. Put results in a small comparison table.
5. Write 3 bullet conclusions:
   - fastest setup
   - best quality
   - your practical recommendation

## Expected Output Artifact
A markdown note with the prompts, timing table, and a short recommendation.

## Stretch Challenge
Automate the benchmark with a tiny script that runs the prompts and logs timings to CSV.
