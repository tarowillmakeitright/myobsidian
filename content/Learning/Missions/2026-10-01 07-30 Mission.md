# Mission: Build a Local AI Release Gate

[[Home]]

#learning #mission #ai #devops #science

## Objective

In 30–60 minutes, create a small CI-style script that rejects an AI-generated answer when it fails simple quality checks.

## Exact steps

1. Create a folder named `ai-release-gate` with `answer.txt` and `check.sh`.
2. Put a short AI-generated explanation of **why containers improve deployment reproducibility** in `answer.txt`.
3. In `check.sh`, fail with a non-zero exit code unless the answer:
   - contains 80–180 words,
   - mentions both `image` and `dependency`,
   - contains no placeholders such as `TODO`, `TBD`, or `lorem ipsum`.
4. Print a clear pass/fail message for every check.
5. Run the gate once with a deliberately bad answer, then revise the answer until all checks pass.
6. Add a short `README.md` showing the command to run and the final terminal output.

## Expected output artifact

A runnable `ai-release-gate/` folder containing `answer.txt`, `check.sh`, and `README.md`, with evidence of one failing run and one passing run.

## Stretch challenge

Add a GitHub Actions workflow that runs `check.sh` on every pull request.
