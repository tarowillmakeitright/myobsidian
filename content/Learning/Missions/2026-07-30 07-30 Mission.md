# Mission: Ship a Tiny AI Service with Health Checks

## Objective

In 30–60 minutes, build and run a minimal HTTP service that exposes an AI-style text classifier plus DevOps-ready health endpoints.

## Exact steps

1. Create a small Python FastAPI app with:
   - `POST /classify` accepting `{"text": "..."}`.
   - A simple rule-based result: `positive`, `negative`, or `neutral`.
   - `GET /health/live` returning HTTP 200.
   - `GET /health/ready` returning HTTP 200 when the classifier is initialized.
2. Add `requirements.txt` with FastAPI and Uvicorn.
3. Run it locally with `uvicorn app:app --reload`.
4. Test all endpoints with `curl`, including one positive and one negative example.
5. Add a `Dockerfile`, build the image, and run it on port 8000.
6. Save the commands and observed responses in a short `README.md`.

## Expected output artifact

A folder containing `app.py`, `requirements.txt`, `Dockerfile`, and `README.md`, with a locally tested containerized classifier service.

## Stretch challenge

Add a `HEALTHCHECK` instruction to the Dockerfile and verify its status using `docker inspect`.
