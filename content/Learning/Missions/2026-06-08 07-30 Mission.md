## Mission Title
Build a Tiny RAG Pipeline with Local Embeddings

## Objective
Learn the core moving parts of retrieval-augmented generation by indexing a small set of notes, running semantic search, and answering one question from retrieved context in 30–60 minutes.

## Exact Steps
1. Create a folder with 5–10 short text files about one topic you care about.
2. Generate embeddings for each file using a local or API-based embedding model.
3. Store the embeddings in a simple vector store (FAISS, Chroma, or even a JSON + cosine similarity script).
4. Write a small script that accepts a question, retrieves the top 3 most relevant chunks, and prints them.
5. Add one final step that produces a short answer using only the retrieved context.
6. Test with 3 questions and note one failure case.

## Expected Output Artifact
A small working script or notebook plus a screenshot or saved terminal output showing: query, top 3 retrieved chunks, final answer, and one observed failure case.

## Stretch Challenge
Add chunking + metadata filters (for example by source or date) and compare retrieval quality before vs after chunking.
