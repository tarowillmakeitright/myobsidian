# Mission: Build a Tiny AI Evaluation Harness

[[Home]]

## Objective

Create a repeatable command-line evaluation for an AI prompt, then compare two prompt variants on accuracy, format compliance, and latency. Timebox: 45 minutes.

## Exact steps

1. Create `eval.py` with five short test cases, each containing an input and expected keywords.
2. Implement a function that sends each case to your available model or, if no API is configured, a deterministic mock responder.
3. Score each response for required keywords and valid JSON output.
4. Run the suite with a baseline prompt and an improved prompt that explicitly requests the schema and constraints.
5. Record pass rate, average latency, and one failure example for each prompt.
6. Write a three-sentence conclusion explaining which prompt you would ship and why.

## Expected output artifact

A small `ai-eval/` folder containing `eval.py`, `results.json`, and `README.md` with the comparison table and conclusion.

## Stretch challenge

Add the evaluation to a GitHub Actions workflow or local pre-commit hook so it fails when the pass rate drops below 80%.
