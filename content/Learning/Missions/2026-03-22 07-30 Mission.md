## Mission Title
**Container Security Quickstart: Scan and Harden a Docker Image (30–60 min)**

## Objective
Learn a practical DevOps + AI-adjacent security workflow by scanning a container image for vulnerabilities and producing a short hardening report.

## Exact Steps
1. **Pick an image** (5 min)  
   Choose one small public image, e.g. `python:3.12-slim`.
2. **Install or run Trivy** (5 min)  
   Use Trivy locally (binary) or via container.
3. **Run baseline scan** (10 min)  
   Scan the chosen image and export results to a file (JSON or table).
4. **Identify top 3 issues** (10 min)  
   Focus on high/critical vulnerabilities and note affected packages.
5. **Harden attempt** (10–20 min)  
   Create a tiny Dockerfile variant that reduces risk (e.g., newer base image, fewer packages, non-root user, clean apt cache).
6. **Re-scan and compare** (10 min)  
   Run the scan again and compare before/after counts.

## Expected Output Artifact
A single note (or gist) containing:
- Baseline scan summary (critical/high counts)
- Hardened image scan summary
- What changed and why (3–5 bullets)
- Final recommendation: keep, modify, or replace the base image

## Stretch Challenge
Automate the scan in a simple CI workflow (GitHub Actions or local script) so every build fails when new **critical** vulnerabilities appear.
