# Mission: Build a Tiny AI Regression Eval

[[Home]]

**Timebox:** 45 minutes

## Objective

Create a small, repeatable Python evaluation that detects whether an AI prompt change improves or degrades five representative examples.

## Exact steps

1. **Define the cases (10 min):** Create `eval_cases.json` with five inputs from one task you care about (for example: summarization, classification, or structured extraction). Add the expected key facts or label for each case.
2. **Write the scorer (15 min):** Create `eval.py` that loads the cases, accepts saved model outputs from `outputs.json`, and scores each result using exact-label matching or required-keyword coverage.
3. **Compare two prompt versions (10 min):** Produce outputs for a baseline prompt and one revised prompt. Save them as `outputs-baseline.json` and `outputs-revised.json`.
4. **Run and inspect (5 min):** Print pass/fail per case plus an overall score for both versions. Investigate the largest regression, if any.
5. **Record the decision (5 min):** Add a short `README.md` stating which prompt wins, the scores, and one limitation of the evaluation.

## Expected output artifact

A folder containing `eval_cases.json`, `eval.py`, two output files, and a brief `README.md` with a baseline-vs-revised score comparison.

## Stretch challenge

Add a `--threshold` flag and make the script exit non-zero when the revised prompt falls below the threshold, so it can serve as a CI quality gate.
