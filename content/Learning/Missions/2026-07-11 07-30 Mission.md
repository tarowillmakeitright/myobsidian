# Mission: Benchmark Local LLM Prompt Latency

## Objective
Measure how prompt length affects response time and output quality for one local or hosted LLM you can access, then turn the result into a tiny performance note you can reuse later.

## Exact Steps
1. Pick one model/tool you already have access to (OpenClaw, Ollama, OpenAI API, etc.).
2. Prepare 3 prompts on the same topic:
   - Short: ~1 sentence
   - Medium: ~1 paragraph
   - Long: ~400–700 words of context
3. Ask the model the same task each time: summarize the prompt in 5 bullet points.
4. For each run, record:
   - prompt size (rough word count)
   - time to first visible output or full completion
   - output quality score from 1–5
5. Put the results in a small table.
6. Write 3 takeaways: what got slower, what stayed useful, and one rule for future prompting.

## Expected Output Artifact
A markdown note with:
- the 3 prompts
- a 3-row results table
- 3 practical takeaways
- 1 personal rule like: “Use short prompts first, add context only when accuracy clearly improves.”

## Stretch Challenge
Repeat the same test with a second model and compare which one handles long-context prompts more gracefully.
