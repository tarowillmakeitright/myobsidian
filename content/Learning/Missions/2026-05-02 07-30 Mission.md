# Daily Learning Mission (2026-05-02)
[[Home]]

## Mission Title
**Ship a Tiny RAG Evaluator (AI + DevOps mindset)**

## Objective
In 30–60 minutes, build and run a minimal script that compares two retrieval settings and reports which gives better answer grounding on a tiny local dataset.

## Exact Steps
1. Create a folder `rag-mini/` and add 3–5 short text notes (any topic you know).
2. Use a small embedding/retrieval setup (or mock with keyword search if needed).
3. Write one script (`evaluate_rag.py` or `.js`) that:
   - takes 5 test questions,
   - runs retrieval with **Setting A** (`top_k=2`) and **Setting B** (`top_k=4`),
   - logs retrieved chunks + final answer.
4. Add a simple scoring table (`grounded`, `partially grounded`, `not grounded`) for each question.
5. Summarize results in a short markdown note with one recommendation.

## Expected Output Artifact
- `rag-mini/eval-results.md` containing:
  - test questions,
  - A vs B scores,
  - 3–5 bullet insights,
  - your final recommendation for default `top_k`.

## Stretch Challenge
Add a third condition: same `top_k` but with chunk overlap enabled/disabled, and note how it changes grounding quality.
