# Mission: Add a Health Check to a Container

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 45 minutes, build a tiny containerized web service with a real health check, then verify how healthy and unhealthy states appear in Docker.

## Exact steps

1. Create a new folder named `container-health-lab` with a minimal HTTP service that returns `200 OK` on `/health`.
2. Add a `Dockerfile` that runs the service and includes a `HEALTHCHECK` instruction polling `/health` every 5 seconds.
3. Build it: `docker build -t health-lab .`
4. Run it: `docker run --rm -d --name health-lab -p 8080:8080 health-lab`
5. Confirm the endpoint works with `curl http://localhost:8080/health`.
6. Inspect status with `docker ps` and `docker inspect --format='{{json .State.Health}}' health-lab`.
7. Break the health check deliberately—for example, change its path to `/wrong`, rebuild, and rerun—then observe the transition to `unhealthy`.
8. Stop the container and record what caused each state transition.

## Expected output artifact

A `container-health-lab/` folder containing the service, `Dockerfile`, and a short `README.md` with the healthy and unhealthy inspection output plus a two-sentence explanation.

## Stretch challenge

Add a startup delay to the service and tune `--start-period`, `--retries`, and `--timeout` so Docker does not report a false failure while the app initializes.
