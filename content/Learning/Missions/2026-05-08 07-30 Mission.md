# Daily Learning Mission — 2026-05-08

[[Home]]

## Mission Title
**Containerize a Tiny AI Inference API + Health Checks**

## Objective
In 30–60 minutes, build and run a minimal FastAPI service that returns a simple AI-style text transformation, then containerize it and add a health check.

## Exact Steps
1. Create a folder `mini-ai-api` with:
   - `app.py` containing one `/infer` POST endpoint (input text -> output transformed text, e.g., summary-like truncation).
   - `requirements.txt` with `fastapi` and `uvicorn`.
2. Run locally:
   - `pip install -r requirements.txt`
   - `uvicorn app:app --reload --port 8000`
   - Test with `curl` to confirm JSON response.
3. Add Docker support:
   - Create `Dockerfile` (Python slim base, install requirements, run uvicorn).
   - Build image: `docker build -t mini-ai-api:today .`
4. Run container + health check:
   - Start container on port 8000.
   - Add `/health` endpoint returning `{ "status": "ok" }`.
   - Verify both `/health` and `/infer` via `curl`.
5. Save outputs:
   - Capture terminal commands and response examples in `MISSION-RESULT.md`.

## Expected Output Artifact
- A working repo/folder with `app.py`, `requirements.txt`, `Dockerfile`, and `MISSION-RESULT.md` showing successful local + container tests.

## Stretch Challenge
Add a `docker-compose.yml` with restart policy and environment variable for default max output length, then demonstrate changing behavior by editing only env vars.
