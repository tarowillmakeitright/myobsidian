## Mission Title
Build a tiny RAG pipeline with local embeddings

## Objective
Understand the core flow of retrieval-augmented generation by indexing a few short documents, running semantic search, and answering one question using the retrieved context.

## Exact Steps
1. Create a folder with 3-5 short text files about one topic you care about.
2. Use Python with a lightweight embedding library or API you already have access to.
3. Generate embeddings for each file and store them in a simple list or JSON.
4. Write a small script that embeds a query and returns the top 2 most similar chunks.
5. Ask one practical question and draft an answer using only the retrieved text.
6. Note one failure mode you observe, such as weak chunking or irrelevant retrieval.

## Expected Output Artifact
A small repo or folder containing:
- the source text files
- one script/notebook for embedding + retrieval
- one short markdown note with the test question, retrieved passages, and final answer

## Stretch Challenge
Add chunking plus cosine-similarity scoring, then compare results before vs. after chunking in 3 bullet points.
