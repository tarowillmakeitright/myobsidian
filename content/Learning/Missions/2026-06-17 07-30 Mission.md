## Mission Title
Build a Tiny RAG Evaluator

## Objective
Compare 3 retrieval settings for a small local document set and identify which one gives the most useful answers.

## Exact Steps
1. Pick 5-10 markdown/text files you already have.
2. Create 5 factual questions whose answers exist in those files.
3. Run one baseline search method (plain keyword or grep-based retrieval).
4. Run two variations with different chunk sizes or top-k values.
5. For each question, record:
   - whether the answer was found
   - which source file was retrieved
   - a 1-5 usefulness score
6. Summarize which setting performed best and why.

## Expected Output Artifact
A short comparison note or table showing the 3 retrieval settings, question results, and your chosen best configuration.

## Stretch Challenge
Add one “hard” question requiring information from two different files, and note which retrieval setup handles it best.
