# Mission: Trace a Request End-to-End with OpenTelemetry

**Objective:** In 30–60 minutes, build a tiny local demo that shows how one HTTP request produces a trace you can inspect, so observability stops feeling abstract.

## Steps
1. Create a tiny HTTP service in Python or Node that exposes one `/hello` endpoint.
2. Add OpenTelemetry auto-instrumentation or a minimal SDK setup.
3. Run Jaeger locally with Docker:
   ```bash
   docker run --rm -d --name jaeger \
     -p 16686:16686 -p 4318:4318 \
     jaegertracing/all-in-one:latest
   ```
4. Configure your app to export traces to `http://localhost:4318`.
5. Start the app and hit `/hello` 5–10 times with `curl` or a browser.
6. Open Jaeger UI at `http://localhost:16686` and inspect one trace.
7. Write down: request path, span count, duration, and one thing that would help during a production incident.

## Expected output artifact
- One markdown note or screenshot showing:
  - the service name
  - one captured trace
  - 3 bullet points of what you learned

## Stretch challenge
Add one custom span around a fake “database” or “external API” function and compare the trace before vs. after.
