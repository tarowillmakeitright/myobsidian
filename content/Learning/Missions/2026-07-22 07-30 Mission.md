# Build a Tiny Prompt Regression Test

[[Home]]

#learning #mission #ai #devops #science

## Objective

In 30–60 minutes, create a small, repeatable test that catches regressions in an AI prompt by checking five representative inputs against explicit pass/fail criteria.

## Exact steps

1. Pick one prompt you use or might reuse—for example, summarizing incident reports into `cause`, `impact`, and `next_action`.
2. Write five short test inputs: one normal case, one vague case, one noisy case, one empty/minimal case, and one adversarial instruction-injection case.
3. Define three binary checks for every response: valid structure, no invented facts, and correct handling of missing information.
4. Run all five inputs through the same prompt and record each response in a Markdown table.
5. Score the 15 checks as pass/fail, note the weakest case, then revise the prompt once.
6. Re-run only the failed cases and add a two-sentence conclusion describing whether the revision improved reliability.

## Expected output artifact

A Markdown prompt-evaluation sheet containing the prompt, five test cases, a 5×3 pass/fail matrix, the revised prompt, and a short conclusion.

## Stretch challenge

Turn one check into an automated assertion using a small shell, Python, or `jq` script, and save the command beside the results.
