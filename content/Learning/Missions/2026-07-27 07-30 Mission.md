# Build a Retrieval Quality Test for an AI Assistant

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 45 minutes, build a tiny, repeatable evaluation that measures whether a retrieval-based AI assistant finds the right source text for five questions.

## Exact steps

1. Create a small corpus of 8–10 short Markdown notes on one topic you know.
2. Write five questions and identify the one note that should answer each.
3. Use a local embedding/retrieval tool already available, or a simple keyword/BM25 search if none is installed.
4. Run all five queries and record the top three retrieved notes.
5. Calculate Recall@3: correct note found in top three / five.
6. Change one retrieval setting or query wording, rerun, and compare.

## Expected output artifact

A Markdown report containing the corpus list, five-question test set, top-three results, baseline and revised Recall@3, and a two-sentence conclusion.

## Stretch challenge

Add one adversarial question with ambiguous wording and document why retrieval succeeds or fails.
