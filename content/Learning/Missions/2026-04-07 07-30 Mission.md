## Mission Title
Ship a Tiny AI API with Docker Health Checks

## Objective
In 30–60 minutes, package a minimal Python API that returns a mock AI response, run it with Docker, and verify reliability using a health check.

## Exact Steps
1. Create a folder `tiny-ai-api` and add `app.py` with two endpoints:
   - `GET /health` → returns `{ "status": "ok" }`
   - `POST /ask` → accepts `{ "question": "..." }` and returns a simple stub answer.
2. Add `requirements.txt` with `fastapi` and `uvicorn`.
3. Create a `Dockerfile` to run the app on port `8000`.
4. Build and run the container:
   - `docker build -t tiny-ai-api .`
   - `docker run -p 8000:8000 tiny-ai-api`
5. Test endpoints using `curl`:
   - `curl http://localhost:8000/health`
   - `curl -X POST http://localhost:8000/ask -H "Content-Type: application/json" -d '{"question":"What is DevOps?"}'`
6. Add a basic `docker-compose.yml` with a healthcheck hitting `/health` every 10s.
7. Run `docker compose up` and confirm the service becomes `healthy`.

## Expected Output Artifact
A Git repo/folder containing:
- `app.py`
- `requirements.txt`
- `Dockerfile`
- `docker-compose.yml`
- A short `README.md` with build/run/test commands and one screenshot or pasted terminal output showing `healthy` status.

## Stretch Challenge
Replace the stub `/ask` response with a real model call (local Ollama or OpenAI API key via env vars), while keeping the same containerized workflow and health check.
