# Mission: Containerize and Observe a Tiny AI API

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, package a minimal Python inference-style API in Docker, add a health check, and inspect its runtime behavior.

## Exact steps

1. Create `app.py` with a FastAPI `/predict` endpoint that accepts a number and returns `{"prediction": number * 2}` plus a `/health` endpoint returning `{"status": "ok"}`.
2. Create `requirements.txt` containing `fastapi` and `uvicorn`.
3. Write a `Dockerfile` using `python:3.12-slim`, install dependencies, copy the app, expose port 8000, and run Uvicorn.
4. Build it: `docker build -t tiny-ai-api .`
5. Run it with a health check: `docker run --rm -p 8000:8000 --health-cmd='python -c "import urllib.request; urllib.request.urlopen(\"http://localhost:8000/health\")"' --health-interval=10s tiny-ai-api`.
6. Test `/health` and `/predict` with `curl`; inspect status with `docker ps` and logs with `docker logs <container-id>`.
7. Write three observations: image size, health status, and one production improvement.

## Expected output artifact

A small folder containing `app.py`, `requirements.txt`, and `Dockerfile`, plus a short `README.md` with the build/run commands, sample responses, image size, and observations.

## Stretch challenge

Add a non-root user and a multi-stage build, then compare the new image size and security posture with the original.
