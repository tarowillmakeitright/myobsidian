# Mission: Build an AI Service Health Gate

[[Home]]

#learning #mission #ai #devops #science

## Objective

Create a small Python health-check script that tests an AI API endpoint for availability, latency, and valid JSON, then returns a CI-friendly exit code.

## Exact steps

1. Choose an AI endpoint you can safely test (a local model endpoint is ideal; otherwise use a harmless public JSON endpoint as a stand-in).
2. Write `ai_healthcheck.py` using only Python's standard library. Accept the endpoint from `AI_HEALTH_URL`, with a sensible local default.
3. Send one `GET` request with a 5-second timeout and measure elapsed time using `time.perf_counter()`.
4. Validate that the response status is 2xx and the body parses as JSON.
5. Print one compact JSON result containing `ok`, `status`, `latency_ms`, and `error`.
6. Exit with code `0` when healthy and `1` on timeout, connection failure, non-2xx status, or invalid JSON.
7. Run one success test and one intentional failure test; save both outputs in `healthcheck-results.txt`.

## Expected output artifact

- `ai_healthcheck.py`
- `healthcheck-results.txt` containing one passing and one failing run

## Stretch challenge

Add a latency threshold via `MAX_LATENCY_MS`; fail the check when the endpoint responds correctly but too slowly.
