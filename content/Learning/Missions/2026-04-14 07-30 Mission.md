# Mission: Build a Local LLM API Healthcheck with Auto-Retry

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Create a tiny Python script that calls a local or remote LLM API endpoint, measures latency, retries once on failure, and logs a one-line status result.

## Exact Steps (30–60 min)
1. Create a folder: `llm-healthcheck/` and inside it create `check.py`.
2. Add environment variable setup for endpoint and key (if needed):
   - `LLM_URL` (e.g., `http://localhost:11434/api/generate` or your API URL)
   - `LLM_MODEL` (model name)
3. In `check.py`, implement:
   - Start timer
   - Send a minimal prompt request (e.g., "Reply with OK")
   - Timeout at 10s
   - If request fails, wait 2s and retry once
   - Print final status line: `timestamp | status=OK/FAIL | latency_ms=... | retries=...`
4. Run it 3 times and capture output in `run.log`.
5. Add a short `README.md` with:
   - How to run
   - Required env vars
   - Sample output

## Expected Output Artifact
A small repo/folder containing:
- `check.py`
- `README.md`
- `run.log` (3 sample runs)

## Stretch Challenge
Add an exit code policy:
- Exit `0` when status is OK
- Exit `1` on final failure
Then show how this could plug into a cron or CI check.
