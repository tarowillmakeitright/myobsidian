# Daily Mission — Build a Tiny RAG Evaluator

[[Home]]

#learning #mission #ai #devops #science

**Mission title:** Build a Tiny RAG Evaluator  
**Objective:** Compare retrieval quality from two chunking strategies on the same small document set and decide which works better.

**Exact steps:**
1. Pick 3-5 documents you already have locally, or download a small set of technical articles.
2. Create two chunked versions of the corpus:
   - Strategy A: fixed-size chunks (for example 500 chars with overlap)
   - Strategy B: larger semantic/section-based chunks
3. Index both versions with the same embedding model/vector store.
4. Write 8-10 realistic questions whose answers are present in the docs.
5. For each question, run retrieval against both indexes and save top-3 results.
6. Score each result set manually on:
   - answer-containing chunk found? (yes/no)
   - relevance (1-5)
   - noise level (1-5)
7. Summarize which chunking strategy performed better and why.

**Expected output artifact:**
- One markdown note or CSV with the test questions, retrieved chunks, scores, and a 5-bullet conclusion.

**Stretch challenge:**
- Add one automatic metric such as recall@3 or MRR and compare it with your manual judgment.
