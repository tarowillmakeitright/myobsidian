# Daily Learning Mission — 2026-04-17

[[Home]]

## Mission Title
Build a Tiny AI Ops Watchdog with Python + System Metrics

## Objective
In 30–60 minutes, create a small script that reads live CPU/RAM usage and uses a lightweight local AI-style rule layer to generate a human-readable "ops health" summary with one recommended action.

## Exact Steps
1. Create a project folder (e.g., `~/tmp/ai-ops-watchdog`) and a Python file `watchdog.py`.
2. Install dependency: `pip install psutil`.
3. In the script, collect:
   - CPU percent (`psutil.cpu_percent(interval=1)`)
   - Memory percent (`psutil.virtual_memory().percent`)
4. Add simple decision logic:
   - If CPU > 80 or RAM > 85 → status = `HIGH LOAD`
   - Else if CPU > 60 or RAM > 70 → status = `MODERATE`
   - Else → status = `NORMAL`
5. Generate a concise text report with:
   - timestamp
   - CPU/RAM values
   - status
   - one recommended action (e.g., check top processes, restart heavy service, monitor trend)
6. Run the script 3 times over ~5 minutes and save outputs.
7. Write a short note: did recommendations match your real machine state?

## Expected Output Artifact
- `watchdog.py`
- `sample-output.txt` containing 3 run results
- 3–5 bullet reflection in your notes

## Stretch Challenge
Add a 10-minute trend mode: sample every 30 seconds for 10 minutes, then output min/avg/max CPU+RAM and whether load is stable, rising, or spiky.
