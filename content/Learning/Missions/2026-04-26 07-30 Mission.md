## Mission Title
**RAG Grounding Drill: Measure Hallucination Drop in 45 Minutes**

## Objective
Build a tiny retrieval-augmented Q&A test and compare answers **with vs. without** retrieved context to see whether grounding reduces hallucinations.

## Exact Steps (30–60 min)
1. **Pick a topic (5 min):** Choose one narrow domain (e.g., Kubernetes probes, JWT basics, or Mars rover timeline).
2. **Create source notes (10 min):** Write 8–12 bullet facts in a local markdown file (`facts.md`). Keep them specific and checkable.
3. **Prepare 6 questions (5 min):** Write 4 answerable-from-facts questions + 2 trick/out-of-scope questions.
4. **Run baseline (10 min):** Ask your LLM the 6 questions **without** providing `facts.md`; save answers.
5. **Run grounded pass (10 min):** Ask the same 6 questions again, but include `facts.md` as context and require: “If unknown, say UNKNOWN.”
6. **Score results (5–10 min):** For each question, mark correct / incorrect / unsupported and compare both runs.

## Expected Output Artifact
A one-page report (`rag-grounding-results.md`) containing:
- Topic and source facts
- The 6 questions
- Baseline vs. grounded answers
- A tiny score table
- 3-line conclusion: Did grounding reduce hallucinations? By how much?

## Stretch Challenge
Add a **confidence score (0–100%)** to each answer in both runs, then check calibration: high confidence wrong answers are the main failure mode to track.
