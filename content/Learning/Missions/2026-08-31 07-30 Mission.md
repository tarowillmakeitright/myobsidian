# Mission: Containerize a Tiny AI Inference API

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

Build and run a reproducible Docker container that exposes a small local text-classification model through one HTTP endpoint.

## Exact steps (45–60 minutes)

1. Create a folder with `app.py`, `requirements.txt`, and `Dockerfile`.
2. In `app.py`, make a FastAPI `POST /classify` endpoint that accepts text and returns a sentiment label using `transformers.pipeline("sentiment-analysis")`.
3. Pin the required packages in `requirements.txt`: FastAPI, Uvicorn, Transformers, and a CPU PyTorch build.
4. Write a Dockerfile based on a slim Python image, install dependencies, copy the app, expose port 8000, and start Uvicorn.
5. Build the image: `docker build -t tiny-ai-api .`
6. Run it: `docker run --rm -p 8000:8000 tiny-ai-api`
7. Test it with a `curl` POST request and record the response.
8. Inspect image size and startup time; add one sentence noting the main optimization opportunity.

## Expected output artifact

A working three-file mini-project (`app.py`, `requirements.txt`, `Dockerfile`) plus a saved sample request/response proving the containerized endpoint works.

## Stretch challenge

Add a Docker health check and a `/health` endpoint, then verify the container reaches a healthy state.
