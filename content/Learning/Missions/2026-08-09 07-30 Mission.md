# Mission: Build a Tiny AI Service Health Check

[[Home]]

#learning #mission #ai #devops #science

## Objective

In 30–60 minutes, create a small Python health-check script that tests an AI API endpoint for availability, latency, and valid JSON output—without exposing credentials.

## Exact steps

1. Pick an AI endpoint you can safely call, or use `https://httpbin.org/delay/1` as a credential-free stand-in.
2. Create `ai_healthcheck.py` using Python's standard library (`urllib.request`, `json`, and `time`).
3. Make one request with a 5-second timeout and measure elapsed time with `time.perf_counter()`.
4. Validate the HTTP status and confirm the response parses as JSON.
5. Print a single structured JSON result containing `status`, `status_code`, `latency_ms`, and `checked_at`.
6. Exit with code `0` when healthy and `1` on timeout, HTTP error, or invalid JSON.
7. Run it three times and record the results in `healthcheck-results.md`, including one sentence on what threshold you would alert on.

## Expected output artifact

- `ai_healthcheck.py`
- `healthcheck-results.md` with three measurements and a proposed alert threshold

## Stretch challenge

Add a GitHub Actions workflow or cron entry that runs the check every 15 minutes and preserves failures as an artifact.
