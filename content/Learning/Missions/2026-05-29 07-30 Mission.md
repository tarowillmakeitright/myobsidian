## Mission Title
Build a Tiny RAG Assistant with Local Embeddings

## Objective
In 30–60 minutes, create a minimal retrieval-augmented assistant that answers questions from your own small note set (5–10 docs), so you understand the full RAG flow end-to-end.

## Exact Steps
1. Create a folder `mini-rag/` and add 5–10 short markdown/text notes (topics you already know).
2. Use any embedding tool/library you prefer (e.g., Python + sentence-transformers) to generate vectors for each note.
3. Store vectors in a lightweight index (FAISS or even cosine similarity over a JSON file if you want ultra-minimal).
4. Write a script that:
   - Accepts a user question
   - Embeds the question
   - Retrieves top 3 relevant chunks
   - Produces an answer using only retrieved context
5. Test with 3 questions:
   - 1 easy factual
   - 1 cross-note synthesis
   - 1 question that should return “insufficient context”
6. Log one failure case and one improvement idea.

## Expected Output Artifact
A working repo/folder containing:
- `run_rag.py` (or equivalent)
- your note corpus
- retrieval output for 3 test questions
- a short `README.md` explaining setup + what worked/failed

## Stretch Challenge
Add a simple reranking or chunking tweak, then compare before/after answer quality in 3–5 bullet points.
