## Mission Title
Build a Tiny Local RAG Prototype with Embeddings + Retrieval

## Objective (30–60 min)
Create a minimal local Retrieval-Augmented Generation workflow that can answer questions from your own notes using semantic search.

## Exact Steps
1. Create a project folder: `~/tmp/tiny-rag` and add 3–5 short text notes (AI/DevOps/space topics) in a `notes/` folder.
2. Generate embeddings for each note using a local or API embedding model (e.g., sentence-transformers or OpenAI embeddings).
3. Store vectors + metadata in a simple index (FAISS, Chroma, or even a JSON+cosine similarity script).
4. Write a small script (`ask.py` or `ask.js`) that:
   - takes a user question,
   - retrieves top 2 relevant notes,
   - builds a prompt with retrieved context,
   - returns a short answer.
5. Test with 3 questions and log:
   - retrieved note titles,
   - answer quality (1–5),
   - one failure case.

## Expected Output Artifact
A single README (`README.md`) containing:
- setup steps,
- architecture diagram (simple text diagram is fine),
- 3 test Q&A examples,
- one improvement idea for tomorrow.

## Stretch Challenge
Add source-citation formatting in the final answer (e.g., `[source: note-2.md]`) and reject answering when retrieval score is below a threshold.
