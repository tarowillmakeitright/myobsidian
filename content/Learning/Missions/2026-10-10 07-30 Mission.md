# Build a Tiny Prompt Regression Test

#learning #mission #ai #devops #science

[[Home]]

## Objective
Create a repeatable five-case test that catches regressions when an AI prompt changes. Complete in 30–60 minutes.

## Exact steps
1. Pick one prompt you use often (summarization, classification, or code review).
2. Create `cases.jsonl` with five representative inputs and one measurable expectation per case.
3. Write a small script that runs the prompt against all five cases and records the raw responses.
4. Implement simple checks such as required keywords, maximum length, valid JSON, or expected label.
5. Run the baseline, change one prompt instruction, rerun, and compare pass rates.
6. Add a short note explaining which version performed better and why.

## Expected output artifact
A folder containing `cases.jsonl`, the test runner, two result files, and a brief `README.md` with the pass-rate comparison.

## Stretch challenge
Add latency and estimated token/cost tracking, then fail the run when quality drops or cost rises by more than 20%.
