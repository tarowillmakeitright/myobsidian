# Model Drift Quickcheck with a Tiny Eval Set

## Objective
Build a 20-prompt mini evaluation to detect whether your LLM outputs have drifted (quality/style/safety) compared to a saved baseline.

## Exact Steps (30–60 min)
1. **Pick one use case** (e.g., summarization, coding help, translation).
2. **Create `prompts.jsonl` with 20 prompts** covering easy/medium/hard cases.
3. **Run baseline outputs** with your current “known-good” model/settings and save as `baseline.jsonl`.
4. **Run candidate outputs** with today’s model/settings and save as `candidate.jsonl`.
5. **Score quickly (0–2)** for each pair on:
   - Task correctness
   - Clarity/format compliance
   - Safety/tone fit
6. **Compute totals** and mark any prompt with score drop ≥1 as a drift case.
7. **Write a short conclusion**: pass/fail + top 3 failure patterns.

## Expected Output Artifact
A note or repo folder containing:
- `prompts.jsonl`
- `baseline.jsonl`
- `candidate.jsonl`
- `drift-report.md` (table of scores + pass/fail decision)

## Stretch Challenge
Automate step 5–6 with a small script that outputs a markdown report and trend line you can run daily.
