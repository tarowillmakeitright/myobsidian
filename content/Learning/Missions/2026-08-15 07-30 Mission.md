# Mission: Build an AI Output Quality Gate

[[Home]]

#learning #mission #ai #devops #science

## Objective

Create a tiny, repeatable test that catches weak or malformed AI responses before they reach a user. Timebox: 45 minutes.

## Exact steps

1. Create `eval_cases.json` with 5 prompts and expected checks: required phrase, maximum length, and valid JSON where appropriate.
2. Write a small Python script that loads the cases and evaluates saved sample responses—no API key needed.
3. Implement three checks: keyword presence, length limit, and JSON parsing.
4. Print a pass/fail line per case plus a final score.
5. Deliberately break two sample responses, run the evaluator, then fix them and rerun until all five pass.
6. Add a short README section explaining how this quality gate could run in CI.

## Expected output artifact

A folder containing `eval_cases.json`, `evaluate.py`, sample responses, and a README snippet, plus terminal output showing `5/5 passed`.

## Stretch challenge

Add a semantic relevance check using embeddings or an LLM judge, while keeping the deterministic checks as the first gate.
