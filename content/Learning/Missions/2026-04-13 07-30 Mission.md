# Mission: Ship a Minimal RAG Chat API with Evaluated Answers

Tags: #learning #mission #ai #devops #science  
Links: [[Home]]

## Objective
Build a tiny Retrieval-Augmented Generation (RAG) API that answers questions from a local markdown knowledge base, then evaluate 5 test questions for answer quality.

## Exact Steps (30–60 min)
1. Create a folder `rag-mini/` with:
   - `kb/notes.md` (10–20 short facts you choose)
   - `app.py` (or `index.js`) for one `/ask` endpoint.
2. Implement pipeline:
   - Load `kb/notes.md`
   - Split into chunks
   - Embed chunks (any local/API embedding model)
   - Store in a simple vector index (FAISS/Chroma/in-memory)
3. For `/ask`:
   - Embed user query
   - Retrieve top 3 chunks
   - Prompt LLM with retrieved context + question
   - Return answer + cited chunk IDs
4. Create `eval_questions.md` with 5 questions answerable from your KB.
5. Run all 5 questions and score each answer 0/1 for correctness.

## Expected Output Artifact
A working mini project folder containing:
- Runnable API (`/ask`)
- `eval_results.md` with a 5-row score table
- One screenshot or terminal log of successful query output

## Stretch Challenge
Containerize it with Docker and expose health check + latency log (`/health`, average response time for 5 eval queries).
