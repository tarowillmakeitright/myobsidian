## Mission Title
Container Healthcheck Bot with OpenAI + Shell

## Objective
Build a tiny command-line workflow that inspects Docker container health and generates a one-paragraph AI incident summary with one actionable fix.

## Exact Steps (30–60 min)
1. **Create sample data (5 min):**
   - Run `docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Image}}" > container_status.txt` (or mock this file if Docker isn’t running).
2. **Add quick checks (10 min):**
   - Note any container with `unhealthy`, frequent restarts, or unusual uptime in `notes.txt`.
3. **Generate AI summary prompt (10 min):**
   - Prepare a prompt that includes `container_status.txt` + `notes.txt` and asks for:
     - probable cause,
     - severity (low/med/high),
     - one immediate remediation step.
4. **Run and capture output (10–15 min):**
   - Execute the prompt with your preferred AI tool and save output as `incident_summary.md`.
5. **Final sanity check (5 min):**
   - Verify the remediation step is concrete, safe, and testable in one command.

## Expected Output Artifact
A folder (or note section) containing:
- `container_status.txt`
- `notes.txt`
- `incident_summary.md` (final AI-generated diagnosis + fix)

## Stretch Challenge
Convert the flow into a single script (`healthcheck.sh`) that collects status + notes template and auto-builds the AI prompt for reuse tomorrow.
