# Today’s Learning Mission

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Mission Title
Build a tiny Docker Compose lab with a real healthcheck

## Objective
Learn how container healthchecks and service readiness differ by making one app wait for a dependency, then documenting what actually happens.

## Exact Steps
1. Create a new folder for the lab.
2. Write a `docker-compose.yml` with:
   - a `redis` service
   - a small app service (Python or Node) that tries to connect to Redis and prints success/failure
3. Add a Redis `healthcheck` to Compose.
4. Run the stack once **without** dependency gating and note the startup behavior.
5. Update Compose to use `depends_on` with a healthy condition.
6. Run it again and compare the logs.
7. Write a short note: what changed, what did not, and why healthchecks matter.

## Expected Output Artifact
A small repo or folder containing:
- `docker-compose.yml`
- app source file
- `notes.md` with before/after observations

## Stretch Challenge
Add a second failure mode: make the app retry Redis 5 times with backoff, then compare “app-level retry” vs “Compose healthcheck gating.”
