# Mission: Build a Tiny Prompt-Evaluation Harness

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

Create a small, repeatable test that compares two prompts on the same five inputs and reports which prompt is more reliable.

## Steps (30–60 minutes)

1. Pick one task you use often, such as summarizing logs, classifying support messages, or extracting action items.
2. Write five representative test inputs in `cases.json`, including one awkward edge case.
3. Write two prompt variants: a simple baseline and a more explicit version with output rules.
4. Create `evaluate.py` that runs both prompts against every case using an available model API, or saved manual responses if no API key is configured.
5. Score each response from 0–2 for correctness and 0–1 for format compliance; record the criteria before scoring.
6. Generate `results.md` with per-case scores, totals, failures, and a one-sentence recommendation.
7. Run the evaluation once and note one change that would make the test fairer or more useful.

## Expected output artifact

A folder containing `cases.json`, `evaluate.py`, and `results.md`, with a clear winner or a documented tie.

## Stretch challenge

Add a CI job that runs the harness on demand and uploads `results.md` as an artifact.
