# Build a Minimal AI Service Health Check

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, build a small Python health-check script for an AI API that measures availability, latency, and response validity without exposing credentials.

## Exact steps

1. Create a new temporary project folder and Python virtual environment.
2. Write `ai_healthcheck.py` using only the standard library. Read the endpoint and API key from `AI_API_URL` and `AI_API_KEY` environment variables.
3. Send one lightweight request with a 10-second timeout and record total latency with `time.perf_counter()`.
4. Validate three conditions: HTTP status is successful, the body parses as JSON, and the expected response field exists.
5. Print one JSON result containing `timestamp`, `status`, `latency_ms`, and `checks`; never print the key or full response body.
6. Test both a success case and a deliberate failure case, then save the two outputs in `healthcheck-results.jsonl`.
7. Add a short `README.md` with setup, run instructions, and the meaning of each status.

## Expected output artifact

A runnable `ai_healthcheck.py`, a concise `README.md`, and `healthcheck-results.jsonl` containing one successful and one failed probe.

## Stretch challenge

Add retry logic with exponential backoff and jitter for transient HTTP 429 and 5xx responses, capped at three attempts.
