# Mission: Benchmark a Local AI API

## Objective

Build a tiny, repeatable benchmark that measures latency and reliability for an AI HTTP endpoint. Finish in 30–60 minutes.

## Exact steps

1. Pick an available AI endpoint (local Ollama, OpenAI-compatible API, or another test endpoint) and one short fixed prompt.
2. Write a shell or Python script that sends the prompt 10 times and records HTTP status plus elapsed time for every request.
3. Calculate success rate and min, median, p95, and max latency.
4. Run the benchmark once cold, then once immediately afterward as a warm run.
5. Add a five-sentence analysis covering the cold/warm difference, any failures, and one likely bottleneck.

## Expected output artifact

One benchmark script plus a Markdown report containing the command used, endpoint/model, raw results, summary statistics, and conclusions.

## Stretch challenge

Add concurrency (five simultaneous requests) and compare throughput and p95 latency with the sequential run.
