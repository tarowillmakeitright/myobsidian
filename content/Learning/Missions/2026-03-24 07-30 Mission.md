## Mission Title
Harden an LLM Prompt Against Injection (30–60 min)

## Objective
Design and test a simple system prompt + input filter that reduces prompt-injection success in a small local test set.

## Exact Steps
1. Create a baseline system prompt for a helper bot (5 min).
2. Prepare 6 test inputs: 3 normal requests + 3 injection attempts (10 min).
3. Run each input against the baseline prompt and note failures (10 min).
4. Add defenses: explicit refusal policy + delimiter strategy + simple keyword filter for risky meta-instructions (15 min).
5. Re-run the same 6 tests and compare pass/fail results (10 min).

## Expected Output Artifact
A short markdown report saved in your vault containing:
- baseline prompt
- defended prompt
- test cases
- before/after results table
- 3 bullet takeaways

## Stretch Challenge
Write a tiny script (Python or Node) that automatically runs the 6-case test set and outputs a JSON score summary (pass rate before vs after).
