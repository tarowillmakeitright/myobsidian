## Mission Title
Build a Tiny RAG Evaluator

## Objective
Compare plain keyword search vs embedding-based retrieval on a small local note set, and see which gives better answers for 5 test questions.

## Exact Steps
1. Create a folder with 10-20 short notes or documents you already have, or make a tiny sample set.
2. Write 5 realistic questions those notes should answer.
3. Run a simple baseline:
   - search with grep/ripgrep or basic keyword matching
   - record the top result for each question
4. Run an embedding-based version:
   - use any local script, notebook, or tool you like
   - chunk the notes if needed
   - retrieve top 3 matches for each question
5. Score both methods on relevance using a simple 1-3 scale.
6. Write a short conclusion: when did embeddings help, and when did keyword search win?

## Expected Output Artifact
A single markdown note or CSV with:
- the 5 questions
- baseline top results
- embedding top results
- scores for each
- a 3-5 bullet takeaway summary

## Stretch Challenge
Add one failure case where both methods do poorly, then improve retrieval by changing chunk size, query wording, or metadata filtering and note what changed.
