# Mission: Build and Test an AI Output Quality Gate

#learning #mission #ai #devops #science

Related: [[Home]]

## Objective

In 45 minutes, build a small Python quality gate that validates an AI-generated JSON response before it can enter an automation pipeline.

## Exact steps

1. **Define the contract (5 min):** Create `schema.json` requiring `summary` (string), `confidence` (number from 0 to 1), and `actions` (array of strings).
2. **Create test outputs (10 min):** Write three JSON samples: one valid, one missing `confidence`, and one with an out-of-range confidence value.
3. **Implement validation (15 min):** Create `validate_output.py` using Python's `json` module and `jsonschema`; accept a JSON filepath, print clear validation errors, and exit `0` for valid or `1` for invalid.
4. **Run the gate (10 min):** Install `jsonschema` if needed, run all three samples, and record their exit codes.
5. **Document the lesson (5 min):** Add a short README explaining why schema validation makes AI-powered automation safer and more observable.

## Expected output artifact

A folder containing `schema.json`, `validate_output.py`, three sample response files, and a README with the test commands and results.

## Stretch challenge

Add a fourth test that rejects unknown fields, then wrap all test runs in a single shell script suitable for a CI job.
