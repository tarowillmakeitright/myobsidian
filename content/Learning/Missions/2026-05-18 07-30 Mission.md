## Mission title
Build a Tiny RAG Evaluator (AI + DevOps mindset)

## Objective
In 30–60 minutes, create a minimal script that compares retrieval quality for two embedding models on a small document set.

## Exact steps
1. Create a folder `tiny-rag-eval/` with 8–12 short docs (notes/articles you already have).
2. Pick two embedding options (e.g., `text-embedding-3-small` vs a local sentence-transformer).
3. Write a script (`eval.py` or `eval.js`) that:
   - chunks docs,
   - builds vectors for model A and B,
   - runs 5 fixed queries,
   - records top-3 hits for each query/model.
4. Define a quick scoring sheet: relevant hit in top-3 = 1, else 0.
5. Calculate average score per model and print a simple comparison table.
6. Add one short note: when would you choose the weaker model anyway (cost/latency/privacy)?

## Expected output artifact
- `tiny-rag-eval/` folder containing script + sample docs + `results.md` with:
  - score table,
  - 2–3 key observations,
  - final pick and rationale.

## Stretch challenge
Containerize it with a `Dockerfile` and run once with `docker run` so the evaluator is reproducible on any machine.
