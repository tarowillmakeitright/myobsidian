# Mission: Build an AI Incident-Log Triage Pipeline

#learning #mission #ai #devops #science

Link: [[Home]]

## Objective

Create a small Python tool that turns a noisy service log into a structured incident summary using deterministic parsing plus an LLM-ready prompt. Complete in 30–60 minutes.

## Exact steps

1. Create `incident_triage.py` and a 20–30 line sample log containing INFO, WARN, and ERROR events.
2. Parse each line into timestamp, level, service, and message fields.
3. Count events by severity and service; collect the first and last ERROR timestamps.
4. Output a Markdown summary with impact signals, a short timeline, and the three most frequent error messages.
5. Add a generated prompt beneath the summary asking an AI to propose the likely cause, evidence, and next three diagnostic checks.
6. Run the tool against the sample log and verify that malformed lines are skipped with a warning rather than crashing.

## Expected output artifact

`incident-summary.md`, plus the reusable `incident_triage.py` script and sample log.

## Stretch challenge

Add a `--since` option that includes only events newer than a supplied ISO-8601 timestamp.
