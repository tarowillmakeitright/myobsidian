# Mission: Add AI-Assisted Incident Triage to a DevOps Runbook

## Objective

In 30–60 minutes, build and test a reusable prompt that turns a short service-incident log into a structured triage report without inventing facts.

## Exact steps

1. Create a 20–30 line sample log containing one clear failure, timestamps, one harmless warning, and one misleading symptom.
2. Write a prompt that asks an AI to return: incident summary, evidence, likely causes ranked by confidence, missing information, and the next three safe diagnostic commands.
3. Add guardrails: quote exact evidence, label uncertainty, avoid destructive commands, and never claim a root cause without proof.
4. Run the prompt against the sample log and save the response.
5. Review every claim against the log. Mark unsupported claims and revise the prompt once to prevent them.
6. Run the revised prompt again and compare the two reports.

## Expected output artifact

A Markdown file named `ai-incident-triage-runbook.md` containing the sample log, final prompt, final triage report, and a three-bullet evaluation of accuracy and usefulness.

## Stretch challenge

Convert the final report format into a strict JSON schema and validate one model response against it.
