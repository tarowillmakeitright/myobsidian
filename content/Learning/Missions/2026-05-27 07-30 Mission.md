## Mission Title
**Ship a Local RAG Prototype with Quality Checks (AI + DevOps)**

## Objective
Build a minimal local Retrieval-Augmented Generation (RAG) workflow that can answer questions from a small document set, then evaluate answer quality on 5 test queries.

## Exact Steps (30–60 min)
1. Create a working folder and add 5–10 short docs (Markdown/text) on one topic (e.g., Kubernetes basics, LLM notes, or space mission summaries).
2. Set up a quick local pipeline (any stack you prefer: Python + FAISS/Chroma, or JS equivalent):
   - chunk docs
   - create embeddings
   - store vectors
   - implement retrieve + answer
3. Write exactly **5 test questions** that should be answerable from your docs.
4. Run the pipeline for each question and log:
   - top retrieved chunks
   - generated answer
   - quick score: Correct / Partly Correct / Incorrect
5. Improve one weak point (chunk size, top-k, prompt format, or source filtering), rerun all 5 questions, and compare scores.

## Expected Output Artifact
A single note or README containing:
- setup commands
- the 5 test questions
- before/after result table
- one short conclusion: what change improved quality most

## Stretch Challenge
Add source-grounding in the final answer (include chunk IDs or quoted snippets) and reject answers when retrieval confidence is low.
