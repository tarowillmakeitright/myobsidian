# Mission: Build a Tiny AI Service Health Gate

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, build a small Python health-check script that tests an AI HTTP endpoint for availability, latency, and valid JSON, then exits with a CI-friendly status code.

## Exact steps

1. Pick an AI endpoint you can safely call (a local model endpoint is ideal); record its URL and expected JSON field.
2. Create `ai_healthcheck.py` using Python's standard library or `requests`.
3. Send one minimal request with a 10-second timeout and measure elapsed time.
4. Validate the HTTP status, JSON parsing, expected field, and a latency threshold such as 3 seconds.
5. Print a compact PASS/FAIL report and exit `0` on success or `1` on failure.
6. Test three cases: healthy endpoint, invalid URL, and an intentionally strict latency threshold.

## Expected output artifact

`ai_healthcheck.py` plus a short terminal transcript showing one PASS and two expected FAIL results.

## Stretch challenge

Add a GitHub Actions or local CI workflow step that runs the health gate and uploads the report as an artifact.
