# Mission: Ship a Local AI Log Anomaly Detector (30–60 min)

Tags: #learning #mission #ai #devops #science  
Links: [[Home]]

## Objective
Build a tiny Python tool that scans system logs and flags unusual lines using a simple AI-style anomaly score (TF-IDF + Isolation Forest), then outputs a short report.

## Exact Steps
1. Create a working folder and a Python virtualenv.
2. Install: `scikit-learn`, `pandas`.
3. Collect a sample log file (e.g., `/var/log/messages`, `/var/log/syslog`, or app logs) and copy ~500–2000 lines to `sample.log`.
4. Write `detect_anomalies.py`:
   - Load log lines.
   - Convert lines to TF-IDF vectors.
   - Train `IsolationForest(contamination=0.03)`.
   - Score lines and print top 20 most anomalous.
5. Run the script and save output to `anomaly-report.txt`.
6. Review top findings and label each as: expected/noise/suspicious.

## Expected Output Artifact
- `detect_anomalies.py`
- `anomaly-report.txt` with top 20 anomalies and quick labels.

## Stretch Challenge
Containerize it with a minimal `Dockerfile` and run it against logs mounted as a volume, so the same detector can be reused on another host quickly.
