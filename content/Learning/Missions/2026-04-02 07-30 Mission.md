# Mission: Build a Tiny RAG Evaluator in 45 Minutes

Tags: #learning #mission #ai #devops #science
Link: [[Home]]

## Objective
Create a minimal Retrieval-Augmented Generation (RAG) evaluation script that measures answer quality on 5 Q&A pairs using a local embedding model/API and outputs a simple score table.

## Exact Steps (30–60 min)
1. Create a working folder (`rag-eval-mini`) and a `questions.json` file with 5 domain questions + expected key points.
2. Pick your stack (Python preferred) and install only essentials (`sentence-transformers` or API SDK, `pandas`, `rich` optional).
3. Add 3–5 short source documents (`docs/`) and chunk them into small passages.
4. Implement retrieval: embed chunks + question, return top-3 chunks by cosine similarity.
5. Implement generation: build prompt with retrieved chunks and produce one answer per question.
6. Implement scoring:
   - **Retrieval hit**: expected key points present in top-3 chunks (0/1)
   - **Answer coverage**: expected key points present in final answer (0–1 fraction)
7. Output `results.md` with a compact table (question, retrieval hit, coverage, notes).
8. Write a 3-line reflection: biggest failure mode, one fix, and next experiment.

## Expected Output Artifact
- `results.md` containing a score table for all 5 questions and a short reflection.

## Stretch Challenge
Add one reranking step (cross-encoder or heuristic) and compare before/after average coverage in the same `results.md`.
