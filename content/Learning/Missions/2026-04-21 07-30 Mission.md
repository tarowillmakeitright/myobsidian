## Mission title
Build a Local RAG Mini-Pipeline with Embeddings + Retrieval Evaluation

## Objective
In 30–60 minutes, create a tiny local retrieval-augmented workflow: index 5 short docs, run 5 test queries, and measure whether top-1 retrieval matches the expected doc.

## Exact steps
1. Create a folder `rag-mini/` and add 5 short text files (topics you care about: AI, DevOps, space science, etc.).
2. Install tools (pick one stack):
   - Python: `pip install sentence-transformers faiss-cpu`
3. Write a script to:
   - Read all docs
   - Generate embeddings
   - Store vectors in FAISS
   - Query top-3 matches for each test question
4. Define 5 test queries and expected “correct” doc IDs in a small JSON file.
5. Run evaluation:
   - Compute Top-1 accuracy (`correct_top1 / total_queries`)
   - Print failed cases with returned vs expected doc
6. Tune one thing (chunk size, query wording, or model choice) and rerun once.

## Expected output artifact
A repo/folder containing:
- `index_and_eval.py`
- `docs/*.txt`
- `tests.json`
- `results.md` with Top-1 score before/after one tuning change

## Stretch challenge
Add a reranker step (or simple cosine re-score with a second model) and compare whether Top-1 accuracy improves.
