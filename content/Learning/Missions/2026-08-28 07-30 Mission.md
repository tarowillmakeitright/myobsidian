# Build a CI Gate for an AI Evaluation

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

Create a small, repeatable evaluation that blocks a mock AI release when response quality falls below a threshold.

## Exact steps (45 minutes)

1. Create a folder named `ai-eval-gate` with `responses.json`, containing 5 prompt/response pairs and a required keyword for each.
2. Write `evaluate.py` using only Python’s standard library. Score each response as pass/fail based on whether its required keyword appears.
3. Print a compact report with passed cases, total cases, percentage score, and failed case IDs.
4. Exit with code 1 when the score is below 80%; otherwise exit with code 0.
5. Add a GitHub Actions workflow that runs `python evaluate.py` on pushes and pull requests.
6. Run it locally once with all cases passing, then deliberately break one case and verify the report and exit code.

## Expected output artifact

A runnable `ai-eval-gate/` mini-project containing `responses.json`, `evaluate.py`, `.github/workflows/eval.yml`, and a pasted sample evaluation report in `README.md`.

## Stretch challenge

Add a second metric that checks response length against a configurable minimum and maximum, then require both metrics to pass the 80% gate.
