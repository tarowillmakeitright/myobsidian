# Mission: Dockerize a FastAPI Health Service with CI Smoke Test

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Build and run a minimal FastAPI service in Docker, then add a GitHub Actions workflow that runs a smoke test (`/health`) on every push.

## Exact Steps (30–60 min)
1. Create a folder `fastapi-health-mission` and initialize a git repo.
2. Add `app/main.py` with one endpoint:
   - `GET /health` returns `{"status":"ok","time":"<iso timestamp>"}`.
3. Add `requirements.txt` with `fastapi` and `uvicorn`.
4. Add a `Dockerfile`:
   - Base: `python:3.12-slim`
   - Copy files, install deps, expose `8000`
   - Start command: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
5. Build and run locally:
   - `docker build -t fastapi-health .`
   - `docker run -p 8000:8000 fastapi-health`
6. Test endpoint:
   - `curl http://localhost:8000/health`
   - Confirm JSON response and HTTP 200.
7. Add `.github/workflows/smoke.yml`:
   - On `push`
   - Setup Python
   - Install deps
   - Start app in background
   - Run curl smoke test and fail if status != 200.
8. Commit all files with message: `feat: dockerized fastapi health service with CI smoke test`.

## Expected Output Artifact
A GitHub repository containing:
- `app/main.py`
- `Dockerfile`
- `requirements.txt`
- `.github/workflows/smoke.yml`
- A successful local `/health` curl output screenshot or terminal log snippet.

## Stretch Challenge
Add a `/metrics` endpoint (Prometheus text format) with one custom counter (e.g., total health checks), and include it in the smoke workflow.
