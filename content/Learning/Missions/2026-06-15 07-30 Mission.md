**Mission title:** Build a 1-day ISS pass tracker for Tokyo

**Objective:** In 30–60 minutes, fetch today’s ISS pass times for Tokyo, convert them to local time, and produce a clean markdown quicklook you can reuse.

**Exact steps:**
1. Create a working folder for the mission.
2. Use a public API such as Open Notify to fetch upcoming ISS passes for Tokyo coordinates (35.6762, 139.6503).
3. Save the raw JSON response.
4. Convert each pass timestamp from UTC to Asia/Tokyo.
5. Make a small markdown report with: pass time, duration, and a one-line note for the best viewing window.
6. Add one short section: "What I learned" with 3 bullets.
7. If time remains, script the whole flow so it runs in one command.

**Expected output artifact:**
- `iss-passes-tokyo.json`
- `iss-passes-tokyo.md`
- Optional: `fetch_iss_passes.py` or `fetch_iss_passes.sh`

**Stretch challenge:**
Plot the next pass windows into an `.ics` calendar file or add a weather check to flag likely visible passes.
