# Mission: Build a Tiny RAG Evaluator with Local Embeddings

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
In 30–60 minutes, create a minimal script that compares retrieval quality across two chunk sizes for the same document set.

## Exact Steps
1. Create a folder `rag-mini-eval` and add 3 short docs (can be markdown/text notes).
2. Install deps: `pip install sentence-transformers faiss-cpu` (or your preferred vector store).
3. Write a script that:
   - chunks docs at **200 chars** and **600 chars** (two runs),
   - embeds chunks,
   - indexes vectors,
   - runs 5 test queries,
   - records top-3 retrieved chunk IDs for each query.
4. For each query, mark whether at least one relevant chunk appears in top-3.
5. Compute simple hit@3 for both chunk sizes.

## Expected Output Artifact
A markdown report `results.md` containing:
- test queries,
- top-3 retrieval results per query for each chunk size,
- hit@3 comparison,
- one-paragraph conclusion on which chunk size worked better and why.

## Stretch Challenge
Add a third run with metadata filtering (e.g., by document topic) and compare whether precision improves.
