# Mission: Build a Tiny AI Answer Verifier

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective
In 45 minutes, build a small script that checks an AI-generated factual answer against supplied evidence and returns a structured verdict: `supported`, `unsupported`, or `uncertain`.

## Exact steps
1. **Define the contract (5 min):** Create a JSON schema with `verdict`, `confidence`, and `reason` fields.
2. **Prepare test cases (10 min):** Write three evidence/answer pairs—one supported, one contradicted, and one ambiguous.
3. **Implement the verifier (15 min):** Use an available LLM API or local model. Prompt it to judge only from the supplied evidence and produce schema-valid JSON.
4. **Run and inspect (10 min):** Execute all three cases. Record the raw verdicts and note any schema or reasoning failures.
5. **Harden once (5 min):** Improve the prompt or validation logic based on the failures, then rerun the weakest case.

## Expected output artifact
A folder containing `verify.py` (or equivalent), `cases.json`, and `results.json`, plus a short README with one lesson learned.

## Stretch challenge
Add an automated retry that activates only when the model returns invalid JSON or confidence below `0.6`.
