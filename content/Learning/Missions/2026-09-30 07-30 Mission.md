# Mission: Build a Tiny AI Output Evaluator

[[Home]]

## Objective

In 45 minutes, create a small Python evaluator that scores short AI answers for required facts, forbidden phrases, and length. The goal is to learn the core mechanics behind repeatable LLM evaluation without needing an API.

## Exact steps

1. **Define three test cases (10 min).** Create a JSON file containing a prompt, a sample answer, required keywords, forbidden phrases, and a maximum word count for each case.
2. **Write the evaluator (15 min).** Load the JSON and award one point each for: all required keywords present, no forbidden phrase present, and staying within the word limit.
3. **Add diagnostics (10 min).** For every failed check, print a specific reason such as `missing keyword: orbit` or `over limit: 63/50 words`.
4. **Run and refine (10 min).** Execute the script, deliberately make one answer fail, confirm the diagnostic is useful, then restore or improve the answer.

## Expected output artifact

A folder containing:

- `cases.json` with three evaluation cases
- `evaluate.py` with deterministic scoring and diagnostics
- `results.txt` showing each case's score out of 3 and the overall score

## Stretch challenge

Add a `--json` option that emits machine-readable results suitable for a CI pipeline, then make the command exit with status 1 when any case scores below 3.
