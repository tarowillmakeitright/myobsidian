# Mission: Containerize a Tiny AI Inference API

[[Home]]

## Objective

Build and run a minimal FastAPI service that exposes a deterministic “AI-style” text classification endpoint inside Docker. Practice the full path from Python code to a reproducible container in 30–60 minutes.

## Exact steps

1. Create a new folder containing `app.py`, `requirements.txt`, and `Dockerfile`.
2. In `app.py`, add a FastAPI `POST /classify` endpoint accepting `{"text": "..."}`.
3. Implement a tiny keyword classifier returning one label: `ai`, `devops`, `space`, or `other`.
4. Add FastAPI and Uvicorn to `requirements.txt`.
5. Write a Dockerfile based on `python:3.12-slim`, install dependencies, copy the app, and start Uvicorn on port 8000.
6. Build with `docker build -t learning-classifier .`.
7. Run with `docker run --rm -p 8000:8000 learning-classifier`.
8. Test all four labels using `curl`, then stop the container.

## Expected output artifact

A working three-file repository plus a `README.md` containing the build/run commands and four successful request/response examples.

## Stretch challenge

Add a `/health` endpoint and a Docker `HEALTHCHECK`, then verify the container becomes `healthy` with `docker inspect`.
