# Mission: Build a Tiny AI Prompt Regression Test

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 45 minutes, create a small automated test that detects when an AI prompt stops producing an acceptable structured response.

## Exact steps

1. **Define the contract (5 min):** Choose one prompt, such as “Summarize this incident report,” and require JSON with `summary`, `severity`, and `next_action` fields.
2. **Create three cases (10 min):** Write one normal incident, one ambiguous incident, and one harmless event. Add the expected severity for each.
3. **Build the checker (15 min):** Write a short Python script that loads the cases, calls your available model—or a stub response if no API is configured—and verifies valid JSON, required fields, and expected severity.
4. **Run and inspect (10 min):** Execute all three cases, record pass/fail results, and deliberately break the prompt once to confirm the checker catches the regression.
5. **Document one finding (5 min):** Note which assertion was most useful and one improvement you would make before using this in CI.

## Expected artifact

A folder containing `cases.json`, `evaluate.py`, and `results.md` with a three-case pass/fail table and one short lesson learned.

## Stretch challenge

Add the checker to a GitHub Actions or other CI workflow so it runs automatically on prompt changes.
