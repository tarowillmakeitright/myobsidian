# Mission: Build a Local AI Service Health Check

#learning #mission #ai #devops #science

[[Home]]

## Objective
In 30–60 minutes, build a small Bash health-check script that tests a local AI API endpoint and returns useful pass/fail diagnostics.

## Exact steps
1. Choose a local or test HTTP endpoint (for example, an Ollama `/api/tags` endpoint or a simple mock server).
2. Write `ai-healthcheck.sh` using `curl` with a 5-second timeout.
3. Check the HTTP status, total response time, and whether the response contains an expected JSON field.
4. Print one clear `OK` or `FAIL` line with the measured values; exit `0` on success and nonzero on failure.
5. Run one successful test and one deliberate failure test using a bad port or URL.
6. Add a short usage example and dependency note to the script header.

## Expected output artifact
`ai-healthcheck.sh`, plus two captured terminal outputs showing the success and failure cases.

## Stretch challenge
Emit a Prometheus-compatible metric such as `ai_endpoint_up 1` and `ai_endpoint_response_seconds 0.123`.
