# Mission: Build a Tiny AI Service Health Gate

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, build a small Python health gate that checks an AI service's latency and response validity, then exits with a CI-friendly status code.

## Exact steps

1. Create `ai_health_gate.py` using only Python's standard library.
2. Make it call a configurable HTTP endpoint (use a local mock or public test endpoint if no AI API is available).
3. Measure response time and verify the response is HTTP 200 plus valid JSON containing a required key.
4. Accept `--url`, `--max-latency-ms`, and `--required-key` arguments.
5. Print a one-line PASS/FAIL report and exit `0` on success or `1` on failure.
6. Run three checks: healthy response, missing key, and deliberately strict latency threshold.
7. Record the commands and results in a short `README.md` snippet.

## Expected output artifact

`ai_health_gate.py` plus a README snippet showing one passing and two failing test runs.

## Stretch challenge

Add a GitHub Actions workflow that runs the gate against a local mock server and uploads the test log as an artifact.
