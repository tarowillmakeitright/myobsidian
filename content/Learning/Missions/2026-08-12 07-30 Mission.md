# Mission: Build an AI Incident Summarizer

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, build a small Python tool that converts a short DevOps incident log into a structured summary with timeline, probable cause, impact, and next actions.

## Exact steps

1. Create `incident.txt` with 8–12 timestamped events from a fictional service outage.
2. Write `summarize_incident.py` that reads the file and sends it to an LLM using a prompt that requests four sections: **Timeline**, **Probable cause**, **Impact**, and **Next actions**.
3. Require the model to distinguish facts from inferences and return valid Markdown.
4. Save the response as `incident-summary.md`.
5. Review the summary against the source log and add one sentence noting any unsupported claim or missing event.

## Expected output artifact

`incident-summary.md` containing a concise, evidence-aware post-incident summary, plus the prompt and script used to generate it.

## Stretch challenge

Add JSON output with fixed fields and validate it before rendering the final Markdown report.
