## Mission Title
Build a Tiny RAG Prototype with Local Documents

## Objective
Learn the core workflow of retrieval-augmented generation by indexing 3-5 local notes/files and querying them with a simple semantic search pipeline.

## Exact Steps
1. Pick 3-5 short local text or markdown files you already have.
2. Split them into small chunks (roughly 200-500 words each).
3. Generate embeddings for each chunk using any embedding tool/API you have available.
4. Store the chunks + embeddings in a simple format (JSON, SQLite, or a lightweight vector DB).
5. Run 3 test questions against the index and retrieve the top matching chunks.
6. For each question, inspect whether the retrieved context is actually useful.
7. Write a short note on what worked, what failed, and one improvement you would make next.

## Expected Output Artifact
A small repo or folder containing:
- the sample documents
- the chunk/index file
- 3 example queries with retrieved results
- a short README or note with lessons learned

## Stretch Challenge
Add metadata filtering (for example by file name, tag, or date) and compare retrieval quality before vs. after filtering.
