# AI Mission — Build a Tiny RAG Evaluator

[[Home]]

## Objective
Compare naive keyword search vs embedding-based retrieval on a tiny note set, and see which one returns more relevant context for a question.

## Steps
1. Create a small dataset of 10–15 short notes in a text or JSON file on any topic you know.
2. Write a simple script that implements baseline keyword search (term overlap / TF-IDF if convenient).
3. Add embedding-based retrieval using a local or API embedding model.
4. Prepare 5 test questions that should map to specific notes.
5. Run both retrieval methods on all 5 questions.
6. Score results with a simple rubric: top-1 relevant? top-3 relevant?
7. Summarize where embeddings helped and where they did not.

## Expected Output Artifact
- One script or notebook
- One tiny dataset file
- A short markdown summary with a 5-row comparison table of results

## Stretch Challenge
Add a reranker or query expansion step and see if it beats both baselines on at least 1–2 questions.
