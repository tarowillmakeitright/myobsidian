# Daily Learning Mission (2026-05-07)

[[Home]]

## Mission Title
**Ship a Tiny RAG Evaluator (Local, 45 min)**

## Objective
Build and run a minimal Retrieval-Augmented Generation (RAG) evaluator that measures whether retrieved context improves answer quality on 5 test questions.

## Exact Steps (30–60 min)
1. Create a folder `rag-mini/` and add a small corpus (`docs.txt`, ~15–25 short paragraphs on one topic you know).
2. Write a simple script (Python or JS) to:
   - split corpus into chunks,
   - embed chunks (any local/API embedding model),
   - retrieve top-3 chunks per question,
   - call an LLM twice per question: **without context** and **with retrieved context**.
3. Prepare 5 factual questions where answers are present in your corpus.
4. Score each pair manually on a 0–2 scale:
   - 0 = wrong,
   - 1 = partially correct,
   - 2 = correct.
5. Compute average score for no-context vs with-context and write one-paragraph takeaway.

## Expected Output Artifact
A single markdown report: `rag-mini/report.md` containing:
- the 5 questions,
- both answers per question,
- scores,
- average comparison,
- 3 bullet insights.

## Stretch Challenge
Add a **failure analysis table**: for every miss, label root cause (`retrieval miss`, `chunk too long`, `ambiguous question`, `model hallucination`) and propose one fix per cause.
