# Mission: Demystify Self-Attention in 45 Minutes

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

Implement single-head scaled dot-product attention with NumPy and explain how changing the temperature affects token focus.

## Exact steps

1. **5 min — Set up:** Create `attention_demo.py`; import NumPy and define three 3D token vectors plus fixed `Wq`, `Wk`, and `Wv` matrices.
2. **15 min — Implement:** Compute `Q`, `K`, and `V`, then scores as `Q @ K.T / sqrt(d_k)`. Implement a numerically stable softmax and calculate `weights @ V`.
3. **10 min — Inspect:** Print the score matrix, attention weights, row sums, and output vectors. Assert that every weight row sums to 1 within `1e-6`.
4. **10 min — Experiment:** Repeat with divisors `0.5 * sqrt(d_k)`, `sqrt(d_k)`, and `2 * sqrt(d_k)`. Record which setting produces the sharpest and flattest distributions.
5. **5 min — Explain:** Write three bullets connecting query-key similarity, softmax normalization, and the role of scaling.

## Expected output artifact

- `attention_demo.py`, runnable with `python attention_demo.py`
- A short results section containing the three attention matrices and three explanatory bullets

## Stretch challenge

Add a causal mask so each token can attend only to itself and earlier tokens, then verify that all forbidden attention weights are zero.
