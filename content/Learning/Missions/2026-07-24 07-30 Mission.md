# Mission: Build a Tiny AI Service Health Gate

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, build a Python health-check script that probes a local or public AI API endpoint, measures latency, validates the response shape, and exits with a CI-friendly status code.

## Exact steps

1. Choose an endpoint: a local model server’s `/health` or `/v1/models`, or another safe JSON API.
2. Create `ai_healthcheck.py` using `urllib.request` or `requests`.
3. Add a 5-second timeout and measure round-trip latency with `time.perf_counter()`.
4. Validate the HTTP status and one expected JSON field.
5. Print a single-line result containing `status`, `latency_ms`, and any error.
6. Exit `0` when healthy and `1` when unhealthy or slower than a chosen threshold.
7. Run one healthy test and one intentional failure test; record both commands and outputs.

## Expected output artifact

`ai_healthcheck.py` plus a short Markdown test log showing one passing and one failing run.

## Stretch challenge

Add a GitHub Actions workflow or cron example that runs the check on a schedule and preserves the result as an artifact.
