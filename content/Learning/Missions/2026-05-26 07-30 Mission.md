# Daily Learning Mission (2026-05-26)

[[Home]]

## Mission Title
**Build a Tiny RAG Evaluator (AI + DevOps mindset)**

## Objective
In 30–60 minutes, create a minimal Retrieval-Augmented Generation (RAG) evaluation script that measures answer quality on 5 Q&A pairs and outputs a simple score report.

## Exact Steps
1. Create a folder for today’s experiment (e.g., `rag-eval-mini/`).
2. Prepare a small local dataset: 1 short reference text file and 5 questions with expected key points.
3. Write a script (Python or Node) that:
   - retrieves relevant chunks from the reference text (simple keyword match is fine),
   - generates draft answers (LLM/API or mocked answers if offline),
   - checks each answer for expected key points (string/regex match),
   - computes a per-question score and overall average.
4. Run the script and capture results.
5. Note one weakness in your evaluator and one improvement idea.

## Expected Output Artifact
- `report.md` containing:
  - the 5 questions,
  - retrieved context snippets,
  - generated answers,
  - per-question scores,
  - overall score,
  - one weakness + one next improvement.

## Stretch Challenge
Add a second retrieval strategy (e.g., chunk overlap or TF-IDF) and compare both strategies in a mini table with accuracy and runtime.
