# Mission: Build a Tiny RAG Evaluator for Space Facts

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Create a minimal local script that answers 3 space-related questions using retrieval-augmented generation (RAG), then score answer quality with a simple rubric.

## Exact Steps (30–60 min)
1. Create a folder `rag-space-mini/` and a text file `space_notes.md` with 8–12 short facts (e.g., Artemis timeline, JWST, exoplanets, Mars atmosphere).
2. Write a small script (Python or Node) that:
   - Splits `space_notes.md` into chunks
   - Retrieves top relevant chunks for a query (keyword or embedding-based)
   - Produces an answer constrained to retrieved context
3. Prepare 3 test questions in `questions.txt`.
4. Run the script on all 3 questions and save outputs to `results.md`.
5. Score each answer (1–5) on:
   - Factual correctness
   - Grounding to provided notes
   - Clarity
6. Add one short retrospective: what failed, and one concrete improvement.

## Expected Output Artifact
A mini repo/folder containing:
- `space_notes.md`
- `questions.txt`
- `results.md` (answers + scores)
- `README.md` (how to run + one improvement idea)

## Stretch Challenge
Add one “hallucination guard” check: if retrieved context confidence is low, the system must return “insufficient context” instead of guessing.
