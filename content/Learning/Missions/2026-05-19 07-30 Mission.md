# Daily Learning Mission — 2026-05-19

[[Home]]

## Mission Title
Build and Compare a Tiny RAG Pipeline (Local Notes Q&A)

## Objective
In 30–60 minutes, create a minimal retrieval-augmented generation (RAG) workflow and evaluate whether retrieval improves answer quality over plain prompting.

## Exact Steps
1. **Prepare source text (10 min):** Create one markdown file with ~600–1000 words (any topic you know).
2. **Chunk + embed (15 min):** Split text into small chunks (e.g., 300–500 chars, overlap 50) and generate embeddings (OpenAI or local embedding model).
3. **Retrieve (10 min):** For 3 test questions, fetch top-3 relevant chunks using cosine similarity.
4. **Answer generation (10 min):**
   - Run answers **without retrieval**.
   - Run answers **with retrieved context**.
5. **Quick evaluation (10 min):** Compare both on factual correctness and specificity.

## Expected Output Artifact
A single note named `RAG-mini-eval.md` containing:
- 3 test questions
- Retrieved chunks for each question
- Baseline answer vs RAG answer
- 3–5 bullet conclusion on when retrieval helped (or didn’t)

## Stretch Challenge
Add a tiny reranking step (or manually rerank top-5 to top-2) and check if answer quality improves further.
