## Mission Title
Prompt Engineering Bake-Off: Improve a Local Coding Prompt in 45 Minutes

## Objective
Design and compare 3 prompt variants for one coding task, then identify which prompt gives the best balance of correctness, clarity, and speed.

## Exact Steps (30–60 min)
1. Pick one small coding task (e.g., "write a Python script to parse a CSV and output grouped stats").
2. Write a **baseline prompt** and run it once in your preferred AI coding tool.
3. Create **Prompt A** (more constraints: output format, edge cases, test expectations).
4. Create **Prompt B** (role + stepwise reasoning request + acceptance criteria).
5. Run both prompts on the same task.
6. Score each output (1–5) on:
   - Correctness
   - Readability
   - Completeness
   - Time-to-use (how much fixing needed)
7. Choose the winner and write 3 rules you’ll reuse in future prompts.

## Expected Output Artifact
A short note (bullet list) containing:
- The 3 prompts (baseline, A, B)
- Scores table
- Winning prompt
- 3 reusable prompt rules

## Stretch Challenge
Take the winning prompt and adapt it for a **DevOps version** of the task (e.g., generate a Dockerfile + healthcheck + minimal CI snippet), then compare if your 3 rules still hold.
