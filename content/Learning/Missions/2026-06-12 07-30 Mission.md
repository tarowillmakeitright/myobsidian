# Edge LLM Benchmark: Tiny Local Inference

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Run one small local language model, measure inference speed and memory use, and write a 5-bullet conclusion about whether it is practical on this machine.

## Steps
1. Check what local inference tools are already installed (`ollama`, `llama.cpp`, or similar).
2. Pick one small model you can actually run today (about 1B–3B params if possible).
3. Run the model on one fixed prompt: "Summarize why quantization matters for local LLMs in 5 bullet points."
4. Measure:
   - model name
   - prompt + response latency
   - tokens/sec if available
   - peak RAM/VRAM use if available
5. Save a short note with:
   - your exact command
   - the model output
   - the measurements
   - 5 bullets: usable / not usable / why

## Expected Output Artifact
A benchmark note in Obsidian with the command used, raw result, measured performance, and a 5-bullet conclusion.

## Stretch Challenge
Repeat the same test with a second quantization or second small model and compare quality vs speed in 3 bullets.
