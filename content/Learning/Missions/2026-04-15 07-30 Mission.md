# Mission: Prompt Regression Test in 45 Minutes

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Set up a tiny prompt regression test so you can detect output quality drift after model/prompt changes.

## Exact Steps (30–60 min)
1. Create a folder `prompt-regression/` and add 5 representative prompts from your real use cases.
2. Define a simple scoring rubric (0–2 each): correctness, completeness, format compliance.
3. Run your current prompt/model on all 5 inputs and save outputs to `baseline.md`.
4. Make one intentional prompt improvement (structure, constraints, examples, or output schema).
5. Re-run the same 5 inputs and save outputs to `candidate.md`.
6. Score baseline vs candidate with the rubric and total the scores in `results.md`.
7. Write a 3-bullet conclusion: what improved, what regressed, what to keep.

## Expected Output Artifact
A mini evaluation bundle:
- `baseline.md`
- `candidate.md`
- `results.md` (with scores + final decision)

## Stretch Challenge
Automate step 3–6 with a small script (`python` or `bash`) so future prompt checks run with one command.
