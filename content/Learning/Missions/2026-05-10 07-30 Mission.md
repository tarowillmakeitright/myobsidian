# Edge AI Inference Benchmark Sprint

Tags: #learning #mission #ai #devops #science  
Links: [[Home]]

## Objective
Benchmark one small local LLM inference setup and document which runtime settings give the best speed/quality tradeoff on your machine in 30–60 minutes.

## Exact Steps
1. **Pick model + runtime (5 min):** Choose one small model already available locally (e.g., 1B–3B class) and one runtime you can launch quickly.
2. **Define benchmark prompt set (5 min):** Create 3 prompts: reasoning, summarization, and code explanation. Keep prompts fixed for all runs.
3. **Run baseline test (10 min):** Execute with default settings and record:
   - Time to first token (or first response latency)
   - Total response time
   - Output quality notes (1–2 lines per prompt)
4. **Run two configuration variants (15–20 min):** Change only one variable per run (e.g., context length, quantization level, thread count, batch size, or temperature).
5. **Compare + decide (10 min):** Summarize which config is best for:
   - Fastest response
   - Best perceived quality
   - Best overall balance
6. **Capture findings (5 min):** Write a short markdown report with a small comparison table/bullets and your recommended default profile.

## Expected Output Artifact
A note titled **"Local LLM Benchmark – 2026-05-10"** containing:
- Model/runtime used
- 3 test prompts
- Baseline + 2 variant results
- Final recommended config and why

## Stretch Challenge
Containerize the winning setup (or write a one-command launcher script) so tomorrow’s benchmark can be rerun in under 2 minutes.
