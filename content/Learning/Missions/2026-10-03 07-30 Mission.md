# Mission: Build a Tiny LLM Evaluation Harness

Links: [[Home]]

## Objective

In 30–60 minutes, create a repeatable Python test harness that compares two prompts on a small set of structured-output tasks and reports which prompt follows the required JSON schema more reliably.

## Exact steps

1. **Define the test set (10 min):** Write five short inputs that require output shaped as `{\"summary\": string, \"priority\": \"low|medium|high\"}`. Include one ambiguous and one deliberately messy input.
2. **Create two prompt variants (5 min):** Make Prompt A a simple instruction; make Prompt B explicitly state the schema, allowed values, and “return JSON only.”
3. **Build the evaluator (15–20 min):** Write `eval_prompts.py` to run both prompts against every input, parse each response with `json.loads`, and validate required keys, types, and allowed priority values. Use a model/API already available, or store sample responses locally if no API is configured.
4. **Score the results (5–10 min):** Print a compact table with prompt name, valid responses, failures, and pass rate. Save failure examples.
5. **Write the takeaway (5 min):** Add three sentences explaining which prompt won, the most common failure mode, and the next improvement you would test.

## Expected output artifact

A folder containing `eval_prompts.py`, `cases.json`, and `results.md` with pass rates and at least one documented failure example.

## Stretch challenge

Add a second metric that checks whether each summary is 25 words or fewer, then rerun the evaluation and compare whether better schema compliance also improves concision.
