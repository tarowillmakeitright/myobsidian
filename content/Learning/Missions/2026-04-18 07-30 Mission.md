## Mission Title
Build a Tiny Local RAG Pipeline (AI + DevOps)

## Objective
In 30–60 minutes, create a minimal Retrieval-Augmented Generation workflow that indexes 3 local markdown notes and answers one question using retrieved context.

## Exact Steps
1. Create a folder `rag-mini/` and add 3 short `.md` files (5–10 lines each) on different topics.
2. Write a small script (`rag_mini.py` or `rag_mini.js`) that:
   - reads the files,
   - splits text into chunks,
   - computes embeddings (any local/API method you already have),
   - stores vectors in a simple local index (FAISS/Chroma/simple cosine matrix).
3. Add a query step: input one question and retrieve top 3 relevant chunks.
4. Generate an answer using only retrieved chunks as context.
5. Log latency for indexing and query time (even rough timing is fine).

## Expected Output Artifact
A Git repo or folder containing:
- script file (`rag_mini.py` or `rag_mini.js`),
- sample notes,
- one `README.md` with:
  - how to run,
  - one test question,
  - retrieved chunks,
  - final answer,
  - timing numbers.

## Stretch Challenge
Add a `--source` flag so the script can index either markdown files or a single URL’s fetched text, then compare answer quality between both sources.
