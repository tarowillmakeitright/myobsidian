# Mission: Test an AI Output Contract

Links: [[Home]]

#learning #mission #ai #devops #science

## Objective

In 45 minutes, build a tiny repeatable test that checks whether an LLM returns valid, schema-compliant JSON for a practical incident-triage task.

## Exact steps

1. **Define the contract (5 min):** Create a JSON Schema with `severity` (`low|medium|high|critical`), `service`, `summary`, and `next_action`; make every field required.
2. **Create test cases (10 min):** Write five short synthetic DevOps alerts, including one ambiguous alert and one with distracting text.
3. **Run the experiment (15 min):** Send each alert to any available LLM using one fixed prompt. Save the raw responses without correcting them.
4. **Validate (10 min):** Check each response with a JSON Schema validator (for example, Python `jsonschema`) and record parse errors, schema errors, and incorrect severity judgments.
5. **Summarize (5 min):** Calculate the valid-response rate and write three prompt or schema improvements based on the failures.

## Expected output artifact

A folder containing:

- `schema.json` — the output contract
- `cases.jsonl` — five alerts and raw model responses
- `results.md` — pass/fail table, valid-response rate, observed failure modes, and three improvements

## Stretch challenge

Run the same five cases with a second prompt or model, then compare schema-validity and severity accuracy in `results.md`.
