# Edge AI Benchmark Sprint

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Compare the inference speed and resource usage of one small local LLM/runtime option on your machine, then write down what setup feels most practical for everyday use.

## Steps
1. Pick one lightweight local model/runtime you can already run or install quickly (for example: Ollama + a small model, llama.cpp, or a tiny embedding model).
2. Run a baseline prompt 3 times and record:
   - model/runtime name
   - prompt length
   - response length
   - time to first token or total response time
   - CPU/RAM usage if easy to capture
3. Change one variable only:
   - different quantization, or
   - different model size, or
   - different thread count
4. Run the same prompt 3 times again.
5. Summarize the difference in a short note: what got faster/slower, and whether quality stayed acceptable.

## Expected Output Artifact
A short benchmark note in Obsidian with:
- the exact commands used
- a tiny results table or bullet list
- your conclusion: “best practical setup for this machine today”

## Stretch Challenge
Automate the benchmark with a tiny shell script that reruns the same prompt and appends results to a dated log file.
