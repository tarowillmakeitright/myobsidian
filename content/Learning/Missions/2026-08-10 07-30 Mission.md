# Mission: Build a Tiny AI Service Health Check

#learning #mission #ai #devops #science

[[Home]]

## Objective

In 30–60 minutes, build and test a small shell-based health check for an AI inference API, measuring availability and response latency.

## Exact steps

1. Choose an AI API endpoint you can safely call (local Ollama, a development endpoint, or a mock HTTP server).
2. Write `ai-healthcheck.sh` using `curl` to send one minimal request, record the HTTP status, and measure total response time.
3. Make the script exit `0` when the response is successful and below a chosen latency threshold; otherwise exit nonzero with a clear error.
4. Run it five times and save timestamp, status, latency, and pass/fail results to `healthcheck-results.txt`.
5. Add a short README section explaining the endpoint, threshold, usage, and one failure you simulated.

## Expected output artifact

A folder containing `ai-healthcheck.sh`, `healthcheck-results.txt`, and a short `README.md` with evidence of both a passing check and a simulated failure.

## Stretch challenge

Wrap the script in a minimal GitHub Actions workflow or cron entry that runs automatically and preserves the latest result as an artifact.
