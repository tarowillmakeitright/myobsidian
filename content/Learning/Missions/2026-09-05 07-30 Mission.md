# Mission: Build an AI Service Health Check

[[Home]]

## Objective

In 30–60 minutes, build a small Python health-check script that verifies an AI inference endpoint is reachable, returns valid JSON, and responds within a latency threshold.

## Exact steps

1. Choose a local or hosted AI endpoint; if none is available, use a public JSON test endpoint as a stand-in.
2. Write `ai_healthcheck.py` using Python's standard library or `requests`.
3. Record HTTP status, total latency, and whether the response contains an expected JSON key.
4. Exit with code `0` when all checks pass and `1` when any check fails.
5. Run one successful test and one deliberate failure (for example, set an unrealistically low latency threshold).
6. Add a short README section showing the command, expected output, and how the check could run in CI or cron.

## Expected output artifact

- `ai_healthcheck.py`
- A README snippet with example pass/fail output
- Terminal evidence of both exit paths

## Stretch challenge

Emit a Prometheus-compatible latency metric or add exponential-backoff retries without exceeding a fixed timeout.
