## Mission Title
Build a 1-File AI Log Summarizer for Systemd Services

## Objective
In 30–60 minutes, create a small script that reads recent `journalctl` logs for one service and outputs a concise AI-style summary of errors, warnings, and likely next actions.

## Exact Steps
1. Pick one service to inspect (example: `sshd`, `docker`, or `openclaw-gateway`).
2. Export the last 200 lines to a text file:
   - `journalctl -u <service> -n 200 --no-pager > logs.txt`
3. Create a script (`summarize_logs.py` or `summarize_logs.sh`) that:
   - Counts ERROR/WARN/INFO patterns.
   - Extracts the top 3 repeated error lines.
   - Produces a short summary block with:
     - “What happened”
     - “Most likely cause”
     - “Suggested next check”
4. Run the script on `logs.txt`.
5. Save result as `artifact-log-summary.md`.

## Expected Output Artifact
A markdown file: `artifact-log-summary.md` containing counts, top repeated issues, and a 5–8 line actionable summary.

## Stretch Challenge
Add a “change detector” mode: compare today’s summary with yesterday’s summary and highlight **new** error patterns only.
