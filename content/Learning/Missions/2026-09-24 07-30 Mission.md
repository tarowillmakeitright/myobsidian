# Mission: Build a Tiny AI Service Health Gate

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective
In 30–60 minutes, build a small Python health gate that tests whether an AI inference endpoint is reachable, fast enough, and returning valid JSON before a deployment proceeds.

## Exact steps
1. Create `ai_health_gate.py` using only Python's standard library.
2. Accept an endpoint URL from `AI_HEALTH_URL`; default to a local mock URL such as `http://localhost:8000/health`.
3. Send a GET request with a 5-second timeout and record latency.
4. Validate that the response is HTTP 200 and JSON contains `{"status": "ok"}`.
5. Exit `0` when latency is under 1,000 ms and validation passes; otherwise print the failure reason and exit `1`.
6. Add three tests using a tiny local mock server: healthy, malformed JSON, and slow response.
7. Run the tests and capture the results in a short `README.md` usage example.

## Expected output artifact
A folder containing `ai_health_gate.py`, its tests, and a short `README.md` showing the command, pass/fail output, and how it could be used as a CI pre-deployment check.

## Stretch challenge
Emit a compact JSON result (`status`, `latency_ms`, `reason`) so a CI system can archive and graph the health-gate history.
