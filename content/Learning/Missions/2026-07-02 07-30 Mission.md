## Mission Title
Build a tiny local AI evaluation harness

## Objective
In 30–60 minutes, create a simple script that sends the same prompt to 3 test cases and scores the outputs with a clear rubric so you can compare quality consistently.

## Exact Steps
1. Pick 3 short prompts:
   - one summarization prompt
   - one extraction prompt
   - one reasoning prompt
2. Create a folder for the mini-lab and add a file like `eval_cases.json` with the 3 inputs.
3. Write a small script (Python or Node) that:
   - loads the test cases
   - runs them through your chosen local/API model setup
   - saves outputs to `results.md` or `results.json`
4. Define a rubric with 3 criteria:
   - correctness
   - clarity
   - brevity
   Score each from 1–5.
5. Review the results manually and note which prompt/task was strongest and weakest.
6. Write a 5-line conclusion: what failed, what worked, and one prompt tweak you would test next.

## Expected Output Artifact
A small folder containing:
- `eval_cases.json`
- your script
- `results.md` or `results.json`
- a short conclusion note

## Stretch Challenge
Add one automatic check, such as JSON-format validation for the extraction task or a length limit check for the summary task.
