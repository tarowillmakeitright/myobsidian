# Daily Learning Mission — 2026-03-25

## Mission Title
Build a Tiny RAG Evaluator (Local)

## Objective
In 30–60 minutes, build and run a minimal script that compares semantic search quality between two embedding models on a small custom dataset.

## Exact Steps
1. Create a folder `rag-mini-eval` and add a `data.json` file with 15 short facts (mix AI, DevOps, and space topics).
2. Define 8 query questions and expected relevant fact IDs in `queries.json`.
3. Write a Python script (`eval.py`) that:
   - loads data and queries,
   - computes embeddings with Model A and Model B,
   - runs cosine-similarity retrieval (top-3),
   - reports Recall@3 for each model.
4. Run the script and save output to `results.md`.
5. Add a 5-line conclusion: which model performed better and one likely reason.

## Expected Output Artifact
A mini evaluation package containing:
- `data.json`
- `queries.json`
- `eval.py`
- `results.md` (scores + brief conclusion)

## Stretch Challenge
Add one reranking step (simple keyword overlap or LLM reranker) and report whether Recall@3 improves.
