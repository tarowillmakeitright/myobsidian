# Mission: Test a Small AI Prompt Like an Engineer

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective
Build a tiny, repeatable evaluation that compares two prompt versions on 10 examples and reveals which prompt is more reliable.

## Exact steps (45 minutes)
1. **Choose a task (5 min):** Pick one narrow AI task, such as classifying support messages into `billing`, `bug`, or `question`.
2. **Create the test set (10 min):** Write 10 representative inputs in a Markdown table and assign each an expected answer.
3. **Write two prompts (5 min):** Make Prompt A minimal. Make Prompt B specify the labels, decision rules, and exact output format.
4. **Run the evaluation (15 min):** Submit every input to both prompts using the same model and settings. Record each output without correcting it.
5. **Score and inspect (10 min):** Mark exact-match pass/fail, calculate accuracy for A and B, and note the two most informative failures.

## Expected output artifact
A single Markdown evaluation report containing the 10-case dataset, both prompt versions, all outputs, accuracy scores, and a 3-sentence conclusion naming the better prompt and why.

## Stretch challenge
Add three adversarial examples with ambiguity, typos, or conflicting cues, then rerun the comparison and report how robust each prompt is.
