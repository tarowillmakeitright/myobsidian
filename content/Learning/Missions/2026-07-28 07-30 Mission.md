# Mission: Containerize a Tiny AI Inference API

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, build and run a containerized Python API that accepts a list of numbers and returns a simple linear-model prediction.

## Exact steps

1. Create a new working folder with `app.py`, `requirements.txt`, and `Dockerfile`.
2. In `app.py`, make a FastAPI `POST /predict` endpoint accepting `{"features": [1, 2, 3]}`.
3. Return `{"prediction": sum(features) * 0.5 + 1}` and reject an empty feature list.
4. Add FastAPI and Uvicorn to `requirements.txt`.
5. Write a minimal Python 3.12 slim Dockerfile, exposing port 8000.
6. Build with `docker build -t tiny-inference-api .`.
7. Run with `docker run --rm -p 8000:8000 tiny-inference-api`.
8. Test one valid and one invalid request with `curl`; record the commands and responses.

## Expected output artifact

A working three-file mini-project plus a short `RESULTS.md` containing the build command, both test requests, their responses, and one lesson learned.

## Stretch challenge

Add a `/health` endpoint and a Docker `HEALTHCHECK`, then confirm the container becomes healthy with `docker inspect`.
