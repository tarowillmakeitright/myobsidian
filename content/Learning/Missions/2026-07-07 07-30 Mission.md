# Fine-Tune a Tiny Text Classifier

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Build and evaluate a tiny sentiment or topic classifier using a small public text dataset, then write down what changed accuracy the most.

## Steps
1. Pick a small dataset: IMDb mini, AG News subset, or any 2-class text CSV you can download quickly.
2. Create a minimal Python notebook or script.
3. Train a baseline with TF-IDF + Logistic Regression.
4. Measure accuracy/F1 on a held-out test split.
5. Change one thing only: n-grams, stopword handling, or class balance.
6. Re-run and compare results.
7. Write a 5-line note: what you changed, metric before, metric after, why it likely helped or hurt.

## Expected Output Artifact
One notebook or script plus a short markdown note with baseline metric, improved metric, and takeaway.

## Stretch Challenge
Package the script so it runs from one command and saves metrics to a JSON file.
