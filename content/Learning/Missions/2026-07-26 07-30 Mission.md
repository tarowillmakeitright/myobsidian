# Mission: Containerize a Tiny AI API

## Objective

Build and run a small containerized Python API that exposes a deterministic “AI-style” text-classification endpoint, then verify its health and response. Timebox: 45 minutes.

## Exact steps

1. Create a new folder named `tiny-ai-api` with `app.py`, `requirements.txt`, and `Dockerfile`.
2. In `app.py`, create a FastAPI app with:
   - `GET /health` returning `{"status": "ok"}`.
   - `POST /classify` accepting `{"text": "..."}` and returning `positive`, `negative`, or `neutral` using a short keyword-based rule.
3. Add FastAPI and Uvicorn to `requirements.txt`.
4. Write a minimal Dockerfile using `python:3.12-slim`, install dependencies, copy the app, expose port 8000, and start Uvicorn.
5. Build it with `docker build -t tiny-ai-api .`.
6. Run it with `docker run --rm -p 8000:8000 tiny-ai-api`.
7. Test both endpoints with `curl`, including at least three classification inputs.
8. Record the image size with `docker image inspect tiny-ai-api --format '{{.Size}}'`.

## Expected output artifact

A runnable `tiny-ai-api/` project plus a short `RESULTS.md` containing the three test inputs/responses and the Docker image size.

## Stretch challenge

Add a Docker `HEALTHCHECK`, rebuild, and confirm the container becomes `healthy` with `docker ps`.
