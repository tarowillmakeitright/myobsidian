# Daily Learning Mission (2026-03-28)
[[Home]]

## Mission Title
**Prompt Hardening Sprint: Build a safer, more reliable system prompt test set**

## Objective
In 30–60 minutes, create and run a compact test suite (10 prompts) to evaluate how well an AI assistant follows constraints under adversarial or ambiguous requests.

## Exact Steps
1. Create a file `prompt-tests.md` with 10 test prompts:
   - 4 normal user tasks
   - 3 ambiguous/conflicting instruction tasks
   - 3 safety-boundary/adversarial tasks
2. For each prompt, write expected behavior in 1–2 lines.
3. Run each prompt against your assistant/model (manual is fine).
4. Record actual behavior in a table: `Prompt | Expected | Actual | Pass/Fail`.
5. Identify top 3 failure patterns and write one mitigation each.

## Expected Output Artifact
A note named `prompt-hardening-results.md` containing:
- The 10 prompts
- Pass/fail table
- 3 failure patterns + mitigations
- One updated “prompt rule” you will reuse going forward

## Stretch Challenge
Automate one part of the workflow (e.g., generate the pass/fail template or run prompts via a script/API) so tomorrow’s test run takes <15 minutes.
