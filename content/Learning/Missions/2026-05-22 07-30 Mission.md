# Daily Learning Mission — 2026-05-22
[[Home]]

## Mission Title
Container Health Signals with AI-Assisted Triage

## Objective
In 30–60 minutes, build a tiny Dockerized app, simulate a failure, capture health/log signals, and use an LLM to produce a concise incident triage note.

## Exact Steps
1. Create a minimal app (any language) that exposes `/health` and returns `OK`.
2. Add a `Dockerfile` and run it locally (`docker build` + `docker run`).
3. Add a Docker `HEALTHCHECK` to call `/health` every 10s.
4. Simulate a failure (e.g., make `/health` return 500 or stop dependency).
5. Collect evidence:
   - `docker ps` health status
   - `docker inspect` health output
   - last 50 lines of container logs
6. Paste the evidence into your preferred LLM and ask for:
   - probable root cause
   - confidence level
   - 3 next diagnostic commands
   - 1 immediate mitigation
7. Validate at least one suggested diagnostic command and note whether it helped.

## Expected Output Artifact
A single note section titled **Triage Snapshot** containing:
- failure timestamp
- observed health status/log excerpt
- AI triage summary
- one validated diagnostic result
- chosen mitigation (or why none)

## Stretch Challenge
Add one auto-remediation action (restart policy or lightweight watchdog script), then re-run the failure test and compare recovery time before vs after.
