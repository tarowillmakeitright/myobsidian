# Mission: Build a Tiny LLM Evaluation Harness

[[Home]]

#learning #mission #ai #devops #science

## Objective

In 30–60 minutes, create a small, repeatable Python harness that tests an LLM prompt against five cases and records whether each response meets simple, explicit criteria.

## Exact steps

1. **Define the task (5 min):** Choose one narrow prompt, such as “turn a short incident report into JSON with `summary`, `severity`, and `next_action`.”
2. **Create five cases (10 min):** Write normal, ambiguous, incomplete, adversarial, and edge-case inputs in `cases.json` with expected fields or keywords.
3. **Build the runner (15 min):** Write `eval.py` to load the cases, call your preferred LLM (or a local stub if no API is available), parse each result, and apply deterministic checks.
4. **Record results (10 min):** Output a Markdown table showing case name, pass/fail, failed criteria, and a short response excerpt.
5. **Improve once (10 min):** Revise the prompt based on the failures, rerun the suite, and compare the before/after pass rate.

## Expected output artifact

A folder containing `prompt.txt`, `cases.json`, `eval.py`, and `results.md`, with both the initial and revised pass rates documented.

## Stretch challenge

Add the harness to CI so it fails when fewer than 4 of 5 cases pass, while keeping model responses cached for reproducibility and cost control.
