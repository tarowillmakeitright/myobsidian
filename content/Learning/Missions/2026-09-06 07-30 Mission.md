# Mission: Build a Tiny AI Prompt Regression Test

#learning #mission #ai #devops #science

[[Home]]

## Objective

Create a small, repeatable test that detects when changes to an AI prompt make structured output worse. Complete it locally in 30–60 minutes.

## Exact steps

1. Create `cases.json` with five short inputs and the required output fields: `summary`, `category`, and `confidence`.
2. Write one prompt that instructs an LLM to return valid JSON matching those fields.
3. Create a script that runs all five cases, parses each response, and checks field presence, category validity, and `confidence` range (0–1).
4. Print a compact pass/fail report and save the raw responses to `results.json`.
5. Deliberately weaken one prompt instruction, rerun the test, and note which check catches the regression.

## Expected output artifact

A folder containing `cases.json`, the test script, `results.json`, and a short `README.md` with the command to run it and the observed pass rate.

## Stretch challenge

Run the same cases three times and add a consistency score showing how often the model returns the same category.
