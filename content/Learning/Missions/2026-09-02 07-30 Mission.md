# Mission: Build a Tiny AI Output Evaluator

#learning #mission #ai #devops #science

[[Home]]

## Objective

In 30–60 minutes, create a small Python script that scores an AI-generated answer against explicit quality checks, turning vague “looks good” reviews into a repeatable evaluation.

## Exact steps

1. Create `evaluate.py` and define one sample task, one candidate answer, and five required keywords or facts.
2. Add checks for: required-term coverage, answer length (50–200 words), presence of at least one concrete example, absence of placeholder text such as `TODO`, and a simple pass threshold.
3. Print each check as pass/fail, a total score out of 5, and the final verdict.
4. Run the evaluator against one strong answer and one deliberately weak answer.
5. Record the two results and write three sentences on which checks were useful or misleading.

## Expected output artifact

A runnable `evaluate.py` plus a short `results.md` containing both test results and the three-sentence reflection.

## Stretch challenge

Add a JSON output mode suitable for a CI pipeline and make the script exit with status code `1` when the candidate fails.
