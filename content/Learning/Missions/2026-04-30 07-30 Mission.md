## Mission Title
Build a Tiny AI Ops Log Classifier with Local Inference

## Objective
In 30–60 minutes, create a small script that classifies DevOps-style log lines into categories (error, warning, info) using a lightweight local model/API call pattern, then outputs a summary report.

## Exact Steps
1. Create a folder `~/tmp/ai-log-mission` and add a file `sample_logs.txt` with 20–30 mixed log lines.
2. Write a short Python script (`classify_logs.py`) that:
   - reads each log line,
   - classifies it into `error`, `warning`, or `info` (rule-based first, then optional LLM/local model fallback),
   - stores results in JSON.
3. Add a summary step in the script to count totals per class and print the top 3 most severe lines.
4. Run the script and save outputs as:
   - `classified_logs.json`
   - `summary.md`
5. Spend 5 minutes reviewing where misclassifications happened and note one improvement.

## Expected Output Artifact
- `classified_logs.json` with per-line label + confidence/reason
- `summary.md` with counts, top severe entries, and one improvement note

## Stretch Challenge
Add a simple anomaly rule: flag any minute with more than 5 `error` logs as a “burst incident,” and include incident windows in `summary.md`.
