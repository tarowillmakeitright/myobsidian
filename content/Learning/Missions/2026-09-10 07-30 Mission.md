# Mission: Measure an AI Semantic Cache

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 45 minutes, build a tiny Python experiment that measures how a semantic cache can reduce repeated LLM-style requests without calling a paid API.

## Exact steps

1. Create `semantic_cache.py` and define 10 sample prompts containing 3-4 paraphrased intent groups.
2. Use `sentence-transformers` with the `all-MiniLM-L6-v2` model to embed each prompt locally.
3. Process prompts in order: compare each embedding with cached embeddings using cosine similarity; count a cache hit when similarity is at least `0.80`.
4. Run the experiment at thresholds `0.70`, `0.80`, and `0.90`.
5. Record hit rate, false matches, and missed paraphrases for each threshold in a Markdown table.
6. Write a three-sentence conclusion choosing the safest useful threshold and explaining the latency/correctness tradeoff.

## Expected output artifact

A small folder containing `semantic_cache.py` and `results.md`, with a reproducible command such as `python semantic_cache.py`.

## Stretch challenge

Add a cache TTL field and simulate expired entries to see how expiration changes the hit rate.
