# Mission: Build a Tiny AI Prompt Evaluation Harness

## Objective

In 45 minutes, compare two prompt variants on a small fixed test set and choose the better one using explicit scoring criteria.

## Steps

1. **Define the task (5 min):** Pick one repeatable task, such as turning incident notes into a three-bullet summary.
2. **Create the test set (10 min):** Write five representative inputs, including one ambiguous case and one noisy case.
3. **Write two prompts (5 min):** Make Variant A minimal; make Variant B structured with output rules and one example.
4. **Run the evaluation (15 min):** Run both prompts on all five inputs with the same model and settings. Save every response.
5. **Score and decide (10 min):** Rate each response from 0–2 for correctness, format compliance, and usefulness. Total the scores and note the winner plus one observed failure mode.

## Expected Output Artifact

A single Markdown file named `prompt-eval.md` containing the five test cases, both prompts, ten model outputs, a score table, and a two-sentence conclusion.

## Stretch Challenge

Add a third prompt that specifically addresses the winning prompt's most common failure mode, then rerun only the failed cases.
