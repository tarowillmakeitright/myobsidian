# Mission: Build a Tiny RAG Evaluator (30–60 min)

[[Home]]

## Objective
Create a minimal local script that evaluates retrieval quality for a tiny RAG setup (5–10 docs) using a simple metric (Top-1 hit rate).

## Exact Steps
1. Create a folder `rag-mini/` and add 5–10 short text docs (AI, DevOps, or space facts).
2. Write 5 test questions where each has one clearly correct source doc.
3. Use embeddings + cosine similarity (or keyword fallback) to retrieve Top-1 doc per question.
4. Compare retrieved doc vs expected doc and compute hit rate = correct/total.
5. Print a small report: per-question result + final percentage.

## Expected Output Artifact
- One script (`evaluate_rag.py` or `.js`) and a terminal report showing Top-1 hit rate for 5 questions.

## Stretch Challenge
Add Top-3 hit rate and one failure analysis note per missed question (why retrieval failed + one fix idea).
