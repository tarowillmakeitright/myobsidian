# Daily Learning Mission — 2026-05-21
[[Home]]

## Mission Title
Build a Tiny RAG Pipeline with Local Documents

## Objective
In 30–60 minutes, build and test a minimal retrieval-augmented generation (RAG) workflow that can answer questions from your own markdown notes.

## Exact Steps
1. Create a folder `mini-rag/` and add 3–5 short markdown/text files as source docs.
2. Install deps in a virtual env: `pip install faiss-cpu sentence-transformers` (or equivalent embedding + vector DB stack).
3. Write a script that:
   - loads documents,
   - chunks text (around 300–500 chars),
   - embeds chunks,
   - stores vectors in FAISS.
4. Add query flow:
   - take a question,
   - retrieve top-3 chunks,
   - print retrieved context,
   - generate a final answer (LLM call or mocked template if no API).
5. Run 3 test questions and note whether answers are grounded in retrieved chunks.

## Expected Output Artifact
- A runnable script/notebook (`mini_rag.py` or `.ipynb`) plus a short `RESULTS.md` containing:
  - 3 sample questions,
  - retrieved snippets,
  - final answers,
  - one observed limitation.

## Stretch Challenge
Add a simple evaluation metric: for each test question, score answer grounding from 1–5 and compute average grounding score.
