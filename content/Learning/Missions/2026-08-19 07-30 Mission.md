## Objective

In 30–60 minutes, wrap a small text-classification function in a FastAPI service, add liveness/readiness endpoints, and verify it locally like a production service.

## Exact steps

1. Create a Python virtual environment and install `fastapi`, `uvicorn`, and `pytest`.
2. Build `app.py` with:
   - `POST /classify` accepting `{"text": "..."}` and returning a simple rule-based label such as `question`, `positive`, or `neutral`.
   - `GET /health/live` returning HTTP 200 while the process is running.
   - `GET /health/ready` returning HTTP 200 only when the classifier is initialized.
3. Run it with `uvicorn app:app --reload`.
4. Test all three endpoints with `curl`, including one invalid request that should return HTTP 422.
5. Add one automated test for `/classify` and one for `/health/ready`; run them with `pytest`.
6. Write three short notes explaining the difference between liveness, readiness, and functional endpoint checks.

## Expected output artifact

A folder containing `app.py`, `test_app.py`, and `README.md` with setup commands, sample `curl` output, test results, and the three health-check notes.

## Stretch challenge

Add a `Dockerfile`, run the service in a container, and configure a Docker `HEALTHCHECK` against `/health/ready`.
