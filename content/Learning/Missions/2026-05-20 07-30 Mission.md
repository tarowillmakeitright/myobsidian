## Mission Title
Build and Monitor a Tiny LLM API with Docker + Healthchecks

## Objective
Containerize a minimal local LLM-style API service, add health monitoring, and verify reliability basics in under 60 minutes.

## Exact Steps (30–60 min)
1. Create a folder `llm-microservice-lab` with:
   - `app.py` (simple FastAPI endpoint `/generate` returning mocked JSON text)
   - `requirements.txt` (`fastapi`, `uvicorn`)
2. Write a `Dockerfile` to run the API on port `8000`.
3. Run it with Docker:
   - `docker build -t llm-microservice-lab .`
   - `docker run -d --name llm-api -p 8000:8000 llm-microservice-lab`
4. Add a health endpoint `/health` and test:
   - `curl http://localhost:8000/health`
5. Add `docker-compose.yml` with a `healthcheck` block and restart policy.
6. Validate service state:
   - `docker ps`
   - `docker inspect --format='{{json .State.Health}}' llm-api`
7. Capture your results in a short note (what worked, one issue, one improvement).

## Expected Output Artifact
A Git-ready project folder containing:
- `app.py`, `requirements.txt`, `Dockerfile`, `docker-compose.yml`
- A short `README.md` with run/test commands and observed healthcheck output

## Stretch Challenge
Replace the mocked `/generate` response with a call to a local model runner (e.g., Ollama) and add request latency logging to each API call.
