# Daily Learning Mission — 2026-06-26

[[Home]]

## Mission Title
Trace a Tiny Python API with OpenTelemetry

## Objective
In 30–60 minutes, make a minimal local Python API emit traces so you can see what “observability” feels like in practice instead of just reading about it.

## Exact Steps
1. Create a new folder for the mini-lab.
2. Make a Python virtual environment and install:
   - `fastapi`
   - `uvicorn`
   - `opentelemetry-api`
   - `opentelemetry-sdk`
   - `opentelemetry-instrumentation-fastapi`
   - `opentelemetry-exporter-otlp`
3. Build a tiny FastAPI app with 2 endpoints:
   - `/hello`
   - `/slow` (add a small artificial delay)
4. Add OpenTelemetry instrumentation to the app.
5. Run the app locally and hit both endpoints a few times with `curl`.
6. Capture what telemetry you can observe:
   - request path
   - latency difference between `/hello` and `/slow`
   - any trace/span IDs shown in logs or exporter output
7. Write a short note: What became easier to understand once traces existed?

## Expected Output Artifact
One Obsidian note or markdown file containing:
- the final `app.py`
- the install commands
- a short sample of trace/log output
- 3 bullet-point observations

## Stretch Challenge
Add one custom span around the delayed section in `/slow`, then compare the trace structure before vs after.
