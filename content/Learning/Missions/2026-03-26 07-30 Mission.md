# Daily Learning Mission — 2026-03-26
[[Home]]

## Mission Title
Build a Tiny AI Ops Log Classifier (Local)

## Objective
In 30–60 minutes, create a small script that classifies DevOps-style log lines into categories (INFO/WARN/ERROR) using a lightweight AI API call or local heuristic fallback, then outputs a summary report.

## Exact Steps
1. Create a file `log_sample.txt` with 20–30 mixed log lines (deploy, health check, timeout, auth failure, etc.).
2. Write a script (`mission_log_classifier.py` or `.js`) that:
   - reads each line,
   - assigns a class (INFO/WARN/ERROR),
   - stores results in a structured format (CSV or JSON).
3. Add a final summary section counting each class and listing top 3 most critical lines.
4. Run the script and verify output is reproducible.
5. Write a short note (3–5 bullets) on where this could fit in a real incident triage workflow.

## Expected Output Artifact
- `classified_logs.json` (or `.csv`)
- `summary.txt` with counts + top critical lines
- One screenshot or terminal paste showing a successful run

## Stretch Challenge
Add simple alert logic: if `ERROR >= 3` in one run, automatically generate a Slack/Telegram-ready alert message template with timestamp and incident hint.
