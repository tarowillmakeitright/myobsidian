## Mission Title
Build a tiny local RAG pipeline with reranking (AI + practical MLOps)

## Objective
In 30–60 minutes, create a minimal Retrieval-Augmented Generation flow that indexes a small document set, retrieves top chunks, reranks results, and answers one query with citations.

## Exact Steps
1. Create a folder `mini-rag-lab/` with 3–5 short docs (markdown or text) on one topic you care about.
2. Chunk docs into ~300–500 character segments (quick script or manual split).
3. Generate embeddings for each chunk (any local/API embedding model you already use).
4. Store chunks + vectors in a simple local index (FAISS/Chroma or even JSON + cosine similarity).
5. Implement query flow: embed query → retrieve top 8 chunks.
6. Add reranking (cross-encoder or lightweight scoring) to reduce to top 3 chunks.
7. Build final prompt with those 3 chunks and ask one question.
8. Save output with cited chunk IDs and a 2–3 line reflection on quality.

## Expected Output Artifact
A repo/folder containing:
- `run_rag.py` or `run_rag.ipynb`
- `data/` documents
- `results.md` with:
  - query
  - top retrieved chunks
  - reranked top 3
  - final answer with citations
  - short reflection

## Stretch Challenge
Add an evaluation mini-check: run 5 test questions and report a simple hit-rate (`answer supported by retrieved chunk: yes/no`) in a small table.
