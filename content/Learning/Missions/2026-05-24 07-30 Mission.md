# Edge AI Healthcheck Pipeline (30–60 min)

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Build and run a tiny end-to-end pipeline that checks a local AI service endpoint, logs latency + status, and visualizes results to practice practical AI + DevOps reliability skills.

## Exact Steps
1. Create a folder `edge-ai-healthcheck` and a Python virtual environment.
2. Add a simple script (`check.py`) that:
   - Sends 20 HTTP requests to one AI endpoint (local model API or any reachable test endpoint).
   - Records timestamp, status code, response time (ms), and success/failure in `results.csv`.
3. Add a second script (`summary.py`) that computes:
   - Success rate
   - p50 and p95 latency
   - Total failures
4. Run both scripts and generate a short markdown report `REPORT.md` with those metrics.
5. (Optional if time remains) Put the checker in a `cron` line or systemd timer draft for every 15 minutes.

## Expected Output Artifact
A mini repo/folder containing:
- `check.py`
- `summary.py`
- `results.csv`
- `REPORT.md` (with success rate + p50/p95 + 1 reliability insight)

## Stretch Challenge
Containerize it with Docker and add one alert rule: if success rate drops below 95% or p95 latency exceeds your threshold, print/emit an alert line in the report.
