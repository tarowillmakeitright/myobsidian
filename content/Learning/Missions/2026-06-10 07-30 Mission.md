## Mission Title
Add Docker health checks to a small local service

## Objective
Learn how Docker `HEALTHCHECK` works by running a simple service, adding a health probe, and verifying healthy/unhealthy states in under 1 hour.

## Exact Steps
1. Pick a tiny service you can run locally (for example: `nginx`, a small Python HTTP server, or one of your own containers).
2. Start it once **without** a health check and inspect it with:
   - `docker ps`
   - `docker inspect <container>`
3. Create a minimal `Dockerfile` that adds a `HEALTHCHECK`, for example using `curl` or `wget` against `http://localhost`.
4. Build the image and run the container.
5. Confirm the health status changes with:
   - `docker ps`
   - `docker inspect --format='{{json .State.Health}}' <container>`
6. Intentionally break the probe once (wrong path, stop the service, or probe a missing endpoint) and observe the unhealthy state.
7. Fix it and confirm the container returns to healthy.
8. Write a short note: when health checks are useful, and one case where they can be misleading.

## Expected Output Artifact
Create a small note or gist-like snippet containing:
- the final `Dockerfile`
- the `docker build` and `docker run` commands
- one screenshot or pasted output showing `healthy`
- one pasted output showing `unhealthy`
- 3 bullet lessons learned

## Stretch Challenge
Put the same service into `docker-compose.yml` / `compose.yaml` with a health check and make another service wait on it before starting.
