# Mission: Build and Verify a Minimal AI Service Container

[[Home]]

#learning #mission #ai #devops #science

## Objective
In 45 minutes, containerize a tiny Python inference-style API and verify that it is healthy, reproducible, and runs as a non-root user.

## Exact steps
1. **Scaffold (10 min):** Create `app.py` with a `/health` endpoint and a `/predict` endpoint that accepts a number and returns its square. Add only the required dependency files.
2. **Containerize (10 min):** Write a small `Dockerfile` using a pinned Python base image, install dependencies, create a non-root user, and expose the service port.
3. **Build and run (10 min):** Build the image with a dated tag, start it locally, and call both endpoints with `curl`.
4. **Verify (10 min):** Confirm the container user is non-root, inspect image size, rebuild once, and compare the two image digests.
5. **Reflect (5 min):** Record what made the build reproducible or non-reproducible and one concrete improvement.

## Expected output artifact
A folder containing `app.py`, dependency file, `Dockerfile`, and `README.md`; the README includes build/run commands, curl results, image size, both digests, and a 3-sentence reflection.

## Stretch challenge
Generate an SBOM for the image with Syft (or Docker Scout) and add one discovered package/version plus a short supply-chain risk note to the README.
