# Mission: Build an AI Output Quality Gate

[[Home]]

## Objective
Create a small Python quality gate that checks structured AI output against a schema and fails like a CI job when the output is invalid.

## Steps (30–60 minutes)
1. Create `mission/response.json` with fields `summary` (string), `confidence` (number from 0 to 1), and `sources` (non-empty array of URLs).
2. Create `mission/schema.json` using JSON Schema to enforce those fields, ranges, and formats.
3. Install `jsonschema` in a temporary virtual environment: `python -m venv .venv && .venv/bin/pip install jsonschema`.
4. Write `mission/validate.py` to load both files, validate the response, print `PASS` on success, and exit non-zero with a readable error on failure.
5. Test one valid response and at least three invalid cases: missing field, out-of-range confidence, and empty sources.
6. Add a minimal CI-style shell command to `mission/README.md`: `.venv/bin/python mission/validate.py`.

## Expected artifact
A `mission/` folder containing `response.json`, `schema.json`, `validate.py`, and `README.md`, with one captured successful run and three documented failure cases.

## Stretch challenge
Add a GitHub Actions workflow that runs the validator on every push and pull request.
