# Daily Learning Mission — 2026-05-16
[[Home]]

## Mission Title
**Ship a Tiny LLM Ops Pipeline with Evaluation Gate**

## Objective
In 30–60 minutes, build a minimal local AI pipeline that runs a prompt against 5 test cases and fails if quality drops below a threshold.

## Exact Steps
1. Create a folder `mini-llm-ops/` with:
   - `prompts/system.txt`
   - `data/tests.json` (5 input/expected pairs)
   - `run_eval.py` (or `run_eval.js`)
2. Implement a script that:
   - Loads system prompt + each test input
   - Calls your model API/local model once per test
   - Scores each output (simple rubric: pass/fail or 0–2)
3. Compute total score and pass rate.
4. Add a quality gate:
   - Exit success only if pass rate >= 80%
5. Run once, then tweak the prompt and run again.
6. Record before/after scores in `RESULTS.md`.

## Expected Output Artifact
- A repo/folder containing `run_eval.*`, `tests.json`, and `RESULTS.md` with two runs (baseline + improved) and final pass rate.

## Stretch Challenge
Add one adversarial test case (ambiguous or noisy input) and make the prompt robust enough to keep pass rate >= 80%.
