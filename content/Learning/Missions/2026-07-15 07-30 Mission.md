# Build a Tiny AI Service Reliability Test

[[Home]]

#learning #mission #ai #devops #science

## Objective

In 30–60 minutes, create and test a minimal health-check harness for an AI API endpoint, covering availability, latency, and response-shape validation.

## Exact steps

1. Pick an AI endpoint you can call locally or remotely; if none is available, use a tiny mock HTTP server.
2. Write `ai_healthcheck.py` using Python standard-library modules. Send one request with a 10-second timeout.
3. Measure elapsed time and validate the HTTP status plus one required JSON field.
4. Print a single JSON result containing `ok`, `status`, `latency_ms`, `checked_at`, and `error`.
5. Run three checks: normal response, forced server error, and delayed response beyond the timeout.
6. Save the three outputs and add a five-line note explaining which failure signal would page an operator.

## Expected output artifact

`ai_healthcheck.py` plus `healthcheck-results.md` containing the three test outputs and the paging rule.

## Stretch challenge

Make the script return exit code 0 on success and 1 on failure, then wire it into a minimal GitHub Actions or cron example.
