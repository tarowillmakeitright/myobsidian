## Mission Title
Build a Tiny RAG Evaluator (AI + DevOps hygiene)

## Objective
In 30–60 minutes, create a minimal script that compares two retrieval settings on a small document set and reports which one gives better answer grounding.

## Exact Steps
1. Create a folder `mini-rag-eval` and add 5 short text docs (your notes or public snippets).
2. Write a simple script (Python or JS) that:
   - loads docs,
   - chunks with **Strategy A** (fixed 500 chars),
   - chunks with **Strategy B** (fixed 300 chars + overlap 50),
   - runs the same 3 test questions against both strategies.
3. For each question, record:
   - top retrieved chunk IDs,
   - answer text,
   - a 1–5 grounding score (manual quick judgment: does answer match retrieved text?).
4. Summarize results in a small table and declare a winner (A or B).
5. Commit files to git with a message: `feat: add mini rag evaluator and baseline comparison`.

## Expected Output Artifact
A short report file: `mini-rag-eval/RESULTS.md` containing:
- 3 questions,
- retrieval + answer comparison table,
- average grounding score for A vs B,
- one paragraph with your takeaway.

## Stretch Challenge
Add one lightweight CI check (GitHub Action or local script) that fails if `RESULTS.md` is missing required sections (`Questions`, `Scores`, `Takeaway`).
