# Daily Learning Mission — 2026-05-03

[[Home]]

## Mission Title
**Container Health Signals with Prometheus + Alert Rules (Mini DevOps Lab)**

## Objective
In 30–60 minutes, set up a tiny local monitoring flow that tracks container uptime and triggers a basic alert condition.

## Exact Steps
1. Start a simple app container (e.g., `nginx`) and confirm it is running.
2. Run Prometheus (or use an existing instance) with a scrape config that includes container metrics source (`cadvisor` or equivalent endpoint).
3. Add one alert rule: trigger when a target is `down` for >2 minutes.
4. Intentionally stop the app container to simulate failure.
5. Verify Prometheus marks the target down and the alert enters firing state.
6. Restart the container and confirm alert recovery.
7. Capture one screenshot (or text export) of target status and alert transition.

## Expected Output Artifact
A short lab note containing:
- The scrape config snippet
- The alert rule YAML snippet
- Proof of alert firing + recovery (screenshot or copied status output)
- 3 bullet “what I learned” summary

## Stretch Challenge
Route the alert to a local Alertmanager receiver (even a webhook/test receiver) and log one delivered notification payload.
