# Mission: Detect Data Drift Before an AI Model Breaks

[[Home]]

#learning #mission #ai #devops #science

## Objective

In 45 minutes, build a tiny Python check that compares a model's reference input distribution with a shifted batch and fails when drift is significant.

## Exact steps

1. Create a folder named `drift-check` and a Python virtual environment.
2. Install `numpy` and `scipy`.
3. Generate 1,000 reference values from `N(0,1)` and 300 current values from `N(0.5,1)` using a fixed random seed.
4. Run SciPy's two-sample Kolmogorov–Smirnov test on the two arrays.
5. Print the KS statistic, p-value, and `PASS` or `DRIFT DETECTED`; use `p < 0.05` as the failure rule.
6. Exit with code `1` when drift is detected so the script can act as a CI/CD quality gate.
7. Run it once with shifted data and once with unshifted data; record both results in a short README.

## Expected output artifact

A `drift-check/` folder containing `check_drift.py`, `requirements.txt`, and `README.md` with the two test runs and a one-sentence interpretation.

## Stretch challenge

Add a GitHub Actions workflow that runs the drift check on every push and intentionally demonstrates both a passing and failing dataset.
