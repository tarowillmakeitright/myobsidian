# Mission: Build a Tiny CI Security Gate

[[Home]]

## Objective

Create a GitHub Actions workflow that scans a small container image for HIGH and CRITICAL vulnerabilities, then fails the build when an unfixed CRITICAL issue is found.

## Exact steps (30–60 minutes)

1. **Create the target (5 min):** In a throwaway repository, add a minimal `Dockerfile` based on `alpine:latest` that runs `echo "security gate passed"`.
2. **Build locally (5 min):** Run `docker build -t security-gate-demo .` and confirm the image runs.
3. **Add CI (15 min):** Create `.github/workflows/container-scan.yml` with jobs to check out the repository, build the image, and scan it using `aquasecurity/trivy-action`. Set `severity: CRITICAL,HIGH`, `ignore-unfixed: true`, and `exit-code: 1`.
4. **Trigger the gate (5 min):** Commit and push, or run the workflow with `act` if available. Observe whether the scan passes or fails.
5. **Record evidence (10 min):** Save the workflow result, the number of HIGH/CRITICAL findings, and one sentence explaining why `ignore-unfixed` was chosen.
6. **Reflect (5 min):** Write two bullets: one benefit of blocking vulnerable images and one risk of making the gate too strict.

## Expected output artifact

A working `.github/workflows/container-scan.yml` plus a short `scan-notes.md` containing the run result, vulnerability counts, configuration rationale, and two reflection bullets.

## Stretch challenge

Generate a Trivy SARIF report and upload it to GitHub Code Scanning so findings appear in the repository’s **Security** tab.
