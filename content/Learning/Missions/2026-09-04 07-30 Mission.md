# Mission: Model an ISS-Like Orbit

[[Home]]

## Objective

Build a small Python calculator that estimates circular-orbit speed and period, then use it to compare low Earth orbit altitudes. Timebox: 30–60 minutes.

## Exact steps

1. Create `orbit.py` using Earth radius `6371 km` and gravitational parameter `398600.4418 km³/s²`.
2. Implement `orbit(altitude_km)` returning orbital radius, speed `sqrt(mu / r)`, and period `2π * sqrt(r³ / mu)`.
3. Calculate results for 200, 400, 800, and 2,000 km altitudes.
4. Print a clean table with altitude, speed in km/s, and period in minutes.
5. Add three assertions: speed decreases with altitude, period increases with altitude, and the 400 km period falls between 90 and 95 minutes.
6. Save the terminal output as `orbit-results.txt` and write two sentences explaining the trend.

## Expected output artifact

`orbit.py` plus `orbit-results.txt`, containing a four-row comparison table, passing assertions, and a two-sentence interpretation.

## Stretch challenge

Add CSV output and plot altitude versus orbital period with Matplotlib.
