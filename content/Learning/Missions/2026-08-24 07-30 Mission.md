# Mission: Build an AI API Reliability Probe

#learning #mission #ai #devops #science

Linked from: [[Home]]

## Objective

In 30–60 minutes, build a small Python probe that calls an AI API (or a local mock), measures latency and success, and produces a machine-readable health report.

## Exact steps

1. Create `ai_probe.py` using Python's standard library plus your preferred AI SDK, if available.
2. Send the same tiny prompt five times: `Reply with exactly: OK`.
3. For each call, record timestamp, HTTP/result status, latency in milliseconds, and whether the response matched `OK`.
4. Add a 10-second timeout and catch errors without stopping the remaining calls.
5. Write all results to `ai_probe_results.json` and print a summary with success rate, median latency, and slowest call.
6. Run the probe and inspect the JSON. Note one reliability risk you observed and one improvement you would make in production.

## Expected output artifact

- `ai_probe.py`
- `ai_probe_results.json` containing five measurements and summary statistics
- A two-sentence reliability note at the bottom of this mission

## Stretch challenge

Add exponential-backoff retries with jitter, then deliberately trigger one failure and verify that the report captures both the initial failure and retry outcome.
