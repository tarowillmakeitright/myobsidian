# Mission: Build an AI Prompt Regression Test

[[Home]]

## Objective

Create a tiny, repeatable test harness that checks whether changes to an AI prompt improve answer quality without breaking required behavior. Complete it in **45–60 minutes**.

## Exact steps

1. **Pick one task (5 min):** Choose a prompt you actually use, such as summarizing an incident report or turning notes into action items.
2. **Create five test cases (10 min):** Save five representative inputs in `cases.json`, each with 2–3 explicit pass criteria (for example: contains an owner, includes a deadline, invents no facts).
3. **Write two prompt versions (5 min):** Put the current prompt in `prompt-a.txt` and one improved version in `prompt-b.txt`.
4. **Run the comparison (15 min):** Submit every case to both prompts using your available model/UI. Save the ten responses in `results.md`.
5. **Score blindly (10 min):** Hide which prompt produced each answer, then score every criterion as pass/fail. Calculate the pass rate for A and B.
6. **Record the decision (5 min):** In `results.md`, note the winner, failure patterns, and whether the new prompt is safe to adopt.

## Expected output artifact

A folder containing `cases.json`, `prompt-a.txt`, `prompt-b.txt`, and `results.md`, with a pass-rate comparison and an adopt/reject decision.

## Stretch challenge

Turn the criteria into an automated script that exits non-zero when any must-pass requirement fails, making the evaluation usable in CI.
