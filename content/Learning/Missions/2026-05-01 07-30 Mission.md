## Mission Title
Build and Compare a Tiny RAG Pipeline (Embeddings + Retrieval)

## Objective
In 30–60 minutes, create a minimal local Retrieval-Augmented Generation (RAG) prototype and evaluate whether retrieval improves answer quality on your own notes.

## Exact Steps
1. Create a small dataset: collect 5–10 short notes (plain text/markdown) on one topic you already know.
2. Generate embeddings for each note chunk (use your preferred local or API embedding tool).
3. Store vectors in a simple index (FAISS/Chroma/LanceDB or equivalent).
4. Prepare 5 test questions whose answers are in the notes.
5. Run baseline answers without retrieval.
6. Run RAG answers with top-3 retrieved chunks.
7. Compare baseline vs RAG for correctness and specificity; record quick observations.

## Expected Output Artifact
A single markdown report with:
- the 5 test questions,
- baseline vs RAG answers,
- retrieved chunks (or IDs),
- a short conclusion: “When did retrieval help most?”

## Stretch Challenge
Add a reranking step (or simply vary top-k = 1, 3, 5) and report which setting gave the best quality/time tradeoff.
