## Mission Title
**PromptOps Mini-Lab: Build a Repeatable LLM Evaluation Harness (45 min)**

## Objective
Create a tiny, reusable evaluation workflow that tests one prompt against 5 varied inputs and scores output quality using a simple rubric.

## Exact Steps (30–60 min)
1. **Pick one task** (e.g., summarize technical text in 3 bullets).
2. **Write a base prompt** in a file (`prompt.md`) with clear constraints.
3. **Prepare 5 test inputs** in `cases.jsonl` (easy, ambiguous, noisy, long, edge-case).
4. **Run the prompt on all 5 cases** (manual or script) and collect outputs in `results.md`.
5. **Score each output (1–5)** on: correctness, clarity, constraint-following.
6. **Identify top 2 failure patterns** and revise prompt once.
7. **Re-run only failed cases** and compare before/after scores.

## Expected Output Artifact
A folder (or note section) containing:
- `prompt.md`
- `cases.jsonl`
- `results.md` with before/after scores
- A 5-line “what improved” summary

## Stretch Challenge
Add a **lightweight pass/fail gate**: define minimum acceptable scores and mark the prompt as “deployment-ready” only if all cases pass.
