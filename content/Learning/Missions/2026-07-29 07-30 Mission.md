# Mission: Containerize a Tiny AI Inference API

[[Home]]

## Objective

In 45–60 minutes, build and run a reproducible Docker container that serves a tiny local text-classification model through one HTTP endpoint.

## Exact steps

1. Create a small Python app with FastAPI and a `POST /classify` endpoint accepting `{"text": "..."}`.
2. Use a lightweight Hugging Face sentiment pipeline such as `distilbert-base-uncased-finetuned-sst-2-english`.
3. Add pinned dependencies in `requirements.txt`.
4. Write a `Dockerfile` using a slim Python base image, a non-root user, and port `8000`.
5. Build the image: `docker build -t tiny-ai-api .`
6. Run it: `docker run --rm -p 8000:8000 tiny-ai-api`
7. Test with `curl` and record the response plus image size.

## Expected output artifact

A folder containing `app.py`, `requirements.txt`, `Dockerfile`, and `README.md` with the build/run/test commands and one sample response.

## Stretch challenge

Add a Docker health check and verify its status with `docker inspect`.
