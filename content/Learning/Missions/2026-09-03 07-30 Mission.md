# Mission: Containerize and Health-Check a Tiny AI API

#learning #mission #ai #devops #science

[[Home]]

## Objective

In 30–60 minutes, package a minimal AI-style inference endpoint in Docker and add a health check so the service can report whether it is ready.

## Exact steps

1. Create a small Python FastAPI service with `GET /health` and `POST /predict`; have `/predict` accept text and return its word count plus a placeholder label.
2. Add pinned dependencies in `requirements.txt` and write a `Dockerfile` using a slim Python base image and a non-root user.
3. Add a Docker `HEALTHCHECK` that calls `/health`.
4. Build the image locally: `docker build -t tiny-ai-api:today .`
5. Run it on port 8000 and verify both endpoints with `curl`.
6. Record the image size, health status, and one thing you would harden before production.

## Expected output artifact

A folder containing `app.py`, `requirements.txt`, `Dockerfile`, and `README.md`, with the README showing the build/run/test commands and observed results.

## Stretch challenge

Add a resource limit with Docker Compose and confirm the endpoint still responds under a short 20-request burst.
