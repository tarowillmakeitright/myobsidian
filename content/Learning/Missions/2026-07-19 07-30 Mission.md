# Build a Tiny AI Answer Verifier

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 45 minutes, build a small Python script that checks an AI-style answer against a trusted reference and flags unsupported claims.

## Exact steps

1. Create a working folder and a `verify.py` script (5 min).
2. Define one short trusted reference paragraph on a topic you know, plus three candidate answers: accurate, partly unsupported, and incorrect (10 min).
3. Split each answer into sentences and compare its important terms with the reference using only Python's standard library (15 min).
4. Print a simple report for each sentence: `SUPPORTED`, `REVIEW`, or `CONTRADICTED`, with a brief reason (10 min).
5. Run all three examples and write down where the heuristic succeeds or fails (5 min).

## Expected output artifact

A runnable `verify.py` and a saved sample report showing results for all three candidate answers.

## Stretch challenge

Add a confidence score from 0-100 and a `--reference` argument that loads the trusted text from a file.
