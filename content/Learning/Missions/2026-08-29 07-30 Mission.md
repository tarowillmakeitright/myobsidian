## Objective

In 30–60 minutes, build a small, repeatable Python harness that compares two prompt variants against five test cases and produces a scored Markdown report.

## Exact steps

1. Create `prompt_eval.py` using only Python’s standard library.
2. Define five short test cases, each with an input and required keywords or facts.
3. Define two prompt variants: a concise baseline and a structured alternative.
4. Run each test case through both variants using an AI interface you already have; paste the ten responses into a JSON file. If no API is available, generate them manually in ChatGPT.
5. Score each response automatically for required-keyword coverage and response length.
6. Have the script generate `evaluation-report.md` with a results table, average scores, and the winning prompt.
7. Write three sentences explaining where the scoring method is misleading or incomplete.

## Expected output artifact

`prompt_eval.py`, `responses.json`, and `evaluation-report.md`, containing a reproducible comparison of two prompts across five cases.

## Stretch challenge

Add one adversarial test case with ambiguous or conflicting instructions, then introduce a third metric that rewards the response for explicitly handling the ambiguity.
