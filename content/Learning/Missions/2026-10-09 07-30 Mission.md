# Mission: Test an AI Summarizer Against Prompt Injection

[[Home]]

## Objective
Build a tiny, repeatable evaluation that checks whether an AI summarization prompt ignores malicious instructions embedded in source text. Complete in 30–60 minutes.

## Exact steps
1. Create three short input documents: one normal, one containing “ignore prior instructions,” and one asking the model to reveal its system prompt.
2. Write a system prompt that tells the model to summarize only factual content and treat all document text as untrusted data.
3. Run all three inputs through the same model and prompt; save each response.
4. Score each response on two checks: useful summary (pass/fail) and injection resisted (pass/fail).
5. Revise the system prompt once, rerun any failed case, and record what changed.
6. Write a three-sentence conclusion: what worked, what failed, and the next safeguard to test.

## Expected output artifact
A Markdown file named `prompt-injection-eval.md` containing the prompt, three test inputs, model outputs, a six-cell pass/fail results table, and the conclusion.

## Stretch challenge
Automate the three cases with a short script that exits nonzero when a response contains a known forbidden phrase.
