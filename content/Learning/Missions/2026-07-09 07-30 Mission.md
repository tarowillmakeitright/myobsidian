# Local AI Mission: Compare Embedding Models on a Tiny Dataset

#learning #mission #ai #devops #science

## Objective
Evaluate two embedding models on a small set of notes and see which one groups similar topics better in practice.

## Steps
1. Create a tiny dataset of 12 short text snippets: 4 AI, 4 DevOps, 4 space/science.
2. Generate embeddings for all 12 snippets using Model A.
3. Generate embeddings for the same 12 snippets using Model B.
4. For each model, compute cosine similarity and list the top 3 nearest neighbors for each snippet.
5. Check whether items cluster with the right topic more often.
6. Write a 5-bullet conclusion on which model feels more useful and why.

## Expected Output Artifact
A short comparison note or markdown table with:
- the 12 snippets
- nearest-neighbor results for both models
- your final verdict in 5 bullets

## Stretch Challenge
Visualize the embeddings with UMAP or PCA and save one chart showing whether the three topics separate cleanly.
