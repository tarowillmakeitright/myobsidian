# Daily Learning Mission — 2026-05-12
[[Home]]

## Mission Title
**Build a Tiny RAG Pipeline with Local Embeddings (AI + DevOps mindset)**

## Objective
In 30–60 minutes, create a minimal Retrieval-Augmented Generation (RAG) demo that indexes 3 short docs, retrieves relevant context, and generates one grounded answer.

## Exact Steps
1. **Set up workspace (5 min):**
   - Create a folder: `~/tmp/tiny-rag-mission`
   - Add 3 text files (`doc1.txt`, `doc2.txt`, `doc3.txt`) on topics you know.
2. **Create embeddings + index (15–20 min):**
   - Use any embedding method you already have access to (local model or API).
   - Store vectors in a simple in-memory list or lightweight DB (e.g., Chroma/FAISS).
3. **Implement retrieval (10–15 min):**
   - Write a script that accepts a question, computes query embedding, returns top-2 chunks.
4. **Generate grounded answer (10–15 min):**
   - Prompt an LLM with only retrieved chunks + question.
   - Force citation format like: `[doc1]`, `[doc2]`.
5. **Quick evaluation (5 min):**
   - Test with 3 questions (1 easy, 1 ambiguous, 1 out-of-scope).
   - Note where retrieval or grounding fails.

## Expected Output Artifact
- One runnable script or notebook (`tiny_rag_demo.py` or `.ipynb`) plus:
  - a short `README.md` with run command,
  - sample Q&A output showing citations,
  - 3-line “what broke / what worked” note.

## Stretch Challenge
Add a **confidence guardrail**: if top retrieval similarity is below a threshold, return “I don’t have enough context” instead of hallucinating.
