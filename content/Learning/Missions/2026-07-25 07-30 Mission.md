# Mission: Containerize and Health-Check a Tiny AI API

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, package a minimal Python “AI inference” API in Docker and verify that it reports both service health and prediction results.

## Exact steps

1. Create a folder named `tiny-ai-api` with `app.py`, `requirements.txt`, and `Dockerfile`.
2. In `app.py`, build a FastAPI service with:
   - `GET /health` returning `{"status":"ok"}`
   - `POST /predict` accepting `{"text":"..."}` and returning the text length plus a simple label: `short` under 40 characters, otherwise `long`.
3. Add `fastapi` and `uvicorn[standard]` to `requirements.txt`.
4. Write a Dockerfile based on `python:3.12-slim`, install dependencies, copy the app, expose port 8000, and run Uvicorn.
5. Build and run it:
   - `docker build -t tiny-ai-api .`
   - `docker run --rm -p 8000:8000 tiny-ai-api`
6. In another terminal, test:
   - `curl http://localhost:8000/health`
   - `curl -X POST http://localhost:8000/predict -H 'Content-Type: application/json' -d '{"text":"Saturn has more than 140 known moons."}'`
7. Record the image size and one thing you learned about containerizing APIs.

## Expected output artifact

A working `tiny-ai-api/` project containing the three source files, plus a short `RESULTS.md` with both curl responses, the Docker image size, and one learning.

## Stretch challenge

Add a Docker `HEALTHCHECK` instruction that probes `/health`, then confirm the container becomes `healthy` with `docker ps`.
