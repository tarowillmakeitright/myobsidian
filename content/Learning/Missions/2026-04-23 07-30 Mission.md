## Mission Title
**Build a Tiny RAG Pipeline with Local Embeddings**

## Objective
In 30–60 minutes, create a minimal Retrieval-Augmented Generation (RAG) workflow that indexes a small text corpus and answers one query with retrieved context.

## Exact Steps
1. Create a folder `mini-rag/` and add 3–5 short text files (`docs/`) on one topic (e.g., Kubernetes basics).
2. Generate embeddings for each file chunk using any local or API embedding model you already have.
3. Store vectors in a simple index (FAISS, Chroma, or even cosine similarity in Python lists).
4. Write a script that:
   - embeds a user query,
   - retrieves top-3 relevant chunks,
   - builds a prompt with those chunks,
   - produces an answer from your LLM.
5. Run one test query and inspect if retrieved chunks actually support the answer.
6. Add a 5-line note: what worked, what failed, what to improve next.

## Expected Output Artifact
- A runnable script/notebook (`mini-rag/main.py` or `.ipynb`)
- Sample query + answer + retrieved chunks (saved in `results.md`)
- Brief retrospective notes (`notes.md`)

## Stretch Challenge
Add a **source-citation check**: every sentence in the final answer must reference one of the retrieved chunk IDs (or mark as "unsupported").
