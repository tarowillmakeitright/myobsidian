## Mission Title
Build a Tiny Local AI API Benchmark

## Objective
Compare the response speed and output quality of 2-3 local or remote LLM API calls using one prompt and one simple measurement table. Finish with a short conclusion on which setup feels best for practical daily use.

## Exact Steps
1. Pick one prompt you actually care about, such as: “Summarize this log and extract action items.”
2. Choose 2-3 model/API targets you can access today.
3. Send the exact same prompt to each target.
4. Measure:
   - time to first response
   - total response time
   - output usefulness (1-5)
5. Record results in a small table.
6. Write 3 bullet observations:
   - fastest
   - most useful
   - best tradeoff
7. End with one decision: which model/API you’d use this week and why.

## Expected Output Artifact
A note with:
- the shared test prompt
- a comparison table
- 3 observations
- a 1-paragraph recommendation

## Stretch Challenge
Run the same benchmark again with a second prompt type (for example: code explanation vs. summarization) and see whether the “best” model changes.
