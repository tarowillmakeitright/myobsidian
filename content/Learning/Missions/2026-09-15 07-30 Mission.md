# Mission: Build a Tiny LLM Output Regression Check

[[Home]]

#learning #mission #ai #devops #science

## Objective

Create a lightweight Python check that compares a candidate AI response with a reference response and fails CI when similarity falls below a chosen threshold.

## Exact steps

1. **Define fixtures (5 min):** Create `reference.txt` and `candidate.txt` with two short answers to the same prompt.
2. **Build the checker (15 min):** Write `check_output.py` using only Python's standard library. Normalize case and punctuation, calculate Jaccard similarity across word sets, print the score, and exit with code `1` below a `0.60` threshold.
3. **Test both paths (10 min):** Run it once with a similar candidate and once with a deliberately unrelated candidate. Confirm exit codes `0` and `1`.
4. **Add CI wiring (10 min):** Create a minimal GitHub Actions workflow that runs `python check_output.py` on pushes.
5. **Record the result (5 min):** Add a short README section explaining the metric, threshold, and one limitation.

## Expected output artifact

A small folder containing `reference.txt`, `candidate.txt`, `check_output.py`, `.github/workflows/llm-regression.yml`, and a README with two recorded test scores.

## Stretch challenge

Add a second metric—character trigram similarity—and require both metrics to pass, then compare which metric better catches a meaning-preserving paraphrase.
