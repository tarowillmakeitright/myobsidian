## Objective
Deploy a tiny FastAPI inference service in Docker and validate health, latency, and basic observability in one local run.

## Steps (30–60 min)
1. **Create app**: Build a minimal FastAPI app with one `/predict` endpoint returning a mock classification.
2. **Containerize**: Add a `Dockerfile` (Python slim base, install deps, expose port 8000).
3. **Run locally**: `docker build -t edge-ai-smoke .` then `docker run -p 8000:8000 edge-ai-smoke`.
4. **Health + load check**: Test `/docs` and `/predict` with `curl`; run 50 requests (loop or lightweight benchmark) and measure average latency.
5. **Add basic metrics**: Log request count + response time (simple middleware/log output is enough).
6. **Document results**: Record command list, latency result, and one bottleneck/improvement idea.

## Expected Output Artifact
A short `README.md` (or Obsidian note) containing:
- service architecture (2–3 bullets)
- exact build/run/test commands
- latency result from 50 requests
- one concrete next optimization

## Stretch Challenge
Swap the mock response for a real tiny model (e.g., scikit-learn `.pkl`), then compare latency before vs after and note deployment trade-offs.
