# Mission: Containerize a Tiny AI Inference API

#learning #mission #ai #devops #science

[[Home]]

## Objective

In 30–60 minutes, package a minimal Python inference endpoint in Docker and verify that it responds locally. Use a deterministic rule-based “model” so the exercise stays focused on deployment fundamentals.

## Steps

1. Create `app.py` with a FastAPI `POST /predict` endpoint accepting `{"text": "..."}` and returning `{"label": "positive"}` when the text contains `good`, otherwise `{"label": "neutral"}`.
2. Add `requirements.txt` containing pinned versions of FastAPI and Uvicorn.
3. Write a `Dockerfile` based on `python:3.12-slim`, install dependencies, copy the app, expose port 8000, and launch Uvicorn.
4. Build it: `docker build -t tiny-inference-api .`
5. Run it: `docker run --rm -p 8000:8000 tiny-inference-api`
6. In another terminal, test it: `curl -X POST http://localhost:8000/predict -H 'Content-Type: application/json' -d '{"text":"good launch"}'`
7. Record the image size and one thing you would improve for production.

## Expected Output Artifact

A small folder containing `app.py`, `requirements.txt`, and `Dockerfile`, plus a saved successful `curl` response and the Docker image size.

## Stretch Challenge

Add a Docker `HEALTHCHECK` and confirm the container reports `healthy` with `docker ps`.
