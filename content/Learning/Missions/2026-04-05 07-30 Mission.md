## Objective
Build and compare two prompt versions for the same task, then evaluate output quality with a simple scoring rubric in 30–60 minutes.

## Exact Steps
1. Pick one practical task (e.g., “summarize a technical article into action items”).
2. Write **Prompt v1** (basic, short instructions).
3. Write **Prompt v2** (adds constraints: output format, tone, and success criteria).
4. Run both prompts on the same input using your preferred AI tool.
5. Score each output (1–5) on: accuracy, clarity, usefulness, and completeness.
6. Note which prompt won and why in 3–5 bullet points.
7. Save everything in this note.

## Expected Output Artifact
A single note containing:
- Prompt v1 and v2
- Two model outputs
- Scoring table (or bullet scores)
- Final “winner + reasoning” summary

## Stretch Challenge
Create **Prompt v3** by combining the best parts of v1/v2, rerun once, and see if total score improves by at least +2 points.
