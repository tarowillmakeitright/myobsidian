## Mission Title
Ship a Minimal CI Pipeline with GitHub Actions (DevOps)

## Objective
In 30–60 minutes, create a working CI workflow that runs lint + tests automatically on every push and pull request.

## Exact Steps
1. Pick a small repo (Python/Node) with at least one test.
2. Add a workflow file:
   - `.github/workflows/ci.yml`
   - Trigger on `push` and `pull_request`.
3. Configure job steps:
   - Checkout code
   - Setup runtime (Python/Node)
   - Install dependencies
   - Run linter (`ruff`/`eslint`)
   - Run tests (`pytest`/`npm test`)
4. Commit and push to a feature branch.
5. Open a PR (or push to main) and verify the workflow passes.
6. Intentionally break one test/lint rule, push again, and confirm CI fails.
7. Fix it and confirm CI returns to green.

## Expected Output Artifact
- A committed CI config file: `.github/workflows/ci.yml`
- One screenshot (or note) showing a failed run and a successful run
- A 3–5 bullet “what I learned” note in this file

## Stretch Challenge
Add a cache step (pip/npm cache) and measure whether the second run is faster; note the time difference.
