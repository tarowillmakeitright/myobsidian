# Mission: Build a Tiny AI Evaluation Harness

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

Create a repeatable Python evaluation harness that scores an AI text classifier against a small labeled dataset. Finish in 30–60 minutes.

## Exact steps

1. Create `cases.jsonl` with 12 short messages labeled `question`, `request`, or `feedback` (four of each).
2. Create `evaluate.py` using only the Python standard library. It should read the JSONL file, call a placeholder `classify(text)` function, and compare predictions with labels.
3. Implement a simple keyword-based baseline in `classify` so the harness runs without an API key.
4. Print overall accuracy plus a per-label table showing correct and total counts.
5. Run `python evaluate.py`, inspect the failures, and improve the baseline once without changing the test labels.
6. Add a short `README.md` documenting the dataset format, run command, final score, and two observed failure modes.

## Expected output artifact

A small folder containing `cases.jsonl`, `evaluate.py`, and `README.md`, with a reproducible evaluation result and documented baseline score.

## Stretch challenge

Add a confusion matrix and a `--predictions output.jsonl` option that saves each input, expected label, predicted label, and pass/fail result.
