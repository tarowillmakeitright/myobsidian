# Mission: Build and Inspect a Minimal Container SBOM

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

In 30–60 minutes, build a tiny container image, generate its Software Bill of Materials (SBOM), and identify one dependency or base-image risk.

## Exact steps

1. Create a directory containing a minimal `Dockerfile` based on `alpine:3.22` that runs `echo "SBOM mission complete"`.
2. Build it: `docker build -t sbom-mission:today .`
3. Record its immutable ID: `docker image inspect sbom-mission:today --format '{{.Id}}'`.
4. Generate an SBOM with Docker Scout: `docker scout sbom sbom-mission:today --format spdx-json --output sbom.spdx.json`. If Scout is unavailable, use `syft sbom-mission:today -o spdx-json=sbom.spdx.json`.
5. Inspect the first 30 lines and search the file for package names, versions, and licenses.
6. Write three observations: package count, one surprising package/license, and one way to reduce the image’s attack surface.

## Expected output artifact

A folder containing `Dockerfile`, `sbom.spdx.json`, and `findings.md` with the image ID and three observations.

## Stretch challenge

Scan the image with Docker Scout or Trivy, then add the highest-severity finding and a concrete mitigation to `findings.md`.
