# Mission: Build a Tiny Local RAG Evaluator (30–60 min)

Tags: #learning #mission #ai #devops #science  
Links: [[Home]]

## Objective
Create a minimal Retrieval-Augmented Generation (RAG) evaluation script that measures whether retrieval quality improves answer accuracy on a tiny custom dataset.

## Exact Steps
1. **Create dataset (10 min):** Make 5 short domain notes (plain text) on one topic (e.g., Kubernetes basics, LLM concepts, or Mars missions).
2. **Write baseline Q&A (10 min):** Create 5 questions answerable from those notes and record model answers **without retrieval**.
3. **Add retrieval (15–20 min):**
   - Chunk notes into small passages.
   - Use a simple embedding/search method (or keyword BM25 if faster).
   - For each question, retrieve top 2 passages and answer with that context.
4. **Score results (10 min):** Compare baseline vs retrieval answers using a 0/1 correctness score per question.
5. **Summarize (5 min):** Write 3 bullets: what improved, what failed, and one next fix.

## Expected Output Artifact
A single folder containing:
- `notes/*.txt` (source docs)
- `questions.md` (5 questions)
- `results.md` (baseline vs RAG answers + scores)
- `summary.md` (key findings + next step)

## Stretch Challenge
Add one “distractor” document with misleading but related content and re-run evaluation to see if retrieval precision drops.
