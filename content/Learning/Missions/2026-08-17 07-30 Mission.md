# Mission: Build a Tiny AI Evaluation Harness

## Objective

In 45 minutes, build a small, repeatable Python test that scores an AI model's answers against five fixed prompts. The goal is to practice evaluation—not prompt tweaking—and leave behind a baseline you can rerun later.

## Exact steps

1. **Define the test set (10 min):** Create `cases.json` with five prompts, each containing one expected keyword or short fact. Use a mix of summarization, extraction, classification, reasoning, and factual recall.
2. **Write the runner (15 min):** Create `evaluate.py`. Load the cases, call any model/API you already have access to (or paste model responses into the JSON), and record each response.
3. **Add deterministic scoring (10 min):** Score each response `1` when the expected keyword appears after lowercasing, otherwise `0`. Print per-case results and an overall percentage.
4. **Run and inspect (5 min):** Execute the evaluation once. Manually review any failures and note whether the model was wrong or the metric was too crude.
5. **Document the baseline (5 min):** Add a short `README.md` with the model name, date, score, and one lesson about evaluation quality.

## Expected output artifact

A folder containing `cases.json`, `evaluate.py`, and `README.md`, plus one recorded baseline score that can be reproduced with a single command.

## Stretch challenge

Add a second scorer that uses a regular expression or a set of acceptable answers, then compare how much the baseline score changes.
