# Mission: Build an AI Service Health Check

Links: [[Home]]

## Objective

In 30–60 minutes, create a small Python health-check script that tests an AI API endpoint for availability, latency, and valid JSON—three signals useful in DevOps monitoring.

## Exact steps

1. Pick an AI-compatible HTTP endpoint you can safely call (a local model endpoint is ideal). If none is available, use `https://httpbin.org/json` as a stand-in.
2. Create `ai_healthcheck.py` using only Python’s standard library (`urllib`, `json`, `time`, and `sys`).
3. Send one GET request with a 10-second timeout and record elapsed time.
4. Validate that the response status is `200` and the body parses as JSON.
5. Print one compact JSON result containing `status`, `http_code`, `latency_ms`, `json_valid`, and `checked_at`.
6. Exit with code `0` when healthy and `1` otherwise.
7. Run it once against the working endpoint and once against an intentionally invalid URL; save both outputs.

## Expected output artifact

- `ai_healthcheck.py`
- `healthcheck-results.txt` containing one successful and one failed test result

## Stretch challenge

Add configurable warning and critical latency thresholds, then emit `healthy`, `degraded`, or `unhealthy` so the script can plug into cron or a monitoring system.
