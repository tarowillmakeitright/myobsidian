# Daily Learning Mission — 2026-04-12
[[Home]]

## Mission title
**Containerize a tiny AI API with a real health check**

## Objective
In 30–60 minutes, build and run a minimal local AI-style API (FastAPI) in Docker, then verify service health and logs like a production mini-deploy.

## Exact steps
1. Create a folder `ai-microservice-lab` and add `app.py` with two endpoints:
   - `GET /health` → `{ "status": "ok" }`
   - `POST /infer` → accepts `{ "text": "..." }` and returns a simple result (e.g., word count + uppercase text).
2. Add `requirements.txt` with `fastapi` and `uvicorn`.
3. Write a `Dockerfile` (Python slim base, install requirements, expose port 8000, run uvicorn).
4. Build and run:
   - `docker build -t ai-microservice-lab .`
   - `docker run --rm -p 8000:8000 --name ai-lab ai-microservice-lab`
5. Validate:
   - `curl http://localhost:8000/health`
   - `curl -X POST http://localhost:8000/infer -H "Content-Type: application/json" -d '{"text":"hello tokyo"}'`
6. Capture operational proof:
   - `docker logs ai-lab --tail 30`
   - Save terminal outputs into `mission-output.md`.

## Expected output artifact
A small repo/folder containing:
- `app.py`, `requirements.txt`, `Dockerfile`
- `mission-output.md` with curl responses and recent container logs
- One screenshot or text snippet proving `/health` and `/infer` both worked

## Stretch challenge
Add a `docker-compose.yml` with a proper `healthcheck` and confirm container health transitions to `healthy` using `docker ps`.
