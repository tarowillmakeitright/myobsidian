# Mission: Build a Tiny AI Prompt Regression Test

#learning #mission #ai #devops #science

[[Home]]

**Timebox:** 45 minutes

## Objective

Create a small, repeatable test that detects when an AI prompt starts producing worse answers after a prompt or model change.

## Exact steps

1. **Define the behavior (5 min):** Pick one task you use often (for example, turning notes into three action items). Write three representative inputs and a one-sentence success criterion for each.
2. **Capture a baseline (10 min):** Run all three inputs with your current prompt. Save the outputs verbatim in a Markdown file.
3. **Create a scorecard (10 min):** Score each output from 0–2 on correctness, format compliance, and usefulness. Record both the scores and one short reason per score.
4. **Test a variation (10 min):** Change exactly one thing in the prompt, rerun the three cases, and score the new outputs with the same rubric.
5. **Decide and document (10 min):** Compare totals, note any regressions, and write a keep/revert decision plus the single most useful lesson learned.

## Expected output artifact

One Markdown report containing the prompt versions, three test inputs, both sets of outputs, the 0–2 scorecard, and a final keep/revert decision.

## Stretch challenge

Turn the scorecard into a JSON test fixture and write a tiny script that calculates totals and fails with a non-zero exit code when the new version scores below the baseline.
