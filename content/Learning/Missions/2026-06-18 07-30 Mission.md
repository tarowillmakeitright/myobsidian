## Mission Title
Trace an AI Request End-to-End with Docker Logs

## Objective
Understand how an AI app behaves at runtime by launching a small containerized service, sending one request, and tracing the request through logs, process state, and configuration.

## Exact Steps
1. Pick any small AI-related app or API container you already have access to locally (or use a simple Python/Node mock service if easier).
2. Start it with Docker and expose one local port.
3. Run `docker ps` and note container name, image, port mapping, and uptime.
4. Send one test request to the app with `curl` and save the request/response.
5. Run `docker logs --tail 50 <container>` and identify the exact log lines related to your request.
6. Run `docker inspect <container>` and extract 3 useful details: env vars, restart policy, and mounted volumes.
7. Write a short summary: what happened from request -> container -> logs -> response.

## Expected Output Artifact
A note or markdown report containing:
- the Docker run/start command
- the test request and response
- the relevant log snippet
- 3 inspect findings
- a 5-bullet end-to-end explanation

## Stretch Challenge
Add a health check or restart policy to the container, restart it, and note what operational visibility improved.
