# Mission: Build a Tiny AI Evaluation Harness

**Objective:** In 45 minutes, create a repeatable 10-case evaluation that measures whether an AI prompt produces correct, well-formatted answers.

## Exact steps

1. **Define the task (5 min):** Pick one prompt you reuse (summarization, classification, extraction, or code review). Write one sentence describing what a correct response must contain.
2. **Create test cases (10 min):** Make `eval_cases.csv` with columns `id,input,expected`. Add 10 cases: 6 normal, 2 edge cases, and 2 deliberately ambiguous cases.
3. **Set a rubric (5 min):** Score each response on correctness (0–2), format compliance (0–1), and unsupported claims (0–1, where 1 means none).
4. **Run the baseline (10 min):** Submit all 10 inputs with the same prompt and record outputs in `eval_results.md`.
5. **Score and diagnose (10 min):** Score every result, total the points out of 40, and identify the two most common failure patterns.
6. **Revise once (5 min):** Improve the prompt to address those failures, rerun the two worst cases, and note whether each score improved.

## Expected output artifact

A small `ai-prompt-eval/` folder containing:

- `prompt-v1.md` and `prompt-v2.md`
- `eval_cases.csv` with 10 labeled cases
- `eval_results.md` with scores, total score, failure patterns, and the two-case rerun

## Stretch challenge

Write a short Python script that reads `eval_cases.csv`, validates the response format automatically, and prints a pass rate.
