# Mission: Containerize a Tiny AI Inference API

[[Home]]

## Objective

In 45–60 minutes, package a minimal Python inference API in Docker and verify that it runs reproducibly with a health check.

## Exact steps

1. Create a small FastAPI app with `GET /health` and `POST /predict`; make `/predict` accept a list of numbers and return their mean plus a simple label (`high` if mean ≥ 0.5, otherwise `low`).
2. Add pinned dependencies in `requirements.txt` (`fastapi` and `uvicorn`).
3. Write a `Dockerfile` using a slim Python base image, a non-root user, and an explicit command to start Uvicorn.
4. Build it: `docker build -t tiny-inference-api .`
5. Run it: `docker run --rm -p 8000:8000 tiny-inference-api`
6. Test both endpoints with `curl`, then record the commands, responses, image size, and one lesson learned.

## Expected output artifact

A folder containing `app.py`, `requirements.txt`, `Dockerfile`, and `README.md` with build/run/test evidence.

## Stretch challenge

Add a Docker `HEALTHCHECK`, then inspect its status with `docker inspect` and document the result.
