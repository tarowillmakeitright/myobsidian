## Mission Title
Build a tiny LLM evaluation harness

## Objective
Compare 2 prompting styles on the same task and measure which one gives more reliable answers in a simple, repeatable way.

## Exact Steps
1. Pick one narrow task with clear correctness checks, like: summarize a paragraph in 3 bullets, extract 5 facts from a short article, or answer 10 basic shell/Linux questions.
2. Create a small test set of 8–10 inputs in a note or CSV.
3. Write Prompt A: a plain direct instruction.
4. Write Prompt B: the same instruction but with explicit output format + success criteria.
5. Run both prompts on the same test set.
6. Score each result on 3 things: correctness, format compliance, and consistency.
7. Write a short conclusion: when did Prompt B help, and when was it unnecessary?

## Expected Output Artifact
A note or markdown table with:
- the test set
- Prompt A and Prompt B
- scores for each input
- a 5-sentence conclusion

## Stretch Challenge
Add a third variant that uses one-shot example prompting, then compare all 3 and write a simple “default prompting rule” for your future work.
