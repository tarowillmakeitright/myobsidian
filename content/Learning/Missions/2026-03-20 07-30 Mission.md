# Mission: Build a Local AI-Powered Log Anomaly Detector (30–60 min)

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Create a small Python script that scans a sample system log file and flags potentially anomalous lines (errors, spikes, or unusual patterns), then outputs a short anomaly report.

## Exact Steps
1. **Create a workspace**
   - Make a folder: `~/tmp/log-anomaly-mission`
   - Create `sample.log` with ~100–300 mixed lines (INFO/WARN/ERROR), or copy a real non-sensitive log.

2. **Set up environment**
   - Create and activate a Python venv.
   - Install: `pandas` and `scikit-learn`.

3. **Build parser + features**
   - Write `anomaly_detector.py` to:
     - Read log lines
     - Extract timestamp (if present), level, and message length
     - Convert lines into basic numeric features (e.g., length, error flag, warning flag)

4. **Detect anomalies**
   - Use `IsolationForest` from scikit-learn.
   - Score each line; mark top outliers as anomalies.

5. **Generate report artifact**
   - Save `anomaly_report.md` with:
     - Total lines analyzed
     - Number of anomalies found
     - Top 10 anomalous lines with reason/score

6. **Quick validation**
   - Inject 3–5 intentionally weird lines (e.g., repeated failures, very long stack traces).
   - Re-run and verify they appear in the report.

## Expected Output Artifact
- `anomaly_report.md` containing anomaly summary and top suspicious log entries.

## Stretch Challenge
Containerize it with Docker (`Dockerfile`) and run it against a mounted log file, so the detector can be used as a reusable DevOps troubleshooting utility.
