## Mission Title
**Build a Tiny RAG Pipeline with Local Embeddings**

## Objective
In 30–60 minutes, build and test a minimal Retrieval-Augmented Generation (RAG) workflow that can answer questions from a small custom note set.

## Exact Steps
1. Create a folder with 3 short text notes (e.g., AI safety, CI/CD basics, exoplanets).
2. Generate embeddings for each note using a local or API embedding model.
3. Store vectors in a lightweight index (FAISS/Chroma or equivalent).
4. Write a simple query script that:
   - embeds the user question,
   - retrieves top-2 relevant notes,
   - builds a prompt with retrieved context,
   - returns an answer.
5. Run 3 test questions and log whether retrieved context was relevant.

## Expected Output Artifact
A single repo/folder containing:
- `notes/` (source texts)
- `build_index.*` and `ask.*` scripts
- `results.md` with 3 example Q&A runs and brief observations

## Stretch Challenge
Add a reranking or citation step so each answer includes the exact source note filename(s) used.
