# Edge AI Mini-Eval Mission

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Compare 3 small language models for one practical task and decide which is best for speed vs output quality on your machine.

## Steps
1. Pick one local or API-accessible small model set (example: 3B–8B class).
2. Create 3 test prompts:
   - summarize a technical paragraph
   - explain a shell command simply
   - generate a short monitoring alert runbook
3. Run all 3 prompts against 3 different models.
4. Record for each run:
   - latency
   - output quality (1–5)
   - obvious failure mode
5. Write a 5-line comparison and choose:
   - best for speed
   - best for clarity
   - best overall

## Expected Output Artifact
A markdown note or table with the 9 results plus your final recommendation.

## Stretch Challenge
Repeat one prompt with a tighter system prompt and see whether prompt engineering beats switching models.
