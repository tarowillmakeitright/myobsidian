# Mission: Build an AI Output Regression Check

#learning #mission #ai #devops #science

Links: [[Home]]

## Objective

Create a tiny automated check that detects when an AI prompt starts producing structurally invalid output. Complete it in 45 minutes using a fixed prompt, five test inputs, and a JSON schema.

## Exact steps

1. **Define the contract (5 min):** Choose a simple task such as classifying incident severity. Specify JSON fields `severity`, `summary`, and `next_action`, including allowed severity values.
2. **Create five cases (10 min):** Write three normal incident descriptions and two edge cases (ambiguous input and empty input). Record the expected severity or expected validation failure.
3. **Build the checker (15 min):** Write a small script that submits each case to your available model, parses the response as JSON, validates required fields and allowed values, and exits non-zero on failure.
4. **Run and inspect (10 min):** Execute all five cases. Save pass/fail status, latency, and the raw response for any failed case.
5. **Document one finding (5 min):** Note the weakest case and make one prompt or schema improvement; rerun only that case.

## Expected output artifact

A folder containing `cases.json`, `check.py` (or equivalent), and `results.md` with a five-row pass/fail summary plus the final prompt/schema version.

## Stretch challenge

Run the suite against a second model or temperature setting and add a comparison showing reliability and median latency.
