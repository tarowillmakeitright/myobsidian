# Mission: Make an AI Evaluation Gate for CI

[[Home]]

## Objective

Build a tiny, repeatable evaluation that checks an AI prompt against five test cases and fails when accuracy drops below 80%—the core of an AI-aware CI quality gate.

## Exact steps (30–60 minutes)

1. Create `eval_cases.json` with five short classification cases, each containing `input` and `expected` (`positive`, `negative`, or `neutral`).
2. Write `evaluate.py` using only Python's standard library. It should load the cases, call a placeholder `classify(text)` function, and compare predictions with expected labels.
3. Print each case as `PASS` or `FAIL`, then print `score: X/5`.
4. Exit with status `0` when the score is at least 4/5; otherwise exit with status `1`.
5. Run `python evaluate.py`, deliberately break one prediction, and confirm the command fails once the score falls below the threshold.
6. Add a minimal CI workflow (GitHub Actions or your preferred CI) that runs `python evaluate.py` on every push.

## Expected output artifact

A small folder containing `eval_cases.json`, `evaluate.py`, and one CI workflow file, plus terminal output proving both a passing and failing run.

## Stretch challenge

Add a second metric—per-label recall—and make the gate fail if any label has 0% recall, even when overall accuracy is at least 80%.
