## Title
Build a Local AI Evaluation Harness

## Objective
In 30–60 minutes, create a tiny repeatable workflow to compare 2 prompts on the same task and judge which one produces more reliable output.

## Exact Steps
1. Pick one small task for an LLM, such as: summarize a short article, extract action items from notes, or classify 10 support messages.
2. Write Prompt A: a simple direct instruction.
3. Write Prompt B: the same task, but with explicit output format and success criteria.
4. Run both prompts on 3 test inputs using the same model.
5. Score each result on accuracy, format consistency, and usefulness from 1–5.
6. Write a 5–8 sentence note on which prompt performed better and why.

## Expected Output Artifact
A short markdown note containing:
- the task
- Prompt A and Prompt B
- 3 test inputs
- score table
- your conclusion on the better prompt

## Stretch Challenge
Turn the scoring into a reusable template so tomorrow you can test a new prompt in under 10 minutes.
