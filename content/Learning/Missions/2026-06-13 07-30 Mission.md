## Mission Title
Edge AI Container Benchmark: CPU vs Quantized Model

## Objective
Measure the practical difference between running a small AI model normally vs a quantized version in a containerized workflow, and capture one clear takeaway about speed, memory, or usability.

## Exact Steps
1. Pick a small local model or demo you can run today (for example: a tiny embedding model, image classifier, or text model already available on your machine).
2. Run it once in your usual setup and record:
   - startup time
   - inference time for 3 test inputs
   - memory usage if visible
3. Create or reuse a simple container for the same workload.
4. Run the workload again in the container and record the same metrics.
5. If you have access to a quantized version of the model, run that too and record the same metrics.
6. Put results in a small comparison table.
7. Write 3 bullets:
   - what got faster/slower
   - what got easier/harder operationally
   - whether the tradeoff feels worth it for edge or laptop use

## Expected Output Artifact
A markdown note with:
- the commands or setup used
- a 3-column comparison table
- one short conclusion paragraph

## Stretch Challenge
Automate the benchmark with a tiny shell script or Makefile so tomorrow you can rerun the same test in one command.
