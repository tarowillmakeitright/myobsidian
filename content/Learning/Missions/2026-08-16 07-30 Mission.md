# Mission: Trace One AI Request End to End

[[Home]]

#learning #mission #ai #devops #science

## Objective

Build a tiny local AI-style API and trace one request through structured logs, latency metrics, and an error path. Finish in 45–60 minutes.

## Exact steps

1. Create a minimal Python HTTP service with `POST /infer` that accepts `{"prompt": "..."}` and returns a deterministic mock response plus a generated request ID.
2. Add structured JSON logs for request ID, prompt length, status, and elapsed milliseconds. Never log the full prompt.
3. Add validation: return HTTP 400 when `prompt` is missing or empty.
4. Send three requests: one valid, one empty, and one with a 1,000-character prompt.
5. Record each status code and latency, then write three observations about reliability, privacy, or performance.

## Expected output artifact

A small runnable service, a three-request test script or command list, and a short results table containing request ID, input size, status, and latency.

## Stretch challenge

Add a 500 ms timeout around a simulated model call and confirm the service returns HTTP 504 with a useful structured error log.
