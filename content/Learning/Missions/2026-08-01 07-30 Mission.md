# Mission: Build an AI Deployment Readiness Gate

[[Home]]

#learning #mission #ai #devops #science

## Objective

In 45 minutes, create a small CI-style script that decides whether an AI model is safe to deploy based on accuracy, latency, and model-size thresholds.

## Exact steps

1. Create a folder named `ai-readiness-gate` and add `metrics.json` with accuracy `0.91`, p95 latency `240` ms, and model size `480` MB.
2. Write `check_readiness.py` using only the Python standard library.
3. Set pass thresholds: accuracy ≥ `0.90`, p95 latency ≤ `250` ms, and size ≤ `500` MB.
4. Print a clear PASS/FAIL result for every metric and exit with code `0` only when all pass.
5. Run it once with passing data, then change one metric so it fails and confirm the process exits nonzero.
6. Add a short `README.md` showing both commands and example output.

## Expected output artifact

A runnable `ai-readiness-gate/` mini-project containing `metrics.json`, `check_readiness.py`, and `README.md`, with evidence of both a passing and failing run.

## Stretch challenge

Add a `--thresholds thresholds.json` option so deployment limits can change without editing Python code.
