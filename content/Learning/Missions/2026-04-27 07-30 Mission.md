# Mission: Ship a Local RAG Evaluator in 45 Minutes

Tags: #learning #mission #ai #devops #science
Links: [[Home]]

## Objective
Build a tiny local Retrieval-Augmented Generation (RAG) evaluation flow that compares 2 retrieval settings and reports which one gives better answer quality.

## Exact Steps (30–60 min)
1. Create a folder `rag-mini-lab` and add 8–12 short markdown notes (your own docs or sample AI/DevOps/science notes).
2. Build embeddings + a vector index (FAISS/Chroma or equivalent) with a simple script.
3. Define 5 test questions with expected key points (1–3 bullets each).
4. Run retrieval+answer generation with **Setting A** (`top_k=3`) for all 5 questions.
5. Run retrieval+answer generation with **Setting B** (`top_k=6`) for all 5 questions.
6. Score each answer quickly (0–2): factual correctness, relevance, and citation support.
7. Summarize totals and decide a winner with one short takeaway.

## Expected Output Artifact
A single file: `evaluation-report.md` containing:
- The 5 questions
- Scores for A vs B
- Final recommendation (`top_k=3` or `top_k=6`) with a 2–3 sentence rationale

## Stretch Challenge
Add one failure-case question (ambiguous wording), then improve retrieval with metadata filtering or query rewriting and re-score that question.
