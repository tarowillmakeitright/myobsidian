# Mission: Build a Tiny LLM Output Quality Gate

[[Home]]

#learning #mission #ai #devops #science

## Objective

Create a small Python quality gate that checks structured AI output before it enters an automated workflow. Learn how schema validation turns unreliable model text into a testable DevOps contract.

## Exact steps

1. **Define the contract (5 min):** Create a JSON shape for a deployment review with `risk_level` (`low`, `medium`, or `high`), `summary` (10–200 characters), and `approved` (boolean).
2. **Write the validator (15 min):** In Python, validate those fields and return clear error messages. Use only the standard library, or Pydantic if already installed.
3. **Create fixtures (10 min):** Add four sample responses: one valid, one missing a field, one with an invalid risk level, and one with an overlong summary.
4. **Add an automation-friendly exit code (10 min):** Make the script exit `0` for valid input and `1` for invalid input, printing errors to stderr.
5. **Run and record (5 min):** Test all fixtures and paste the command output into a short README or the bottom of the script as a comment.

## Expected output artifact

A folder containing `validate_review.py`, four JSON fixtures, and a short `README.md` showing the test commands and results.

## Stretch challenge

Add a GitHub Actions workflow that runs the validator against every JSON fixture on each push, with invalid fixtures explicitly expected to fail validation.
