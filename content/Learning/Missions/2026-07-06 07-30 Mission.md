## Objective
Build a tiny prompt-evaluation set and measure how a model changes when you tighten the instructions.

## Exact steps
1. Pick one everyday task for an LLM:
   - summarize a short article,
   - extract action items from notes, or
   - rewrite text in a clearer style.
2. Create **5 test inputs** in a note or text file.
3. Write a **baseline prompt** and run it on all 5 inputs.
4. Write an **improved prompt** with clearer constraints:
   - required output format,
   - tone/style rule,
   - one “do not” rule,
   - success criteria.
5. Run the improved prompt on the same 5 inputs.
6. Score both versions from 1-5 on:
   - correctness,
   - consistency,
   - formatting.
7. Write a short comparison: what changed, what improved, what still fails.

## Expected output artifact
A note with:
- the 5 test inputs,
- baseline prompt,
- improved prompt,
- a simple score table,
- 3-5 bullet conclusions.

## Stretch challenge
Turn your scoring checklist into a reusable prompt-eval template you can use again this week.
